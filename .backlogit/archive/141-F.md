## Diagnostic outcome handling (amendment A2R — REPLACES the former "hard stop / partial close")

**Superseded wording (review-fix cycle 2, PR #386, threads PRRT_kwDORzpWpM6bSzLz / PRRT_kwDORzpWpM6bSzMM):** this feature previously said that if the bisect could not isolate a minimal pair, 141.001-T "returns blocked" and "the feature closes with the diagnosis + hygiene tasks only". **That is not executable.** `.github/agents/_ship.agent.md:325-340` derives the executable task set from the manifest, treats any member status outside `queued`/`active`/`done`/pre-archived as a **FAIL-CLOSED HALT, never a skip**, and forbids mutating the manifest to make execution proceed. A blocked member deadlocks 149-S rather than permitting a partial close, and backlogit 1.8.0 offers no shipment `blocked` status as an alternative.

**Replacement.** 141.001-T now has TWO terminal outcomes, both closing `done`: `VERDICT: PAIR-ISOLATED` or `VERDICT: INCONCLUSIVE` (narrowed candidate set is the deliverable). No member of this feature can ever end `blocked`. The "no speculative fix" guarantee is preserved STRUCTURALLY rather than by task status: there is no remediation work inside 149-S to slip into, and the successor task 143.002-T forbids any source edit that does not cite a recorded minimal reproducing pair.
