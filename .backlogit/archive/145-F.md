## Defect (as recorded by 141.004-T)

A genuine, pre-existing, **intra-file** test-order pollution exists in `tests/test_gates_topology.py`. Victim #2, `FilesystemTopologyReadersTests.test_empty_queue_and_archive_dirs_pass_as_zero_shipments` (line 112), fails when the file runs **standalone** (94 tests, no other file involved) if any one of these five `BranchOwnershipTests` tests runs first:

- `test_ci_mode_detached_head_resolves_via_github_head_ref` (line 994)
- `test_ci_mode_detached_head_resolves_via_github_ref_name_for_push` (line 1017)
- `test_ci_mode_push_branch_name_with_slash_is_accepted` (line 1038)
- `test_ci_mode_tag_push_does_not_resolve_as_branch` (line 1062)
- `test_ci_mode_detached_head_with_no_env_fallback_still_blocks` (line 1085)

Reproduces identically against the completely unmodified original file. None of the five uses `tempfile`. `141.004-T` recorded no `GIT_CONFIG_*` connection and classified this as a SEPARATE, distinct, unexplained mechanism.

## Why this is a separate feature

The operator directive is explicit: the ambient `GIT_CONFIG_*` mechanism and the `BranchOwnershipTests` intra-file order mechanism must be kept separate, with granular tasks/dependencies or multiple ordered shipments, and must not be conflated. This feature exists to honour that separation.

## Recorded prediction (NOT an assumption)

The deliberation records a falsifiable prediction that mechanism B is a **symptom** of mechanism A: `unittest` sorts classes via `dir(module)` so `BranchOwnershipTests` (B) always precedes `FilesystemTopologyReadersTests` (F) in-file; all five named polluters are `patch.dict('os.environ', ...)` sites, i.e. exactly mechanism A's destruction trigger; and victim #2 reaches git through `src/autoharness/gates/topology.py:200` `_run_git`, whose `check=False` -> `""` swallow launders a git config-parse failure into `detached_head` -> `BRANCH_MISMATCH` -> `exit_code == 1`, which is precisely why B looked unrelated.

The prediction is **never** used to close this feature. `145.001-T` must measure it, and A10 requires a reverted-checkout negative control before `SUBSUMED` may be recorded.

Without the negative control the disposition is `INCONCLUSIVE-VACUOUS` and `145.002-T` proceeds as if `SURVIVES`.
