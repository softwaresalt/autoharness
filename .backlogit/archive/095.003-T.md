<!-- BEGIN:description -->
Add a bounded retention window with a restated, achievable size bound, preserving the sink best-effort concurrent-writer contract. Keep at most _MAX_RETAINED_SEGMENTS (module constant, >=1) SEALED segments; on rollover, prune the oldest sealed generation(s) beyond the window. Pruning removes ONLY sealed segments beyond the window: it NEVER targets the active segment, and never a segment sealed within the current rollover critical section. Pruning is by-design lossy on the MIRROR only -- SQLite retains authoritative history, so pruning never deletes authoritative data; a prune racing a late append into a to-be-pruned sealed segment only drops best-effort mirror lines already superseded by SQLite (acceptable under contract). Prune oldest-first. Replay/conflict checks scan only still-retained segments. Restated byte bound (finding 5): a sealed segment is <= _MAX_SEGMENT_BYTES + one max record (the size check runs before an append; a benign concurrent duplicate is itself <= one max record and is superseded on read); total retained <= (_MAX_RETAINED_SEGMENTS + 1) * (_MAX_SEGMENT_BYTES + one max record). Explicitly document + test the retention horizon: once the segment carrying an epoch_id is pruned, a later replay of that epoch_id can no longer be detected on the mirror and is re-appended (acceptable -- JSONL is a best-effort mirror; SQLite is authoritative). Depends on 095.002-T. Files: src/autoharness/telemetry/jsonl_sink.py, tests/test_telemetry_jsonl_sink.py. <=3 files, <=5 functions, <=4 test scenarios. TDD.
<!-- END:description -->

<!-- BEGIN:acceptance-criteria -->
The sealed-segment count never exceeds _MAX_RETAINED_SEGMENTS and the oldest sealed generation is pruned first. Pruning never targets the active segment. Idempotent-replay and conflict detection still hold across all still-retained segments. The retention-horizon bound is asserted: an epoch whose mirror segment has been pruned is re-appended (no false idempotency), not raised; SQLite remains authoritative. Existing tests still pass.
