- Module constants DISPOSITION_MARKER = "Copilot-Review-Body-Disposition:" and KNOWN_OVERVIEW_VERSION = 2 are exported.
- New tests/test_gates_copilot_review_body.py with 3 table-driven scenario groups (subTest): (1) ccr-overview-v2 bodies - PR #506 round 2 -> count 1, markers ('previously_missed',); round 1 (1 anchored open finding) -> 0; round 6 clean -> 0; synthetic 2 anchored open findings with one nested <details><summary><picture> -> 0; (2) PR #444 legacy 'Suppressed comments (5)' + nested 'Previously missed (2)' -> 5; synthetic '**2 open findings**' with no list -> 2 (unanchored_open); (3) '<!-- ccr-overview-v3 -->' -> overview_version 3; no markers -> count 0 / None; '' -> 0.
- Canonical suite green: $env:PYTHONPATH='src'; python -m unittest discover -s tests.
