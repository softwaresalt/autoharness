<!-- BEGIN:description -->
Goal: the single read-only evidence contract and validator used by the A4/A4b gate and the shipment_close command. Disposition and set-term rules are split to A1c (cycle-1 R4).
Files: src/autoharness/gates/cascade_evidence.py (new), tests/test_cascade_evidence_contract.py (new).
Key rules:
- EVIDENCE_SCHEMA_VERSION = 1; build_evidence_path(workspace_root, S, F) -> docs/closure/evidence/{S}-{F}-close-evidence.json via closure_contract.validate_closure_id and assert_path_within_workspace.
- validate_evidence_record(record, *, shipment_id, feature_id, close_path: Literal["cascade","safe_close"]) -> list[str] is the single validator; close_path is the SELECTED close path, not the classifier verdict.
- Selection consistency (R1/R2, D4a): rebuild EngineSemanticsDecision via shipment_closure.assess_cascade_engine_semantics over the recorded raw engine_semantics inputs (verdict/reason/minor_line must match; a hand-edited VERIFIED fails); rebuild ClosePathDecision from classifier_verdict/classifier_reason; select_close_path(classifier, engine) must equal close_path_selection.{selected_close_path, reason}; invocation_surface must be "cli".
- Sanitized inputs, unredacted outputs (R6): assert redact(x)[0] == x (the text element of the (text, redaction_applied) tuple, never the tuple itself; Copilot PR #481 T1) for engine_semantics.probed_version, probed_commit, reason and close_path_selection.reason (each when non-null); these four are never redacted.
- Path rules (R12): every record path field (observation_set[].path, dispositions[].path, dispositions[].records[].path, read_failures[].path) is a relative POSIX path whose first segment is .backlog or .backlogit (one root per record), no '..', no leading / or \, no drive or UNC prefix; textual check runs before any read. path: null only on a retained_read_error disposition, a read_failures[] entry, or an observation_set entry with location: missing (C2-2).
- redact(text) -> tuple[str, bool] is defined HERE (R6), not in shipment_close/, because the validator needs it and the gate never imports the command package; A1b StreamCapture and every free-text redaction call it. Full pattern set (plan A1b Redaction, owned here): (a) bearer or basic Authorization values; (b) credential pairs over one shared, case-insensitive key set - token, password, secret, api_key, apikey, access_token, refresh_token, client_secret - matched both as key=value AND as a quoted JSON key with a ':' separator and optional whitespace ("token": "...", "api_key":"..."; the quoted value is redacted through its closing quote and the key is kept, R17); (c) GitHub gh[pousr]_ and github_pat_ tokens; (d) sk- style keys. Returns the text and a redaction_applied flag.
- Record serialization codec (R8): the pure *_to_record / *_from_record pairs are owned by this module but are NOT implemented in this task (Copilot PR #481 T8 granularity split): declared_status_* and observation_entry_* are A1d (192.017-T), engine_semantics_* and close_path_selection_* are A1e (192.018-T), disposition_plan_* is A1f (192.019-T). This task implements exactly three public functions: build_evidence_path, validate_evidence_record, and redact (plus private validator helpers). Its validator reads the plain JSON record fields directly; A1d and A1e later route the well-typed and selection-consistency checks through their decoders.
- cascade requires phase post_close, selected_close_path cascade, classifier_verdict CASCADE, engine VERIFIED, postcondition_verdict pass AND internal consistency (exit_code 0, timed_out false, mutation_state completed, no parse_error, empty returned_ids/unexpected_archived/missing_required/linked_deliberation_drift/failures, parent_id_preserved, baseline_invariant, disposition_byte_identical, shipment_archived_shipped all true).
- safe_close requires phase pre_close, selected_close_path safe_close, and classifier SAFE_CLOSE OR (CASCADE with engine UNVERIFIED); CASCADE + VERIFIED on a safe_close record is rejected.
- Record shape per plan (tool{binary_path, binary_sha256, version_excerpt}; pre_close{classifier_verdict, classifier_reason, qualifying_feature_ids, engine_semantics{...}, close_path_selection{...}, shipment_record, manifest_members[], out_of_manifest_descendants[], linked_deliberation_disposition{dispositions[], unresolved_references[], read_failures[], planning_error}, observation_set[] (selected SAFE_CLOSE only), captured_at}; invocation{...}; post_close{... allowed_ids, required_ids (flat), linked_deliberation_drift[], disposition_byte_identical, ...}). The 1.10.x key pre_close.linked_deliberations is removed.
- Serialization: json.dumps(sort_keys=True, indent=2, ensure_ascii=False), LF, one trailing newline, ID lists sorted.
- CascadeEvidenceError is the single error type; this module defines NO exit codes (EXIT_* live in shipment_close/__init__.py, A1b/R15).
