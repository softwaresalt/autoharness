### Why A8 was withdrawn

A8 specified three steps in one shell: `before := probe`, `run the canonical gate`, `after := probe`. All three are **SIBLINGS** of the shell. The canonical gate runs in its OWN process and every mutation it makes dies with that process. The `after` probe is a fresh child of the SHELL, whose block the runner never touched. `before == after` was therefore **TRIVIALLY AND UNCONDITIONALLY TRUE on every platform, defect present or not** — it would have reported PASS against the un-fixed code. It measured nothing.

### A8R topology (three levels)

```text
L0 LAUNCHER  (the proof driver)
  env_block := dict(os.environ) | {"AUTOHARNESS_ENVPROBE_BLANK": "",
                                   "PYTHONPATH": "src"}
  spawn L1 with env=env_block      # explicit block is the ONLY way to establish
                                   # a blank-valued variable on Windows

L1 CONTROLLER  (long-lived; the suite runs HERE, IN-PROCESS)
  a. pre  := probe()               # L2 child, env=None
  b. PRECONDITION GATE: pre must contain AUTOHARNESS_ENVPROBE_BLANK and every
     GIT_CONFIG_COUNT / GIT_CONFIG_KEY_n / GIT_CONFIG_VALUE_n L0 passed in.
     If not -> emit {"status":"INVALID_PRECONDITION"} and exit -> HALT at L0.
     Neither a pass nor a fail: the measurement apparatus is invalid.
  c. prog = unittest.main(module=None,
                          argv=["python -m unittest", "discover", "-s", "tests"],
                          exit=False)
     -> literally the code path `python -m unittest discover -s tests` takes,
        so discovery, ordering and execution are identical.
        Counts are read PROGRAMMATICALLY from prog.result (never by scraping
        stderr, which is where unittest writes its summary).
  d. post := probe()               # L2 child, env=None
  e. emit {"status":"OK","pre":...,"post":...,
           "testsRun":...,"failures":...,"errors":...,"skipped":[...]}

L2 PROBE  (child of L1; env=None -> inherits L1's REAL block)
  python -c "import os,json,sys; sys.stdout.write(json.dumps(dict(os.environ), sort_keys=True))"
```

Because the probes are **L1's own children**, L1's post-suite block is what gets measured — which is exactly what the sibling topology could never see.

SEPARATE from (2) because a whole-block comparison is satisfied by two blocks that are BOTH missing the variable.
