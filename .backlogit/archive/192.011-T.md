Goal: the disposition and set-term half of the A1 validator (re-plan R5, D2, D3a), split from A1 by cycle-1 R4.
Files: src/autoharness/gates/cascade_evidence.py (extended), tests/test_cascade_evidence_disposition.py (new).
Key rules (private helpers called by validate_evidence_record):
- Disposition: pre_close.linked_deliberation_disposition present on both paths; planning_error must be null.
- Pre-mutation outcomes only (R13): "archive" (shipment_closure.PLANNED_ARCHIVE), "already-archived", or one of retained_read_error, retained_ambiguous, retained_engine_unverified, retained_live_status, retained_shared_reference, retained_description_mention. "archived" (LinkedDeliberationOutcome.ARCHIVED) and any other value are rejected (the command never archives).
- reason_code: non-empty string; unknown codes accepted. retained_* never halts by itself.
- Engine/outcome consistency both ways (D3a, R13): under UNVERIFIED only retained_read_error, retained_ambiguous, already-archived, retained_engine_unverified are allowed; under VERIFIED retained_engine_unverified is rejected.
- No linked-deliberation set terms (D2): a recorded allowed_ids or required_ids containing a disposition-set deliberation ID is rejected (H10 explicit members are not in the disposition set).
- Observation set (R2; C2-1): an observation_set entry whose ID is in the disposition snapshot is rejected, EXCEPT on a safe_close record with UNVERIFIED engine, where the set must contain exactly one entry per records[] path of every non-already-archived disposition with matching ID, path and sha256 (missing, extra, or mismatched rejected).
