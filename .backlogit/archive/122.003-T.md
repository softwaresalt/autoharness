title: Implement fair local and remote input multiplexing with metadata audit
updated_at: 2026-08-14T23:46:43.1888095Z
---

Replace direct competing writes to the active child with a broker-owned input multiplexer that accepts local console lines and remote control requests, assigns sequence/order metadata, prevents one source from starving the other, rejects stale/duplicate requests, and hands off safely across child restart. Preserve metadata-only audit for operator text and never persist raw input.

<!-- BEGIN:acceptance-criteria -->
Local-only input works with remote disabled; remote-only input works; interleaved local/remote input preserves a documented ordering/fairness rule; duplicate/stale requests are rejected or replay-safe; writes are serialized across PTY/ACP adapters and child restart; raw operator text is absent from journal/audit; queue overflow and unavailable child produce typed backpressure/unavailable results; concurrency tests cover simultaneous local and remote submissions.
<!-- END:acceptance-criteria -->

<!-- BEGIN:description -->
Arbitration must be deterministic and bounded; it must not put local execution behind a network consumer.
<!-- END:description -->

<!-- BEGIN:implementation-notes -->
Single active workspace/session remains enforced. Do not add raw keystream/browser-terminal behavior.
<!-- END:implementation-notes -->
