<!-- BEGIN:description -->
Goal: compute the path-keyed safe-close observation set that A2 records for a selected SAFE_CLOSE and A4b re-checks. Split from A2 by cycle-1 R4.
Files: src/autoharness/shipment_close/observation.py (new), tests/test_shipment_close_observation.py (new).
Key rules:
- compute_observation_set(manifest_items, shipment_id, backlog_dir, *, excluded_ids, deliberation_records=()) -> tuple[ObservationEntry, ...], read-only; one entry per record path with workspace-relative path, location (queue/archive), SHA-256, declared status, each encoded via A1 observation_entry_to_record (R8). Union of: parent feature of each manifest task plus every unshipped sibling task; every out-of-manifest descendant of each manifest feature member (classifier traversal _scan_backlog / _enumerate_descendants); entries built from deliberation_records.
- Private helpers _scan_backlog, _enumerate_descendants, _read_artifact_record imported lazily inside compute_observation_set (C2-4).
- Per-ID resolution (C2-2) with _read_artifact_record (queue/ and archive/, frontmatter id match): no match -> location: missing, path/sha256/declared_status null, no raise; one match -> fingerprinted; >1 match (torn), BacklogUnavailableError, None traversal scan, or an un-fingerprintable path -> CascadeEvidenceError (A2 maps to exit 2, no record).
- Closure-scope exclusion (R11): every ID in closure_scope(S) = items(S) ∪ {S} (computed locally as A3b computes allowed_ids) is excluded (e.g. the covering feature in a whole-feature manifest).
- excluded_ids (from A2: every disposition-snapshot ID) is removed from traversal entries, so under a VERIFIED engine the set holds no disposition-set deliberation (R2).
- UNVERIFIED engine (C2-1): A2 passes as deliberation_records every records[] entry of each non-already-archived disposition; each becomes an entry with the deliberation ID, the snapshot's path and sha256, location from the path's queue/ or archive/ segment, and snapshot declared_status - copied, never re-read. retained_read_error has no records[] entry and is not included. Under VERIFIED, A2 passes nothing.
