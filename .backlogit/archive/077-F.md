<!-- BEGIN:description -->
> **STATUS: ABANDONED - 2026-08-16 (explicit operator decision).** This feature was terminated without implementation and is retained for historical traceability only. It carries terminal status `rejected`, because backlogit exposes no `abandoned` status for `feature` artifacts (`abandoned` is shipment-only), and `done`/`accepted` would falsely imply the scope was completed.
>
> **Why it was abandoned:** the remaining 077-F scope was predicated on an `autoharness run` command protocol serving as the indirection layer for MCP launcher invocation. Efforts to create that `autoharness run` protocol completely failed to allow proper use of the CLI interface. With that premise gone, consolidating the `github` server target, removing the `pwsh` wrappers, `tavily` env-forwarding, and exact-version pinning behind a single launcher strategy is no longer viable. The operator judged the feature dead rather than merely deferred: this is an abandonment, not an unblock-and-deprioritize, and 077-F should not be resurrected as-is.
>
> **NOT abandoned - 087-F remains DONE and fully in force:** the bunx/runtime and `.mcp.json` tracking decisions delivered under 087-F (`bunx-mcp-runtime-consolidation`) are complete, still authoritative, and explicitly survive this abandonment. The workspace-root `.mcp.json` stays tracked, and JS-engine MCP launchers stay on bunx. Nothing in this abandonment reverts, supersedes, weakens, or calls into question any 087-F decision or its tasks (087.001-T, 087.002-T, 087.003-T). Any reader of this archived artifact must treat 087-F as completed work, not as collateral of this abandonment.
>
> **Residual open items - deliberately dropped, NOT transferred:** the `github` server target ratification, `pwsh` wrapper removal, `tavily` env-forwarding, and exact-version pinning remain unresolved and are intentionally not carried into another feature or shipment. If launcher indirection is ever revisited, open a new feature from scratch. The prior research in `docs/decisions/2026-07-12-mcp-launcher-consolidation-deliberation.md` is preserved and remains readable for that future effort.
