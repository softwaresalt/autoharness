SIZE: M. COMPLEXITY: medium. (Two independent axes; also emitted as structured backlog fields.) Shipment 2 (P0). Create src/autoharness/supervise/process.py defining the ChildProcess Protocol (spawn / read / write / signal / wait / close) plus TWO stdlib-subprocess implementations. F29 RULING - TERMINAL ATTACHMENT IS THE CONTRACT BEING MIGRATED: InheritStdioChildProcess is the DEFAULT for interactive launches and passes the parent's stdin/stdout/stderr handles through UNCHANGED, exactly reproducing today's behavior (start.sh execs the resolved exe so the child replaces the shell and stays on the terminal; start.ps1 inherits handles). PipeChildProcess is RETAINED but is NOT the interactive default - it backs tests and explicitly non-interactive invocations only, and is NEVER silently substituted for an interactive session, because redirected stdio is non-TTY and changes prompt rendering, input handling, colour and buffering. Copilot CLI is an interactive TUI, so that substitution would be exactly the observable behavior change Shipments 1 and 2 forbid. Output journaling is NOT obtained by giving up terminal attachment: see 119.002-T for PTY capture and 119.005-T for the declared degradation. H4: ARGV-ARRAY SPAWN ONLY - shell=True is prohibited and asserted against in tests; no path or argument is ever interpolated into a command string. Operator passthrough arguments are forwarded VERBATIM as a list and never re-parsed, re-quoted, joined, or filtered. H3: EXIT-STATUS FIDELITY IS A HARD INVARIANT - the child's exit code propagates unmodified through wait(); no masking, no remapping of a non-zero child exit into a supervisor-level status, no inference of success from non-empty output. Includes a scripted FAKE child implementation of the same Protocol so the entire state machine, journal, cancellation and restart paths can be tested deterministically without Copilot. Tests: argv fidelity, no-shell assertion, exit-code round-trip over {0,1,2,42,130}, stream capture on the pipe backend, signal/terminate, reaping without zombies, and TTY-ATTACHMENT FIDELITY on the default backend - a child launched through InheritStdioChildProcess must report an interactive terminal from its OWN isatty() call, which is the assertion the T1/T2 characterization baselines were missing.
