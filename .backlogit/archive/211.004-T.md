Plan unit T3 (hardening H3, H6). New src/autoharness/shipment_close/liveness.py: provably_dead(host, pid, pid_start) and process start-time lookup. Windows via ctypes OpenProcess/GetExitCodeProcess(STILL_ACTIVE)/GetProcessTimes ONLY (never os.kill(pid, 0): signal 0 is CTRL_C_EVENT on Windows); POSIX via os.kill(pid, 0) plus /proc/<pid>/stat start time. Rules: same host required; pid absent => dead; pid present with differing recorded pid_start => dead (reuse); pid present and start equal or unrecorded => NOT dead; any error/unknown/foreign host/legacy lock => not provably dead. Injectable seams; test asserts os.kill never called on nt. Gate: PYTHONPATH=src python -m unittest discover -s tests.
