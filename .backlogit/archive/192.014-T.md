<!-- BEGIN:description -->
Goal: detect engine drift on disposition-set deliberations at close time (re-plan item 4, R4; 038-DL D2). Authoritative drift check; the A4b gate does not re-check disposition-set deliberations under a VERIFIED engine (H-C2). Split from A3b by cycle-1 R4.
Files: src/autoharness/shipment_close/postclose.py (extended), tests/test_shipment_close_deliberation_drift.py (new).
Key rules:
- evaluate_linked_deliberation_drift(snapshot, archived_ids, recollected) -> tuple[DriftEntry, ...] is pure; each entry {deliberation_id, kind, detail}:
  - archived: a disposition-set deliberation ID in archived_ids (also fails A3b unexpected-artifact);
  - modified: SHA-256 of any records[] path differs, or the path moved -> disposition_byte_identical false;
  - snapshot_drift: re-collected snapshot differs in deliberation IDs, link kinds, linking members, declared status, record paths, SHA-256, unresolved references, or read_failures ({path, reason_code}); the planned outcome is compared only when either side is a settled outcome (retained_read_error, retained_ambiguous, already-archived), and for retained_read_error its path and reason_code too (R10). Any other outcome change (e.g. archive <-> retained_shared_reference from a live referrer) is NOT drift (C2-3);
  - planning_error: re-collection returned a non-null planning_error -> drift, never a skipped comparison (R10).
- Re-collected plan encoded with A1 disposition_plan_to_record; comparisons always between encodings (R8).
- Any drift entry -> postcondition_verdict fail (exit 5 in A3); retained_* outcomes are never drift by themselves.
