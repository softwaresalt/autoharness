Extend the reader read-path so rotated history survives reads (finding 3). Today reader.py::_read_jsonl opens only config.jsonl_path (the active segment), so after any rollover the source="jsonl" path (and the jsonl half of source="combined") silently returns only the fresh active segment and loses rotated history. Change _read_jsonl (and its source wiring in read_epoch_records) to enumerate active + retained sealed segments via the SHARED segment enumeration exposed by jsonl_sink.py, reading them in order and feeding all records through the existing _dedupe/_combine precedence and malformed-line skipping. The public read contract is unchanged except that it now correctly spans retained segments. Depends on 095.003-T (so real rotated + pruned segments exist to exercise). Files: src/autoharness/telemetry/reader.py, tests/test_telemetry_reader.py (sibling reader test module; import enumeration from jsonl_sink). <=3 files, <=5 functions, <=4 test scenarios. TDD.
