title: Expose stable versioned API and discovery over the session broker

Create a stable external API adapter over the broker with named operations, version negotiation, request/response schemas, capability discovery, error taxonomy, and cursor update endpoints. Gradio callbacks must call this adapter as presentation/API transport and must not become the session protocol. Preserve authenticated Dev Tunnel reachability, application envelope validation, loopback-only bind, and optional Gradio dependency.

<!-- BEGIN:acceptance-criteria -->
Discovery returns a stable API version, named operations, schemas, authority tiers, capability availability, update mechanism, and prerequisite status; named Gradio/API operations map one-to-one to broker operations; malformed/unknown/version-mismatch/auth/account-mismatch requests fail closed; Plan 2 V1 clients remain compatible or receive an explicit versioned migration error; no lambda-only unnamed contract remains relied upon.
<!-- END:acceptance-criteria -->

<!-- BEGIN:description -->
Stable API identity and discovery are required even if the first presentation remains Gradio.
<!-- END:description -->

<!-- BEGIN:implementation-notes -->
Do not add a native autoharness MCP server. HTTP/Gradio is an adapter; the broker remains authoritative.
<!-- END:implementation-notes -->
