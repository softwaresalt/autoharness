Goal: parse the backlogit ship response and evaluate INV-10 over the flat 1.11.x sets. Linked-deliberation drift moved to A3c (cycle-1 R4).
Files: src/autoharness/shipment_close/postclose.py (new), tests/test_shipment_close_postconditions.py (new).
Key rules:
- parse_ship_response(stdout_bytes) -> ParsedResult | ParseError parses the JSON-RPC 2.0 envelope from stdout only. Characterize first: record backlogit --jsonrpc shipment ship --help and a canned envelope captured from a scratch fixture workspace; commit both as test fixtures.
- evaluate_postconditions(snapshot, parsed, reread) -> PostCloseResult is pure (no I/O); reread (from A3) holds the post-close shipment record, every fingerprinted file, and the re-collected disposition snapshot (evaluated by A3c).
- Flat sets (R4; 038-DL D2), from the pre-close snapshot only (INV-P2), over every manifest item regardless of artifact_type: allowed_ids = items(S) ∪ {S} (closure_scope(S)); required_ids = {S} ∪ qualifying_feature_ids ∪ {x in items(S): pre-close declared status is not exactly the str "archived"} (decoded with A1 declared_status_from_record, R8). No linked-deliberation term in either set; H10 explicit-member deliberations are ordinary allowed_ids members. Production code does not import _closure_scope_ids.
- INV-10: returned_ids == []; unexpected-artifact and missing-required checks labelled and failing independently (INV-P3); parent_id preserved for every manifest member incl. archived tasks (AS-F10); byte-identical baseline invariance outside allowed_ids; re-read shipment declares status: archived and archived_status: shipped (AS-F04).
- linked_deliberation_drift[] and disposition_byte_identical come from A3c and are merged into PostCloseResult; any drift entry -> postcondition_verdict fail.
- mutation_state: completed for a parsed success envelope; none only when every fingerprint is unchanged and no fingerprinted ID gained an archive-location file; else indeterminate. A timeout or non-zero exit is never "no mutation".
