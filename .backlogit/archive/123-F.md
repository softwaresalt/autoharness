Second implementation shipment for Plan 3, blocked by S1. Wire the broker foundation to real native PTY and ACP runtime controls without treating the protocols as interchangeable. Native PTY supports only an explicit allowlisted mapping for slash-command-equivalent controls and preserves interactive behavior where the backend supports it. ACP uses typed ACP messages and capability negotiation for model selection, permission/yolo requests, MCP status, prompts, approvals, and agent requests; unsupported capabilities return typed unavailable/degraded outcomes. Add restart handoff and cursor-based live updates so remote operators do not repeatedly press Tail and local execution never waits on a network consumer.
