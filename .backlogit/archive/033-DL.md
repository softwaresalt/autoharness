Stage deliberation resolving stash DDBF283E and EB23D1B9. DDBF283E: the Step 0(c) pre-mutation evidence mechanism planned for 163.004-T proves pre-existence with fields the agent itself writes (collection_completed_at, HEAD SHA, manifest list), so a byte-identical post-hoc reconstruction that backdates the timestamp satisfies every clause of the check — a gate no illegitimate state can fail, the dual of the 15A02E21 gate no legitimate state could satisfy. EB23D1B9: that prerequisite is not encoded in 171-S's claim-eligibility graph, which blocks only on 169-S. DECIDED: adopt an engine-written append-only ordering proof (O4). Step 0(c) appends a PRECASCADE_EVIDENCE_ANCHOR event carrying the evidence record's sha256 to .backlogit/logs/{shipment_id}.jsonl via backlogit's append operation; the engine — not the agent — writes the timestamp, actor, and append position, and the cascade mutation later appends its own shipment_status_changed/commit_tracked/archived events to the same file, so ordering is proved by relative append position in an engine-owned file. Verified against live data: engine authorship confirmed in 150-S/151-S/152-S logs; logs survive archival ON THE LOCAL FILESYSTEM so the proof outlives the mutation it proves for a reviewer working in the closing workspace; and .backlogit/logs/159-S.jsonl demonstrably contains no anchor before archived, making the real failure case mechanically detectable. collection_completed_at is demoted to corroborating metadata. Four separately labelled, independently failing halt tokens (EVIDENCE_MISSING, EVIDENCE_STALE, ANCHOR_MISSING, ANCHOR_NOT_PRE_MUTATION). Rejected: RFC 3161 external timestamps (injects a network dependency into a fail-closed irreversible close path, converting an integrity control into an availability outage); git-commit ancestry as primary (would make the gate unsatisfiable in legitimate states — the 15A02E21 mistake — retained as an optional corroborating field); skill-maintained hash chain (agent owns the chain, self-reported at one remove). CONTAINMENT: revise 171-S in place rather than create a predecessor shipment, because a predecessor would edit the identical Step 0(c) paragraphs 171-S's U2 edits, adding a third contender to a region already contended by 169-S and reproducing the two-independent-restatements drift that produced 15A02E21. No Python source change; no new units; no change to 169-S/161-F or 170-S/162-F scope; 856B6770 disposition untouched; no retroactive-compliance claim for 159-S. Revises plan U1a/U1b/U1c/U2/U3 and tasks 163.001-T, 163.002-T, 163.003-T, 163.004-T, 163.005-T. Threat model stated explicitly: the target is tamper-EVIDENT and out-of-protocol, not tamper-proof — no purely local mechanism resists an operator with shell access, and the design goal is to make the reconstruction path unreachable through the agent's normal tool surface. AMENDMENT D-7 / R1-11 (2026-09-10, review-fix cycle 1) — DURABILITY SPLIT. The O4 durability claim was scoped wrong, not wrong in mechanism: .backlogit/logs/ is covered by a workspace .gitignore rule, so the anchor is durable and auditable LOCALLY but invisible to a fresh-clone reviewer. Two layers are now named separately and neither substitutes for the other. L1 LOCAL RUNTIME ORDERING PROOF (gate-bearing): the anchor event in the engine-owned log, read inside the existing lock before the cascade invocation — all four halt tokens evaluate L1 and only L1, unchanged. L2 REPOSITORY AUDIT EVIDENCE (never gate-bearing): at the closure commit, commit the evidence record AND that shipment's own engine log, force-added past the ignore rule, verbatim and byte-unmodified — the engine's own bytes, never an agent-written transcription, so no agent-authored field becomes load-bearing. Bounded to one shipment at its own closure; not a general un-ignoring of .backlogit/logs/, not a historical backfill, not a .gitignore change. A fifth halt token for L2 was CONSIDERED AND REJECTED as an unsatisfiable gate on an artifact that cannot exist until after the close; instead OPERATIONAL CLOSURE IS INCOMPLETE UNTIL L2 IS COMMITTED (a reportable P-001 condition). A missing L2 never authorizes a close, never downgrades a halt, and is never a fallback. Propagated to plan section R1-11 and to 163-F, 163.003-T, 163.004-T, 163.005-T, 163.006-T.
