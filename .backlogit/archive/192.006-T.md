<!-- BEGIN:description -->
Goal: run_cascade_close orchestration under the A1b pair lock. CLI wiring and --json rendering moved to A3d (cycle-1 R4).
Files: src/autoharness/shipment_close/command.py (new), tests/test_shipment_cascade_close_invoke.py (new).
Key rules (steps, all under the lock):
1. Acquire lock + existing-record check (exit 7 or 2) before any classification.
2. Validate --message/--author: non-empty, no NUL/newline, <= 1,024 chars; else exit 2.
3. run_preclose (A2a probe + select_close_path). No prior cascade-selected record: selected path not CASCADE (classifier SAFE_CLOSE, or CASCADE x UNVERIFIED) -> write pre_close verdict record, exit 3, invoke nothing (engine gate fails closed, R3/D4a). A cascade-selected --classify-only record exists (R1): compare classifier verdict/reason/qualifying set, engine probe (verdict, reason, raw probed_version, raw probed_commit, probe_surface, invocation_surface, re-hashed tool.binary_sha256), selection, and disposition snapshot as A1 *_to_record encodings; ANY difference (incl. fresh SAFE_CLOSE) -> exit 4, record byte-identical, never a safe_close record, never SAFE_CLOSE substitution (INV-P4).
4. Write pre_close. Over a matched cascade record this is a re-stamp of only run_id and captured_at, made ONLY after step 3's exact-match check passes, as an A1b pre_close takeover (Copilot PR #481 T6): write_evidence_atomic(path, restamped, owner_run_id=<this run>, takeover_from_run_id=<run_id of the record the existing-record check returned>), after confirming the *_to_record encodings differ only in run_id and captured_at; the takeover binds the record to this run so steps 7 and 10 are ordinary owner transitions. Replacing a safe_close-selected record uses the same takeover. A refused takeover (on-disk record no longer matches the expected prior run_id or phase) -> exit 4, record byte-identical, nothing invoked; any other write failure -> exit 2.
5. Revalidate (AS-F02): recompute the entire snapshot (ignoring captured_at) incl. disposition snapshot; any difference -> exit 4. Engine re-probe (R3): re-run A2a through the same binary; compare raw probed_version, probed_commit, probe_surface and verdict by exact equality; any difference or re-probe failure -> exit 4, never SAFE_CLOSE.
6. Re-hash the resolved binary; mismatch with tool.binary_sha256 -> exit 4, nothing invoked (AN-F08).
7. Write owner-bound phase: invoking (run_id, argv_redacted, started_at); failure -> exit 2 (INV-P1, INV-P7).
8. Invoke via A3a: [<absolute binary>, "--no-update-check", "--jsonrpc", "--cwd", <workspace root>, "shipment", "ship", S, "--sha", X, "--message", M, "--author", A].
9. Re-read fingerprinted files and shipment record; re-collect the disposition snapshot with compute_linked_deliberation_disposition (pre-close manifest IDs + recorded pre-close engine decision); A3b parse_ship_response + evaluate_postconditions (+ A3c drift).
10. Write owner-bound post_close even when invocation/parse fails; failure -> exit 8.
- Spawns exactly two process kinds: the A2a probe (step 3 and step 5 re-probe) and shipment ship; no --version spawn (R7). Never archives, moves, or edits any artifact (038-DL D3a: the skill's disposition step is the only archiver).
- Exit table (EXIT_* from shipment_close/__init__.py, R15): 0 pass / classify-only CASCADE selected; 2 input, I/O, no-clobber, planning_error, pre-invocation write failure; 3 selected path not CASCADE, nothing invoked; 4 pre-invocation drift incl. engine re-probe difference/failure, binary hash change, or any difference from a cascade-selected --classify-only record; 5 postcondition failed incl. linked_deliberation_drift; 6 backlogit non-zero/timeout/unparsed; 7 existing lock or invoking record; 8 post-close write failed. Exits 5-8 forbid committing the backlog root, re-running, a direct ship call, or SAFE_CLOSE substitution until operator review.
- Returns frozen CascadeCloseOutcome (exit code, evidence path, phase written, fields A3d renders).
