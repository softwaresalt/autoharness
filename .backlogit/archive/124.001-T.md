Upgrade the presentation layer into a simple responsive remote operator console over the stable API. Show connection/account/workspace/session state, PTY versus ACP mode, capabilities and unavailable prerequisites, live status/output/journal updates, model and permission state, MCP status, control results, pending local approvals, agent requests, reconnect/handoff state, and clear failure messages. Preserve bounded rendering and safe redaction.

Presentation only: no direct child writes, shell execution, protocol parsing, or hidden reasoning display in UI code.
