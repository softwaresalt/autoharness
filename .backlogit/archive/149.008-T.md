<!-- BEGIN:acceptance-criteria -->
* `autoharness gate pre-review` runs; `--json` emits parseable JSON; `--base <ref>` is honored.
* `--help`/`-h` prints `GATE_USAGE` and returns without parsing.
* **OPTION-SAFE `--base` (D-12)**: the CLI calls the U8b resolver **before** any discovery call and passes **only the validated 40-char hex SHA** onward. Raw user ref text is **NEVER** interpolated into a `git diff` argument.
* **An unsafe or unresolvable `--base` is rejected with the invalid-input exit class (exit 2) and NO SIDE EFFECT** — no `git diff` invocation, no file written, no report emitted. Option-like values such as `--output=<path>` are rejected, not executed.
* **Exit codes: 0 always; 2 for invalid arguments (including an unsafe `--base`) OR invalid registry.** Nothing else.
* Exit mapping reads the canonical `status` field only (D-9); no alias is consulted.
* Degraded path synthesizes a literal payload and never fabricates a graph.
* The gate is **read-only** — it performs no backlogit or git mutation.
<!-- END:acceptance-criteria -->
