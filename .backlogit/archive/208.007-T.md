Plan docs/plans/2026-10-11-model-routing-catalog-bindings-plan.md unit B6a (RB2a; added by plan-review finding B-F1, P1; reshaped by PR #513 cycle 5, threads PRRT_kwDORzpWpM6rmyoO, PRRT_kwDORzpWpM6rmyoz, PRRT_kwDORzpWpM6rmypP). Files (2): src/autoharness/verify_workspace.py, tests/test_verify_workspace_site_composition.py (new). The render loop already composes per-artifact variables for role artifacts (_resolve_artifact_role + _compose_artifact_variables). Add the equivalent SITE OVERLAY as the SINGLE SHARED FUNCTION `_compose_site_route_variables(base_variables, model_routing, site_id, site_registry, *, config_authoritative, overrides)` (config_authoritative has NO default: every caller passes the C4b-computed authority, so the new function does not repeat the config_authoritative=True default of the older compose helpers, the residual stash 09DFC9F9 item 3 records; this unit leaves those helpers as they are) plus its companion `_expected_site_route`, both in verify_workspace.py next to _compose_artifact_variables (the module that already owns _render_template, the override layer _authoritative_route_variables/_context_tier_override_error, and both render seams; it cannot live in the pure model_routing.py, whose import allowlist excludes verify_workspace, nor in model_routing_sites.py, which must not import verify_workspace at module level). This unit DEFINES the two functions; B7 (208.009-T) CONSUMES them. Two explicit branches: BOUND (model_routing.bindings has an entry for agent:<id>; the artifact is at .github/agents/**/<id>.agent.md, site id the file stem, and its registered site is a managed site with a resolved default tier): overlay the artifact's four route variables (TIER_<N>_FAMILY, TIER_<N>_PROVIDER, TIER_<N>_REASONING_EFFORT, TIER_<N>_CONTEXT_TIER, N = the registry's default_tier) with the pure resolver's BOUND route, then let each of those four names that config.overrides sets to a valid value take the override (precedence mirrors the role overlay and _authoritative_route_variables; an invalid *_CONTEXT_TIER override is skipped as in the existing compose paths); THE OVERLAY ASSIGNS ALL FOUR VARIABLES UNCONDITIONALLY, EMPTY STRINGS INCLUDED, because skipping empty values would leave the base map's value (the agent's old template tier) in place and re-create at render time the cross-tier inheritance the bound branch forbids, so a bound tier that leaves model_provider empty renders model_provider: "". UNBOUND: the base map back unchanged (it already carries the site default tier's TIER_<N>_* with any explicit config.overrides), so every unbound artifact and every pipeline artifact (the same 'no resolved role means base map' constraint as the role overlay) renders byte-identically to before. Base map back unchanged also for: an artifact with no registered site; a workspace-authored agent (not a manifest artifact, no template render, default_tier=None); a managed site whose default tier is unresolved (SiteRegistry.unresolved: its template names no single tier to overlay, so B6 and B7 REJECT a binding on it (ROUTING_BINDING_UNRESOLVED_SITE) rather than let it pass unapplied); a bound site whose binding does not resolve (resolver error: B6 reports it, B7 fails it); and a non-authoritative config (manifest-first, as for the role overlay). `_expected_site_route` reads the four expected frontmatter values from the SAME composed map for a managed site (and from the resolver output alone for a bound workspace-authored site, which has no template and so no TIER_<N>_* variable an override could name). The overlay applies at BOTH seams that render an agent from a template: the staged render loop (manifest artifacts[], managed-rendered) and the in-memory community render in _fc_rendered_candidate (managed-community). A community agent is not in artifacts[], so the staged loop never renders it, and without the second seam the candidate behind a reinstall-community proposal would carry the tier default instead of the bound route (PR #513 thread PRRT_kwDORzpWpM6rmKbh). The site registry is built once per verify run and passed to both seams (not rebuilt per artifact). Without this unit a bound agent could never satisfy both the render-parity check and the B7 drift check. Test scenarios (table-driven over one fixture helper): (1) a bound managed-rendered agent renders with the binding's four values (staged seam); (2) a bound managed-community agent's in-memory candidate render carries the binding's values (second seam); (3) every unbound agent, community agents included, renders byte-identically to the pre-change render (invariant I9) and pipeline agents are unchanged; (4) CONFIG.OVERRIDES: an explicit TIER_<N>_<FIELD> override on a bound agent wins for that variable while the other three come from the binding (overrides are keyed to the variable names the agent's template renders, so an override keyed to the bound route's own tier variables TIER_<T>_*, T different from the agent's N, does not reach the agent), on an unbound agent the render is byte-identical to pre-change, an invalid TIER_<N>_CONTEXT_TIER override is skipped; (5) BOUND/UNBOUND BRANCH AT RENDER: a bound tier that leaves provider, effort or context_tier empty while the agent's template default tier supplies them renders model_provider: "", reasoning_effort: "", context_tier: "default", and the same agent unbound renders the default tier's values; (6) NO OVERLAY (base map, no exception): a managed site with an unresolved default tier, a non-authoritative config, a bound site whose binding does not resolve; (7) SINGLE-FUNCTION CONTRACT: in every fixture above _expected_site_route equals the four frontmatter values parsed back from the rendered bytes, and a source assertion shows both render seams and B7 call _compose_site_route_variables and verify_workspace.py has no other composition of a site's TIER_<N>_* variables; (8) REINSTALL REGRESSION: a bound resolvable community agent and a bound resolvable rendered agent reproduce the bound route (with and without an override) in the reinstall-community candidate and the staged render respectively; for a bound site with an unresolved default tier the candidate carries no binding and B6 rejects the config (cross-checked in 208.008-T's tests).
