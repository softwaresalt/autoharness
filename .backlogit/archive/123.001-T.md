Implement the native PTY control adapter over the S1 contract. Support only an explicit allowlisted mapping for slash-command-equivalent controls where the Copilot CLI accepts them, including model selection, permission/yolo mode, MCP status/show, and agent-request responses as supported by the runtime. Preserve interactive PTY behavior and translate Windows line endings only at the PTY boundary. Unsupported commands return capability_unavailable rather than being guessed or forwarded arbitrarily.

<!-- BEGIN:acceptance-criteria -->
PTY tests prove approved slash commands reach the interactive child with expected newline behavior; unsupported/unknown slash commands are rejected; model selection, permission/yolo, MCP status, and agent-request response controls report capability and outcome; yolo/permission broadening invokes local approval; local and remote input share the S1 multiplexer; no command permits arbitrary executable/argv/filesystem access; Windows and POSIX behavior are covered by fakes/targeted tests.
<!-- END:acceptance-criteria -->

<!-- BEGIN:description -->
This is the native PTY path, not an ACP implementation and not a shell endpoint.
<!-- END:description -->

<!-- BEGIN:implementation-notes -->
Do not expose private model chain-of-thought. Keep command names and arguments bounded and allowlisted.
