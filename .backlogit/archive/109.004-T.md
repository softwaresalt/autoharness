<!-- BEGIN:description -->
[Shipment A / core] Implement the queue/dependency + prior-closure readiness check against the explicit target shipment supplied via `--shipment` (carried on the gate domain-input). For every blocking predecessor and the immediately-prior shipment, require BOTH (a) live status `shipped` OR archived provenance `archived_status: shipped|done`, and (b) complete required closure evidence including P-020 post-merge context compaction. Generic `archived`, non-shipped provenance, missing provenance, `abandoned`, or incomplete closure blocks fail-closed. In agent scoped mode a missing target is INVALID (exit 2); in hook/ci ambient mode with no resolvable target the readiness check is skipped while ambient invariants remain enforced. Uses the injected backlogit-state/closure-evidence reader.
