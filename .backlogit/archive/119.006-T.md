SIZE: M. COMPLEXITY: high. (Two independent axes; also emitted as structured backlog fields.) Shipment 2 (P0). Create src/autoharness/supervise/recovery.py: cancellation, controlled restart, and resume. CANCELLATION: operator cancel is LEGAL FROM EVERY POST-LOCKING PHASE (F18/F23 ruling) and always drives <phase> -> CANCELLING -> DRAINING -> CANCELLED, terminating the child if one exists, flushing the journal, and releasing the lock. CANCELLED IS A DISTINCT FOURTH TERMINAL STATE (operator ruling, 2026-08-12; terminal set is exactly {EXITED, FAILED, REFUSED, CANCELLED}), NOT EXITED: cancellation MUST remain distinguishable from normal completion in the terminal state itself. THIS SUPERSEDES the earlier "-> EXITED" wording of this task, which contradicted the plan diagram and outcome table. DRAINING REMAINS THE SOLE GATEWAY: CANCELLED is entered ONLY AFTER child termination, journal flush and lock release have COMPLETED inside DRAINING, and there is NO CANCELLING -> CANCELLED edge - attempting one is ILLEGAL_TRANSITION per 119.003-T. Because cancel is legal from LAUNCHING, the 'cancel during launch' case below is now SATISFIABLE against the 119.003-T table instead of describing an illegal transition. RESTART: the budget DEFAULTS TO 0 (opt-in via --max-restarts N) with a hard ceiling and exponential backoff; a restart requires BOTH remaining budget AND explicit operator confirmation, and every restart is journaled with its reason. Budget exhaustion drains to a terminal state and NEVER loops (H2). RESUME: resume-from-cursor reads the 119.005-T journal cursor only; it never reads or writes a backlogit checkpoint (H6). H8 DE-RISKING: the state machine and journal are already-fixed contracts, and because the budget defaults to 0 the DEFAULT path is simply cancel-and-drain, so the complex restart path is opt-in and separately testable against the scripted fake child from 119.001-T. Tests use the fake child exclusively: cancel during launch (LAUNCHING -> CANCELLING -> DRAINING -> CANCELLED), cancel during bootstrap, preflight and resolve, cancel during run, restart with budget, restart declined by operator, budget exhaustion, backoff timing, and resume after simulated crash. EVERY CANCELLATION TEST ASSERTS THE TERMINAL STATE IS CANCELLED AND NOT EXITED, and is paired with a normal-completion test asserting EXITED, with the two terminal values asserted to DIFFER - so a regression that conflates cancellation with normal exit fails rather than passing silently. A NEGATIVE-CONTROL TEST asserts that the direct CANCELLING -> CANCELLED transition is absent from the 119.003-T table and raises ILLEGAL_TRANSITION, proving no cancellation path bypasses DRAINING; the drain side effects (child reaped, journal flushed, lock released) are asserted to have ALREADY occurred at the point CANCELLED is observed. EVERY cancellation and failure test additionally asserts that the workspace lock was RELEASED EXACTLY ONCE (F22), so no path can strand it.
