Surfaces: .autoharness/backlog-registry.yaml (create_checkpoint block, ~line 108) and the registry template backlog/registries/backlogit.registry.yaml. The create_checkpoint operation declares only mcp_tool: backlogit_create_checkpoint with NO cli_command, unlike its sibling list_checkpoints which declares cli_command: "backlogit checkpoint list". In MCP-degraded mode an agent therefore has no declared official fallback for creating a checkpoint - the exact condition that invites hand-written JSON and reproduces this bug. Add cli_command: "backlogit checkpoint create" to the create_checkpoint operation. Per hardening H6 update BOTH the installed registry and the registry template together: installed-only drifts and is reverted by reinstall, template-only leaves this repository's own degraded-mode path uncovered before 138-S. Note the registry template is manifest-tracked (checksum at manifest line ~112), so changing its bytes requires a checksum refresh - which is why this task MUST precede the manifest checksum task 130.006-T. Independent of 130.001-T through 130.004-T and may be executed at any point before 130.006-T. Reference: docs/plans/2026-08-17-checkpoint-payload-contract-plan.md (T6).
