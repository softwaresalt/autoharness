<!-- BEGIN:description -->
Files: src/autoharness/frontmatter_contract.py (new), tests/test_frontmatter_contract.py (new).
- Key sets: TIER_KEYS = {max_subagent_tier, subagent_depth}; ROUTE_VALUE_KEYS = {model_family, model_provider, reasoning_effort} plus the review-route keys matching ^(anchor|alt)_review_(family|provider|reasoning_effort)$; ROUTING_KEYS = TIER_KEYS | ROUTE_VALUE_KEYS (AS-F6, AN-F5). The context-tier feature later adds context_tier to ROUTE_VALUE_KEYS only.
- Profiles computed at call time by agent_key_sets(profile) and skill_key_sets() (never stored module-level literals): tier-routed AGENT_REQUIRED = {name, description, max_subagent_tier, subagent_depth, model_family, model_provider, reasoning_effort}, AGENT_OPTIONAL = {id, maturity, tools, argument-hint, handoffs, target} plus the rest of ROUTE_VALUE_KEYS; plugin-global requires {name, description, max_subagent_tier, subagent_depth} and FORBIDS every ROUTE_VALUE_KEYS member (FM_FORBIDDEN_KEY); AGENT_FORBIDDEN = {model} for both; SKILL_REQUIRED = {name, description}, SKILL_OPTIONAL = {argument-hint, input, license, compatibility, metadata, allowed-tools}, SKILL_FORBIDDEN = ROUTING_KEYS | {model}. Skill name must be a string equal to the parent directory name matching ^[a-z0-9]+(-[a-z0-9]+)*$, at most 64 characters.
- parse_frontmatter(text, mode) (H-B6): strips a UTF-8 BOM, normalizes CRLF; first line exactly ---, closing delimiter is the first later line exactly --- (trailing whitespace allowed; ---- does not match); tolerates leading and interleaved # comment lines; duplicate-key-rejecting yaml.SafeLoader subclass (PY-F1); missing, unclosed, invalid, duplicate-key, non-mapping and undecodable frontmatter give FM_PARSE_ERROR with a sub-reason and never raise; catches only OSError, UnicodeDecodeError and yaml.YAMLError (PY-F2).
- Placeholder semantics: template mode replaces each {{NAME}} with an inert sentinel, records placeholder-bearing keys, enforces presence but skips their type validators; installed mode gives FM_UNRESOLVED_PLACEHOLDER for any {{...}} anywhere, walked recursively (PY-F1).
- check_agent(fm, profile, mode) and check_skill(fm, directory_name, mode) return a list of frozen Finding(code, key, message, informational) sorted by (code, key) (PY-F4). Codes: FM_PARSE_ERROR, FM_MISSING_REQUIRED, FM_FORBIDDEN_KEY, FM_BARE_MODEL, FM_TYPE_INVALID, FM_UNRESOLVED_PLACEHOLDER, FM_PATH_ESCAPE (emitted only by B2a) are non-informational; FM_UNKNOWN_KEY is informational (INV-B4). A model key gives exactly one FM_BARE_MODEL, never also FM_FORBIDDEN_KEY.
- Agent routing types (parity with _add_frontmatter_model_routing_check, INV-B3): max_subagent_tier int 1-3, subagent_depth non-negative int, bool rejected for both; model_family non-empty string; model_provider and reasoning_effort strings that may be empty; name and description non-empty strings (name: yes gives FM_TYPE_INVALID). Per-key validators live in VALIDATORS: dict[str, Callable].
- agent_profile_for(path, plugin_agents) returns plugin-global when the path is in the root plugin.json agents[], else tier-routed; shared by B2a and B3.
- Read-only; imports no verify or tune code; the existing verify frontmatter helpers are NOT refactored (INV-B3).
