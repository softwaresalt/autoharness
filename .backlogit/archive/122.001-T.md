Define the protocol-neutral broker contract used by local console, PTY, ACP, Gradio, and stable API adapters. Include versioned request/response/event envelopes, correlation/idempotency keys, cursor semantics, capability discovery, typed unavailable/degraded outcomes, bounded payload rules, and a closed control registry. Preserve Plan 2 V1 Observe + Steer compatibility and keep private model reasoning, raw shell, and unbounded transcript fields impossible in the schema.

<!-- BEGIN:acceptance-criteria -->
Envelope version and operation discovery are stable and machine-readable; unknown operation, wrong version, oversized payload, duplicate request, unavailable capability, and malformed cursor fail closed; compatibility fixtures cover the shipped Plan 2 V1 status/phase/progress/output_tail/journal_tail/pause/resume/cancel/request_checkpoint/send_input operations; tests prove no chain-of-thought or arbitrary shell field is accepted.
<!-- END:acceptance-criteria -->

<!-- BEGIN:description -->
One contract module or equivalent shared contract surface; no transport-specific policy and no blind command fallback.
<!-- END:description -->

<!-- BEGIN:implementation-notes -->
Use typed immutable values and a total capability registry. Gradio and HTTP/API layers must consume this contract rather than inventing callback-specific shapes.
<!-- END:implementation-notes -->
