First implementation shipment for Plan 3. Establish the protocol-neutral session broker foundation over the shipped Plan 2 V1 baseline without changing the existing local-only default or exposing new controls yet. The broker owns stable versioned request/response/event envelopes, capability discovery, adapter interfaces for native PTY and ACP, fair local+remote input arbitration, and authenticated account/workspace/session authorization. It must preserve Plan 2 V1 compatibility, local journal authority, bounded/rate-limited requests, metadata-only operator-text audit, local approval for privileged capabilities, loopback-only transport, optional remote dependencies, no arbitrary shell, no browser terminal, and no chain-of-thought.

<!-- BEGIN:description -->
Scope is foundation only. Runtime control implementations, automatic updates, stable API presentation, and Gradio UX land in dependent shipments S2/S3.
<!-- END:description -->

<!-- BEGIN:dod -->
Broker envelope and capability registry are versioned and discoverable; PTY and ACP adapters share interfaces but no slash-text emulation crosses into ACP; local and remote input are sequenced/fair/idempotent; account/workspace/session binding and privilege policy fail closed; local-only, remote-only, and interleaved input tests pass; no new network listener or required base dependency is introduced.
<!-- END:dod -->

<!-- BEGIN:goals -->
Define one transport-neutral session-broker contract that Gradio, stable API adapters, local console, PTY, and ACP can consume without duplicating session policy. Make backend capabilities explicit and unavailable capabilities fail closed with typed results.
<!-- END:goals -->
