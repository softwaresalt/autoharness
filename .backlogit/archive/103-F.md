Encode role-based model routing enforcement durably in the autoharness harness. Defect: Orchestrator invokes Stage/Ship subagents (template Steps 1/2) with no explicit model-override directive, so sub-sessions inherit the default/session model instead of the intended routing. Chosen design (deliberation 010-DL, Option C hybrid): (1) add optional first-class stage/ship role routes to config.model_routing reusing the anchor_review named-route pattern, with tier fallback (Stage->tier3, Ship->tier2) preserving P-013; (2) add an invocation-time routing directive to Orchestrator Steps 1/2 and the skill-delegation contract (resolve role->model, declare/pass override, ROUTING_DEGRADED fallback — no baked --model CLI flag); (3) fail-closed verify_workspace assertions + red-green tests that fail when routing is omitted/unresolved/defaulted. Dogfood: Stage->claude-opus-4.8, Ship->claude-sonnet-5. Environment-agnostic: provider IDs only in config.yaml; templates stay {{VARIABLE}}-parameterized. Do NOT reintroduce model_tier (053.004-T).
