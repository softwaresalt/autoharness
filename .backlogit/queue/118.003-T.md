SIZE: M. COMPLEXITY: medium. (Two independent axes; also emitted as structured backlog fields.) Shipment 1 (P0). Create src/autoharness/supervise/{__init__.py,result.py,errors.py,contracts.py}. result.py defines ONE typed SupervisorResult envelope with fields status, exit_code, data, messages, warnings, artifacts and a .to_dict(); it WRAPS existing result shapes and never rewrites them. errors.py defines ONE AutoharnessError base carrying a machine-readable `kind` (enum), the supervisor error taxonomy, and a SINGLE machine-readable exit-code contract table from which the CLI adapter derives its exit codes, so agent prose depending on exit codes cannot drift. contracts.py IS THE SHARED SUPERVISOR CORE CONTRACT MODULE, added by the F19/F21 ruling to fix two ordering defects. It defines (a) the STABLE EVENT NAME AND PAYLOAD CATALOG - SessionPhaseChanged, SidecarProbed, CopilotResolved, ChildSpawned, ChildOutput, ChildOutputUnavailable, ChildExited, ApprovalRequested, ApprovalResolved, CancelRequested, RestartScheduled, RestartExhausted, JournalCheckpoint - and (b) the APPROVAL REQUEST/RESPONSE TYPES (kind, summary, options, default, timeout, resolution, resolved_by). PRODUCERS AND CONSUMERS BOTH DEPEND ON THIS MODULE AND NEVER ON EACH OTHER: 119.003-T emits SessionPhaseChanged against this catalog WITHOUT depending on the 119.004-T bus, which removes the F19 dependency cycle; and 120.005-T implements the console approval channel against a contract that already exists upstream, so the approval path is no longer orderable out of the runtime (F21). Definitions only - no bus, no fan-out, no subscribers. Pure modules: no I/O, no subprocess, no sys.exit, no policy. Unit tests cover envelope round-trip, every error kind mapping to exactly one exit code, and exhaustiveness of the contract table. Zero behavior change to any existing surface.
