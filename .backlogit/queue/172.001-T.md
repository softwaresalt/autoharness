Author the HISTORICAL-RECORD CLASSIFICATION POLICY and its outcome set as DESCRIPTIVE TEXT THAT PROHIBITS NO PRODUCER PATH. This task is INERT: it defines vocabulary and decision rules; it changes no call site, no registry, and no enforcement. The Checkpoint Payload Contract's advertisement of the raw create call is NOT touched here - removing it before a wired replacement exists would commit a state in which a contract forbids the only path any producer has.

THE OUTCOME SET, TOTAL OVER EVERY RECORD:
- CHECKPOINT_LEGACY_HINTLESS_RESOLVED (reported, non-blocking) - a record in a TERMINAL status carrying no usable resume_hint. It is excluded from the candidate set and enumerated by filename so the exemption is visible rather than silent.
- CHECKPOINT_ACTIVE_HINTLESS (BLOCKING) - a record in a NON-TERMINAL status with a missing, empty or whitespace-only hint. Fails closed to operator handoff.
- CHECKPOINT_RECORD_MALFORMED (BLOCKING) - an explicit blocking outcome for any record that cannot be classified structurally.

CLASSIFICATION IS TOTAL ACROSS EVERY ACCEPTED STATUS. The accepted status enum is queued, active, shipped, abandoned, plus resolved. NON-TERMINAL = {active, queued}; TERMINAL = {shipped, abandoned, resolved}. ABANDONED IS NAMED EXPLICITLY and classified as terminal: an unnamed status is exactly how a record escapes classification, and an abandoned record silently entering the blocking bucket would halt startup for work deliberately stopped.

MALFORMED IS ENUMERATED, NOT LEFT TO INFERENCE. Every one of the following classifies as CHECKPOINT_RECORD_MALFORMED and BLOCKS: unparseable document; duplicate keys; non-object root; missing status; wrong-typed status; unrecognized status value not in the accepted enum; missing schema_version; a FUTURE schema_version this implementation does not understand; and any required field present with the wrong type. A future schema_version blocks rather than degrades, because a reader that guesses at a shape it was not written for produces a confidently wrong classification.

NO RECORD IS EVER UNCLASSIFIED and no record falls through to a silent pass. The policy states totality explicitly so a reader cannot infer an escape hatch for a record matching no branch cleanly.

THE POLICY IS STATED ONCE and both copies - the installed instruction and its template - change and revert together, byte-identically in the affected blocks.
