Author the historical-record COMPATIBILITY POLICY and perform the ATOMIC Checkpoint Payload Contract update.

PART A - COMPATIBILITY POLICY, TOTAL AND DETERMINISTIC. Define how a pre-existing schema_version: 1 record lacking a usable resume_hint is treated by the fail-closed startup scan. Every historical record lands in exactly one of two outcomes, decided by status alone, and neither outcome is "unspecified":
  * status: resolved with a missing, empty or whitespace-only hint => CHECKPOINT_LEGACY_HINTLESS_RESOLVED. REPORTED, NON-BLOCKING. Enumerated by filename and count, and EXCLUDED from the candidate set - it can never be an active recovery candidate by definition, so excluding it removes no recovery capability.
  * status: active with a missing, empty or whitespace-only hint => CHECKPOINT_ACTIVE_HINTLESS. A CONCRETE, BLOCKING token that fails closed to operator handoff. NEVER exempt, NEVER grandfathered, regardless of the record's age or authorship.
Stating that an active hintless record "fails closed exactly as today" WITHOUT NAMING A TOKEN is the defect this policy closes: a fail-closed behaviour with no token is not observable, not testable and not reportable. Resolved compatibility and active fail-closure are SEPARATE rules; neither widens the other, and there is no third branch. An operator may repair a historical record out-of-band; this policy neither requires nor performs such a repair, and no committed checkpoint file is ever rewritten.

PART B - ATOMIC CONTRACT UPDATE. The authoritative Checkpoint Payload Contract currently advertises backlogit_create_checkpoint (MCP) and backlogit checkpoint create (CLI) as the way a harness producer writes a checkpoint. Once the adapter exists that advertisement names the exact bypass the adapter is a gate in front of, inside the document agents are instructed to obey. Update the contract so that FOR HARNESS PRODUCERS the only permitted create path is autoharness checkpoint create. The raw backlogit operation remains what the adapter itself calls; it is no longer a path a producer may reach directly.

THE UPDATE IS ATOMIC ACROSS BOTH SURFACES: .github/instructions/backlogit.instructions.md (installed authoritative contract) and templates/instructions/backlogit.instructions.md.tmpl (the template it is generated from). Both change in this task and revert together. Changing one alone produces a workspace whose installed instruction and its own template disagree, which the next autoharness install would silently resolve in the wrong direction.
