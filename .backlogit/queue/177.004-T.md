DETERMINING TASK FOR PROPERTY I1: "No credentials of any kind in the job environment." Attempt 01 found I1 assigned to NO determining task, which made the spike's declared pass state ISOLATION_CHARACTERIZED unreachable by any legitimate execution. This task closes that gap by INSPECTING THE ACTUAL JOB ENVIRONMENT rather than by reasoning about it. METHOD: run a probe job on a GitHub-hosted Linux runner configured exactly as the conformance job would be - permissions block minimized, no secrets passed, checkout credential persistence disabled or checkout omitted - and, FROM INSIDE THAT JOB, record: (a) the NAMES of every environment variable present; (b) the presence or absence of credential-bearing filesystem paths (git credential store and helper configuration, container/registry auth files, cloud and CI credential directories, the runner's own token files); (c) the checkout action's credential-persistence setting in effect; (d) the MECHANISM that produces each absence, so the verdict cites a mechanism and not a default. ACCEPTANCE EVIDENCE: that recorded inventory, taken inside the job, plus the mechanism. A documentation citation alone resolves to ABSENT and yields ISOLATION_UNDETERMINED (H2, R3). EVIDENCE HANDLING IS BINDING: record environment-variable NAMES ONLY and path presence/absence only. NO value, token, key fragment or credential content is written to the findings artifact or to any job log. An inventory that would require recording a secret value to be meaningful is ITSELF the finding that I1 is NOT ACHIEVABLE (R6). This task executes NO untrusted binary and acquires nothing. It is independent of 177.005-T, 177.001-T and 177.002-T and may run in any order relative to them; it blocks 177.003-T. Determining I1 before any containment probe is trusted to be safe is deliberate: a probe job carrying credentials would be a privileged process handling an untrusted artifact even without executing it (H7). ELAPSED BOUND 90 min; on reaching it, record NOT DETERMINED with what was attempted and what blocked it. SECURITY MODEL IS A CONSTRAINT, NOT A QUESTION: if I1 is NOT ACHIEVABLE, 181-S degrades to evidence-and-documentation only; the requirement is never relaxed. Source 7F9CB5E9.
