## RULE FOR EMPTY PROFILE FIELDS (023-DL R3, amendment B4)
Use the SKILL.md documented default where one exists; otherwise derive to the EMPTY STRING. **Never invent a value.**

The installed dogfood copies contain literals (`"# no format check command configured"`, `markdownlint "**/*.md"`). **Amendment B4: "observed in the current dogfood copy" is a FORBIDDEN provenance.** Hardcoding those observed literals would make the derivation lie about a workspace whose profile genuinely has no linter.
