Close the colon-anchored coverage gap in the already-shipped failure-bearing-success detector. In experiments/088-compression-experiment/brainspace/policy.py, extend _FAILURE_BEARING_PATTERNS so classify_decline_reason returns FAILURE_BEARING_SUCCESS for the common non-colon / alternate non-zero-exit and stderr forms, while still returning None for benign/zero-exit forms. Do NOT re-implement the detector, hook wiring, or the existing negative controls — they already shipped in 088.004-T (commit 118bf21). This is an additive, fail-safe-directional change (more declines = more byte-identical passthrough; it can never newly hide evidence).

Current gap: patterns require a colon (exit code:\s*[1-9]), so 'exit code 1', 'exited with code 1', make 'Error 1'/'*** [target] Error 1', 'npm ERR!', and 'Process finished with exit code 1' are NOT detected -> classify_decline_reason returns None -> _compress_view can collapse the failure line into the omitted middle (evidence loss).

Single concern: the decline detector patterns in policy.py and their tests only. Do not touch hook.py/evidence_oracle.py here (that is 093.002-T).

<!-- BEGIN:acceptance-criteria -->
- Each added failure form classifies as DeclineReason.FAILURE_BEARING_SUCCESS via classify_decline_reason and, through the hook, passes the original through byte-identically (positive controls): at minimum 'exit code 1' (space, no colon), 'exited with code 1' / 'exited with exit code 1', make 'Error 1' and '*** [target] Error 1', 'npm ERR!', 'Process finished with exit code 1', and a bare 'returncode 1' (space form).
- Zero-exit / benign forms still return None and remain compressible (negative controls, no false-positive regression): 'exit code: 0', 'exit code 0', 'exited with code 0', prose merely containing the words 'error'/'failed'/'warning' without a non-zero-exit/stderr signal, and an 'All checks passed' style success line.
- Secret-priority ordering preserved: contains_secret still takes precedence over the failure-bearing check.
- New positive + negative controls added to tests/test_policy_decline_cases.py (and, where hook-level behavior matters, tests/test_hook_decide_then_stash.py).
- Experiment pytest suite green: pytest experiments/088-compression-experiment/tests. No change to the disabled-by-default flag.
<!-- END:acceptance-criteria -->
