Surface: **test module** (`tests/test_docs_compound_frontmatter_contract.py`). Width-isolated from corpus data (146.001-T) and the template family (146.003-T).

Depends on 146.001-T (corpus fix lands first — deliberate deviation from RED-harness-first, justified in 026-DL R4: with exactly one known violation against an exactly measured baseline, a RED intermediate commit would break the canonical local gate mid-shipment for zero diagnostic gain).

## Steps

1. Add a value-shape assertion for `source`: with surrounding quotes stripped and whitespace trimmed, `source` MUST equal the file's own repo-relative POSIX path.
2. **Derive the expected path from the file's actual location** — `path.relative_to(repo_root).as_posix()` — never a hard-coded flat `docs/compound/` prefix (026-DL R1). The authoring template models `source: "{{DOCS_COMPOUND}}/{category}/{slug}-{YYYY-MM-DD}.md"`, so a category SUBDIRECTORY is a legal future shape; a flat-prefix predicate becomes a false failure the day the first one is created.
3. Make the assertion **ADDITIVE** (026-DL R2). Every existing behaviour must still fail after the ratchet: non-emptiness, YAML null (`source: null` / `source: ~`), comment-only (`source: # missing`), empty string, and the `*.md`-only scope guard (`test_no_non_markdown_assets_are_in_scope`, amendment C2). Do not delete or relax any of them to simplify the new assertion.
4. **Exemption allowlist (A2).** One named constant, exempting files from the VALUE-SHAPE assertion only (never from non-emptiness). EMPTY in the expected one-outlier case. Non-empty ONLY when 146.001-T recorded additional non-conforming files, enumerating exactly those, each annotated with the deferring P-021 capture ID. SHRINKING in the sense of 141.002-T: entries may only be removed, never added, without new Stage authorization.
5. Leave `doc_type` at its existing non-emptiness check (026-DL R3 — a literal `learning` assertion would hard-code rung 3 of the template's capability-neutral authority order and contradict amendment C3).
6. On failure, report the offending file, its actual `source`, and the expected path, so the message is self-diagnosing.
