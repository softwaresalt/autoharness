Create src/autoharness/supervise/recovery.py: cancellation, controlled restart, and resume. CANCELLATION: operator cancel is LEGAL FROM EVERY POST-LOCKING PHASE (F18/F23 ruling) and always drives <phase> -> CANCELLING -> DRAINING -> EXITED, terminating the child if one exists, flushing the journal, and releasing the lock. Because cancel is legal from LAUNCHING, the 'cancel during launch' case below is now SATISFIABLE against the 119.003-T table instead of describing an illegal transition. RESTART: the budget DEFAULTS TO 0 (opt-in via --max-restarts N) with a hard ceiling and exponential backoff; a restart requires BOTH remaining budget AND explicit operator confirmation, and every restart is journaled with its reason. Budget exhaustion drains to a terminal state and NEVER loops (H2). RESUME: resume-from-cursor reads the 119.005-T journal cursor only; it never reads or writes a backlogit checkpoint (H6). H8 DE-RISKING: the state machine and journal are already-fixed contracts, and because the budget defaults to 0 the DEFAULT path is simply cancel-and-drain, so the complex restart path is opt-in and separately testable against the scripted fake child from 119.001-T. Tests use the fake child exclusively: cancel during launch (LAUNCHING -> CANCELLING -> DRAINING -> EXITED), cancel during bootstrap, preflight and resolve, cancel during run, restart with budget, restart declined by operator, budget exhaustion, backoff timing, and resume after simulated crash. EVERY cancellation and failure test additionally asserts that the workspace lock was RELEASED EXACTLY ONCE (F22), so no path can strand it.
