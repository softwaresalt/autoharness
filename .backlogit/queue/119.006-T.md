Create src/autoharness/supervise/recovery.py: cancellation, controlled restart, and resume. CANCELLATION: operator cancel drives RUNNING -> CANCELLING -> DRAINING -> EXITED, terminating the child, flushing the journal, and releasing the lock. RESTART: the budget DEFAULTS TO 0 (opt-in via --max-restarts N) with a hard ceiling and exponential backoff; a restart requires BOTH remaining budget AND explicit operator confirmation, and every restart is journaled with its reason. Budget exhaustion drains to a terminal state and NEVER loops (H2). RESUME: resume-from-cursor reads the 117.010-T journal cursor only; it never reads or writes a backlogit checkpoint (H6). H8 DE-RISKING: the state machine and journal are already-fixed contracts, and because the budget defaults to 0 the DEFAULT path is simply cancel-and-drain, so the complex restart path is opt-in and separately testable against the scripted fake child from 117.006-T. Tests use the fake child exclusively: cancel during launch, cancel during run, restart with budget, restart declined by operator, budget exhaustion, backoff timing, and resume after simulated crash.
