Files: src/autoharness/shipment_close/command.py (new), src/autoharness/cli.py (dispatch and usage only), tests/test_shipment_cascade_close_invoke.py (new).
run_cascade_close(...) steps, all under the A1b pair lock:
1. acquire the lock and run the existing-record check (exit 7 or 2) before any classification;
2. validate --message and --author (non-empty, no NUL or newline, at most 1,024 characters; else exit 2);
3. run_preclose; a non-CASCADE verdict writes the pre_close verdict record and exits 3 without invoking anything;
4. write the pre_close record; on failure exit 2 without invoking;
5. revalidate (AS-F02): recompute the ENTIRE pre-close snapshot and compare with the durable record ignoring only captured_at; any difference exits 4 (HALT - cascade pre-invocation revalidation drift detected);
6. re-hash the resolved binary; a mismatch with tool.binary_sha256 exits 4 without invoking, leaving only the replaceable pre_close record (AN-F08);
7. write the owner-bound phase: invoking record (run_id, argv_redacted, started_at); on failure exit 2 without invoking (INV-P1, INV-P7);
8. invoke through A3a with the fixed argv [<absolute binary>, "--no-update-check", "--jsonrpc", "--cwd", <workspace root>, "shipment", "ship", S, "--sha", X, "--message", M, "--author", A];
9. re-read the fingerprinted files, then parse_ship_response and evaluate_postconditions;
10. write the owner-bound post_close record EVEN WHEN the invocation or parse fails; if this write fails exit 8.
Exit codes: 0 mutating pass / classify-only CASCADE recorded; 2 input, I/O, no-clobber (already finalized) or pre-invocation write failure (no mutation); 3 verdict not CASCADE, verdict record written, nothing invoked; 4 revalidation drift incl. binary hash change, nothing invoked; 5 postcondition failed (record names every failure); 6 backlogit non-zero, timed out or stdout unparseable (indeterminate); 7 existing lock or invoking record, nothing invoked; 8 post-close evidence write failed after invocation. Exits 5-8 forbid committing the backlog root, re-running cascade-close, calling backlogit shipment ship directly, or substituting SAFE_CLOSE (INV-P4) until an operator reviews.
--json (AN-F06): one object {mode, exit_code, evidence_path, phase_written, classifier_verdict, mutation_possible no|yes|indeterminate|unknown, postcondition_verdict, failures[], operator_action none|review_required}; exit-2 cases always report mutation_possible: no.
cli.py gains the shipment group, the cascade-close subcommand and USAGE lines; USAGE labels the mutating mode and --classify-only --replace-pre-close DESTRUCTIVE, and plain --classify-only no-clobber and read-only apart from creating a new evidence record (Principle VII, CR-F01, PR #460 review).
