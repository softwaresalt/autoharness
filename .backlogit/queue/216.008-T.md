Extends src/autoharness/docs_only_check.py with the BASELINE PHASE (--phase baseline), run by Ship at Step 4.1 right after the task is active. P-011 guarantees a clean tree only before the claim, and ClaimShipment is shipment-wide (P-002.7/P-002.8: it activates and stamps every queued manifest member), so the post-claim diff against the start SHA contains claim writes for the task, its feature, its shipment AND every sibling manifest member. The phase reads the shipment's live custom_fields.items (never caller-supplied), computes the union of git diff --name-status <start-sha>, staged, unstaged and untracked paths, and requires every changed path to be a backlog file of the task, its feature, its shipment or a manifest member with a claim-only delta: frontmatter limited to status queued->active, updated_at and custom_fields.scheduler_baseline_claim equal to the shipment id, body byte-identical. Any other changed path (inside or outside the backlog root), any owned path already modified, or any non-claim delta fails closed with BASELINE_NOT_CLAIM_ONLY (no retroactive qualification of partial work). On pass it emits the lifecycle baseline: map of each such backlog file path to the SHA-256 of its LF-normalized content, which Ship records in the task comment (item log, git-ignored). AC: (1) a two-task shipment claim (both tasks active, markers set) passes and yields baselines for the task, feature, shipment and the sibling; (2) fails closed for an item outside the manifest, a stash edit, a body edit, a non-claim frontmatter change, a modified owned path and a src/ edit; (3) manifest membership comes from the live shipment file; (4) unit tests green.
