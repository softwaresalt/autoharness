FOUNDATION (P2). Build the four security and integrity primitives every safe operation composes from. (1) ATOMIC WRITE: temp file in the destination directory, fsync, os.replace - motivated by two OBSERVED torn checkpoint records in the live corpus that truncate mid-object at exactly the file length. (2) PATH CONTAINMENT: resolve against a declared workspace root and reject every escape. (3) FIXED-ARGV EXEC: subprocess.run(argv_list, shell=False) with a per-operation executable allowlist and no shell anywhere. (4) BOUNDED READER: size and nesting bounds over untrusted JSON, returning a typed QUARANTINE record rather than raising, so a malformed or partially written file is classified instead of crashing the caller. Each primitive ships with its own RED-first contract suite. These primitives are the reason 178-S, 180-S and 176-S can be fixed at all. Sources: 86498B64 merged with 14F4D6F3, 71200CBB, C9CD24F3.
