<!-- BEGIN:description -->
Files: src/autoharness/shipment_close/__init__.py, src/autoharness/shipment_close/persist.py (new), tests/test_shipment_close_persist.py (new).
- StreamCapture: counts bytes and lines and folds every byte into a SHA-256; retains a tail window of the final 64 KiB / 500 lines plus a 4 KiB leading margin, and for stdout only an in-memory parse buffer of at most 1 MiB that is never persisted. Bytes past 1 MiB / 10,000 lines are drained and hashed but not retained (capture_truncated: true). A stdout overflow makes the result unparseable (parse_error: stdout exceeded capture cap), never silently truncated JSON (AS-F03).
- redact(text) -> (text, redaction_applied): bearer or basic Authorization values; key=value credential pairs whose key is token, password or secret; GitHub gh[pousr]_ and github_pat_ tokens; sk- style keys. It runs over the retained tail window BEFORE the excerpt is sliced (H-B4) and over every persisted free-text field: argv, version excerpt, parse_error, both excerpts and failures[] (SL-F04).
- acquire_pair_lock(workspace, S, F, run_id): creates .autoharness/gates/cascade-close/{S}-{F}.lock (gitignored runtime directory) with O_CREAT | O_EXCL (plus O_NOFOLLOW where available, following gates/bootstrap_grant.py), holding run_id, PID and started_at. Before creating anything every path component from the workspace root to the lock directory and to docs/closure/evidence/ is checked: contained and a real directory (no symlink, junction or reparse point); missing components are created one at a time with mkdir and re-checked (SL-F06). Held from the first existing-record check through the final write, released in finally. An existing lock is never broken automatically (exit 7); stale-lock removal is an operator action.
- Existing-record check (first action under the lock, every mode): invoking record -> exit 7; post_close record -> exit 2 (evidence already finalized); a pre_close record may be replaced.
- write_evidence_atomic(path, record, *, owner_run_id): the owning run (same run_id, holding the lock) may move its own record pre_close -> invoking -> post_close; any other writer and any transition out of post_close are refused (AS-F01). Same-directory temp file, flush + fsync, os.replace; refuses symlinked or reparse-point targets and parents (reuse the shipment_closure helpers). On Windows skip the directory fsync and retry a sharing-violation PermissionError at most 3 times with bounded backoff; remove the temp file in finally.
