Dispose of the SAFE_CLOSE record-transition gap: no supported backlogit command path can record a shipped disposition for a partially complete shipment, so the behaviour is OBSERVED, REPORTED UPSTREAM, and handled by a documented operator-only administrative procedure - never by forging a transition the tool refuses.

EXTERNAL EVIDENCE IS ACQUIRED UNDER AN ELEVATED, APPROVAL-GATED PROCEDURE. Part A0 binds nine preconditions on acquiring and installing the pinned binary: in-session approval naming version AND exact asset coordinates; five canonicalized roots (repository, install, executable, fixture, disposable backlog storage) with symlink/junction/reparse/hardlink/out-of-root rejection by resolved-component comparison; a fresh private install directory; a scrubbed environment with invocation by absolute resolved path; digest AND coordinate verification before first invocation; a platform halt when the platform's digest is unpinned; bounded careful execution; an explicit disposable storage root with a pre-mutation assertion RE-EVALUATED BEFORE EVERY MUTATING CALL that it is never the live .backlogit/ tree; and pre-recorded rollback with pathspec-level, immediately revalidated deletion approval - absent which the ignored directory is RETAINED and the run HALTS. Approval withheld means halt and report, never a fallback and never a skip.

THE ASSET BINDING IS THE FULL COORDINATE TUPLE - host, repository, tag, asset name, platform, architecture and digest - verified coordinate by coordinate. This is directly coupled security hardening: a digest alone does not say where the bytes must come from, and coordinates alone do not say which bytes. The CI pin currently covers LINUX-AMD64 ONLY and no Windows digest is pinned, so an unpinned platform HALTS.

THE SUITE IS PARTITIONED. The four refusal fixtures and the baseline live in tests_conformance/, outside the ordinary discovery root, and run in a SEPARATE REQUIRED CI JOB that provisions the binary reproducibly. The ordinary suite stays HERMETIC and PYTHONPATH=src python -m unittest discover -s tests exits 0 on a clean checkout with no provisioned binary. Conformance fixtures FAIL LOUDLY rather than skip when the binary is absent. The tracker regression 173.010-T deliberately stays in the ordinary suite because it only reads backlog records.

THE ADMINISTRATIVE-CLOSE PROCEDURE IS OPERATOR-ONLY and fully specified: four binding constraints plus seven steps - fresh in-session approval naming shipment, current state, exact fields and effects; byte snapshot with manifest and relationship hashes; manifest-scope verification; a fixed-argv shell=False mechanism with direct file editing prohibited; five asserted postconditions; automatic rollback on any failure; and an audit/P-005 evidence record.
