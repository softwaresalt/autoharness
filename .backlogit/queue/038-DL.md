# Align shipment-reconcile / P-015 CASCADE contract with backlogit >=1.11.0 flat cascade semantics (linked deliberations stay independent)

## Problem Frame

<!-- BEGIN:problem-frame -->
backlogit v1.11.0 (commit 5a4b70dd, task 174.058-T) made `shipment ship` flat: it archives only the shipment record, terminal explicit manifest members, and explicit feature members; linked deliberations and unlisted descendants remain independent (internal/core/shipment_lifecycle.go collectArchiveCandidateIDs L716-751, comment L734-735; engine regression test TestUArchiveCandidateFlat_UnlistedLinkedDeliberationIsUntouched). autoharness still encodes the pre-1.11.0 behavior: shipment-reconcile Step 0(c) Linked-deliberation snapshot extension, pre-invocation re-collection, allowed_ids/required_ids (template + mirror), P-015 D1a/INV-1/INV-6 (template + mirror), shipment_closure.py docstring, Ship agent CASCADE bullet, and 155-S-era tests. Result: every CASCADE close whose qualifying feature links a live deliberation deterministically HALTs post-mutation (190-S / 034-DL, 2026-09-29), and SAFE_CLOSE silently strands the same deliberation live. Operator goal (verbatim): "make sure that autoharness is aligned in workflow with how backlogit operates such that we don't recreate this scenario." This is the fourth backlogit engine-behavior drift discovered at closure time (019-DL 143-S, 1.10.1 archived_ids pre-archived tasks, 1.10.0 claim cascade, now 1.11.0).
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
A. Contract realignment only (drop linked deliberations from allowed_ids/required_ids; add sanctioned post-closure explicit archive). B. A + fail-closed engine-semantics version gate on CASCADE (verified minor line 1.11.x; unknown/older/newer -> SAFE_CLOSE) + path-independent linked-deliberation disposition step. C. Dual-mode contract (pre-1.11 vs >=1.11 semantics selected by version). D. Upstream backlogit option (ship --archive-linked-deliberations / returned linked IDs). E. Stage-side prevention (deliberations as explicit manifest members, or archive deliberations at harvest). F. Workspace-wide engine-behavior compatibility registry + verify-workspace drift probe in this unit.
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
Option B. (1) P-015/skill/gate docstring/Ship agent realigned to backlogit >=1.11.0 flat semantics: allowed_ids(S)=closure_scope(S), required_ids(S)={S} ∪ qualifying features ∪ non-archived manifest items; a linked deliberation appearing in archived_ids is an unexpected-artifact HALT (engine-drift detector) and each must be byte-identical to its pre-close snapshot after the cascade. (2) New path-independent Linked-Deliberation Disposition step after either close path's postconditions pass: each validated linked deliberation not truly archived pre-close is archived individually (non-cascade archive_item, verify-after-each, archived_status provenance recorded) unless a shared-reference guard finds another live artifact outside closure_scope still linking it (then retained and recorded). (3) CASCADE additionally requires a fresh backlogit version probe inside the contract's verified engine-semantics line (1.11.x, single-source constant in shipment_closure.py pinned by parity tests); missing/unparseable/other -> SAFE_CLOSE (ENGINE_SEMANTICS_UNVERIFIED). Classifier signature unchanged (separate pure function composed at Step 0(c)). F deferred as a separate stash entry; D not needed (engine semantics are intentional); E rejected.
<!-- END:chosen-direction -->
