RELEASE DRY RUN A — build and package integrity. Runs BEFORE the PR.

STEP 0 (MANDATORY FIRST — do not skip): CLEAN dist/. Verified this session: dist/ currently contains STALE 1.4.11 artifacts (autoharness-1.4.11-py3-none-any.whl, autoharness-1.4.11.tar.gz). This was raised as P1-1 in plan review. If not cleaned:
  - `uvx twine check dist/*` validates the OLD artifacts and reports a MISLEADING PASS;
  - an isolated install from a dist/*.whl glob could install 1.4.11 while the operator believes 1.5.0 was verified.
That defeats the entire gate immediately before an irreversible publish.

STEPS:
1. Remove stale artifacts from dist/.
2. `uv build`
3. Confirm exactly two freshly-built artifacts exist, both carrying 1.5.0 in their filenames. FAIL if ANY non-1.5.0 artifact is present in dist/.
4. `uvx twine check dist/*`
5. Install the EXPLICITLY NAMED 1.5.0 wheel (never a glob) into an isolated environment — not the source tree.
6. Assert `autoharness version` outputs EXACTLY "1.5.0" AND the command exited zero.
7. Assert the installed distribution METADATA reports 1.5.0 (__init__.py prefers importlib.metadata.version(); a stale literal fallback would otherwise stay hidden).
8. Assert `autoharness home` resolves.
9. BUNDLED DATA: inspect the wheel contents and confirm autoharness/data/templates/ is present AND non-empty; then confirm from the ISOLATED install that templates are readable. This force-include mapping (templates -> src/autoharness/data/templates) is the most likely packaging regression and is INVISIBLE to the test suite, which runs from the source tree via pythonpath = ["src"].

LEARNING APPLIED (docs/compound/2026-08-08-shell-pipeline-exit-status-masking-in-version-probes.md): assert exact string equality and the command's OWN exit status. Do NOT infer success from non-empty output. Do NOT mask failures with a trailing `|| true`.

STOP CONDITION: any failure here halts the release. Do not open the PR. Fix and re-run the full gate set from the start.
BLOCKED-PATH HANDLING: if a step cannot run (tool missing, no network for twine), record TOOL_UNAVAILABLE and HALT. Do not substitute a weaker check.
