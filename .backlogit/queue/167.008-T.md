PLAN UNIT U8. Domain: tests. Posture: test-first.

FILES (1): tests/test_gates_topology.py (extended).

PURPOSE
The recognized-read set is widened in 167.002-T. Widening a discovery predicate on a FAIL-CLOSED gate is the single highest-risk change in this feature (risks R1/R2). This task supplies the ADVERSARIAL evidence that the widening admits nothing beyond its intended targets.

TESTS (5)
1. ADJACENT-ID REJECTION — a legacy-named artifact for `16-S` MUST NOT satisfy closure_complete('162-S'), and vice versa. This is the direct R2 regression: the delimiter-anchored ID match is what prevents a substring collision from admitting a foreign shipment's closure record as a predecessor's evidence.
2. INVALID-UNDER-RECOGNIZED-NAME STILL BLOCKS — an artifact matching R2 but carrying `closure_status: BLOCKED` MUST still fail the gate. Proves recognition widening did NOT weaken the validity predicate.
3. UNSATISFIED-CONDITIONS STILL BLOCK — READY_WITH_CONDITIONS with an unsatisfied conditions block still fails (the _closure_conditions_satisfied path, topology.py:281-300).
4. MALFORMED FRONTMATTER STILL FAILS LOUDLY — a recognized-name artifact with unparseable frontmatter still raises BacklogUnavailableError / yields BACKLOG_UNAVAILABLE. Guards the explicit non-goal that a discovery change must never convert a loud failure into a silent skip.
5. CASE-INSENSITIVE ID SEGMENT — the lowercase `162-s` form present in the real corpus is recognized, while a foreign ID is still rejected.

WHY THIS IS A SEPARATE TASK
These tests target the ADVERSARIAL boundary of the widened predicate, whereas 167.007-T targets COMPOSED end-to-end behaviour. Keeping them separate keeps each within the 2-hour envelope and keeps failure diagnosis unambiguous — a failure here means the widening over-admitted; a failure there means producer and consumer disagree.

SCOPE GUARD
Adds tests ONLY. Does not modify any non-test source file. Touches NOTHING under docs/closure/ — all fixtures are written to temporary scratch directories.
