## Task 097.005 — Manifest refresh + verification gate (P-006 completeness)

Width domain: manifest + integration gate. Est. ~1h. Depends on 097.001-004.

1. `.autoharness/harness-manifest.yaml`:
   * Rename the 2 installed-agent PATH keys (~lines 107,112):
     `.github/agents/.stage.agent.md` -> `_stage.agent.md`;
     `.github/agents/.ship.agent.md` -> `_ship.agent.md`.
   * **Normalize-then-hash (CRLF-safe, ORDERED — do not reorder).** `autoharness
     verify` hashes RAW working-tree bytes (verify_workspace.py:3186); a
     `.gitattributes` `eol=lf` pin only governs FUTURE checkout/clean conversion
     and does NOT rewrite an already-checked-out CRLF file. So you MUST actually
     convert the two renamed working-tree files to LF in place, assert no CRLF
     remains, and only then hash the raw bytes:
     1. Set the `eol=lf` attribute (done in 097.002), then force in-place
        renormalization: `git add --renormalize .github/agents/_stage.agent.md .github/agents/_ship.agent.md`
        (or rewrite bytes: read, `.replace(b"\r\n", b"\n")`, write back).
     2. ASSERT no CRLF remains in either working-tree file, e.g.:
        `python -c "import pathlib,sys; [sys.exit('CRLF in '+p) for p in ['.github/agents/_stage.agent.md','.github/agents/_ship.agent.md'] if b'\r\n' in pathlib.Path(p).read_bytes()]"`
     3. Hash the RAW bytes of each now-LF file (this is what verify recomputes):
        `python -c "import hashlib,pathlib; print(hashlib.sha256(pathlib.Path('.github/agents/_stage.agent.md').read_bytes()).hexdigest())"`
        (repeat for `_ship`). Write these into the 2 manifest `checksum` fields.
   * Update the 3 assertion-text lines naming the files (~54,55,67).
   * Templates are NOT checksummed — only these 2 artifact entries change.

2. Run `autoharness verify` (or `python -m autoharness verify`) — must pass for
   both renamed installed agent artifacts (unchanged/OK checksum status).

3. Run the CANONICAL full-suite gate (matches CI ci.yml:89; root `pytest` is
   NONCANONICAL per docs/compound/097-S-canonical-unittest-gate.md — it can
   collect vendored `references/`): `PYTHONPATH=src python -m unittest discover -s tests`
   — must be green (record `Ran N tests ... OK`). An optional
   `uv run pytest tests/` smoke may be run for convenience but is NOT the gate.

4. Run the ZERO-RESIDUAL-REFERENCE GATE (H1):
   ```
   rg -n "\.ship\.agent\.md|\.stage\.agent\.md|name:\s*\.(Ship|Stage)|\.Ship\b|\.Stage\b" `
     --glob '!.backlogit/**' --glob '!docs/memory/**' --glob '!docs/decisions/**' `
   ```
