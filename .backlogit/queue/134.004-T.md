<!-- BEGIN:description -->
Ship is the agent that actually performs fix cycles, so it carries the operative procedure. Add to Ship's review-fix and build/CI-fix loops:

1. Evaluate EVERY finding against the P-021 C1 same-contract-surface test before fixing it.
2. For out-of-scope findings, ALWAYS perform the C2 capture with the full six-field payload FIRST, then C3-resolve the original as far as possible without the expansion. Where a review thread exists, reference the deferred entry ID in the thread reply and then resolve the thread, and name it in the PR/closure residual-risk record. Where no review thread exists -- Ship's local review runs before PR creation, and build/CI findings have no thread -- mark the PR and review-thread payload fields not applicable and reference the deferred entry ID in the task/run/closure residual-risk records instead; the reply and resolution steps are inapplicable, not skipped obligations.
3. Annotate the Stop Conditions review-fix row with C4: reaching the cycle limit does not authorize expansion; remaining findings are accepted as captured deferred entries, not as silently expanded fixes.
