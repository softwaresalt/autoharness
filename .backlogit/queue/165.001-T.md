Author the derivation test harness. Split into CHARACTERIZATION tests (behaviour that already exists — these PASS on current `main` and must keep passing) and NEW EXPECTATIONS (behaviour that does not yet exist — written as STRICT EXPECTED-FAILURE tests). Do NOT claim a RED observation for behaviour that already works; that observation is impossible to make honestly and is not required.

THIS TASK ENDS GREEN. New expectations land as STRICT expected-failure (xfail-strict / expectedFailure) tests, so the suite is green at task end. Strictness is REQUIRED: an expectation that starts passing must FAIL the suite, otherwise the marker silently hides a behaviour change. 165.002-T flips them to ordinary assertions when it delivers the behaviour.

CHARACTERIZATION (must pass immediately, in tests/test_gates_topology.py):
C1. Explicit linear chain blocks correctly on an unshipped explicit predecessor.
C2. Closure evidence is demanded for an actual explicit predecessor.
C3. Converging DAG — two explicit predecessors on one successor; EVERY explicit predecessor is evaluated, none skipped.
C4. Malformed / unresolvable dependency IDs FAIL CLOSED and are never silently dropped.

NEW EXPECTATIONS (strict expected-failure; flipped by 165.002-T):
N1. Two numerically adjacent EDGE-LESS roots are NOT blocked by numeric inference (fixture mirroring the 148-S/149-S shape).
N2. Closure evidence is NEVER demanded for a merely numerically-adjacent non-predecessor.
N3. `predecessor_source` is present and correct on a PASSING payload AND on a BLOCKED payload (hardening F1).
N4. Declared root (record carries the `dag-root` label) passes with `predecessor_source: "declared_root"`.
N5. Genesis workspace (no shipped-terminal shipment anywhere) passes with `predecessor_source: "genesis"`.
N5b. GENESIS PROBE MUST CONSIDER ARCHIVED HISTORY (plan-review cycle 2, P2-1). Assert that a workspace whose only shipped-terminal shipments exist as ARCHIVED records is NOT genesis — an edge-less shipment there must block as `unsequenced`, not pass. The probe must read archived shipment state (`archived_status` / `archived_record_present`, already carried on ShipmentState), never only live queue records. Otherwise archiving or pruning history would silently re-enter genesis and convert a block into a pass — a fail-open through the back door.
N6. Unsequenced shipment (no edges, no declaration, workspace HAS shipping history) blocks with token UNSEQUENCED_SHIPMENT, and the message NAMES BOTH remedies (add the real `blocks` edge, or declare the shipment a root).

FIXTURE QUALITY GATE (hardening F10, from docs/compound/2026-08-09-next-eligible-detail-scoping-and-vacuous-tiebreak-tests.md): each of the four derivation states must be independently REACHABLE and DISTINGUISHABLE by its fixture. A fixture in which two states would produce the same observation cannot assert either — that is a vacuous test, not coverage.
