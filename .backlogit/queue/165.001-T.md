Strictness is REQUIRED: an expectation that starts passing must FAIL the suite, otherwise the marker silently hides a behaviour change. 165.002-T flips them to ordinary assertions when it delivers the behaviour.

EXPECTED-FAILURE REASONS ARE CONSTRAINED (review-fix cycle 3, finding 1). Every strict expected-failure marker MUST be scoped to the SPECIFIC expected defect — the assertion it is allowed to fail on and the exception type it is allowed to raise. A fixture/setup error, an import or collection error, an unknown or unregistered `--phase` value, a typo, or any other incidental failure MUST NOT satisfy RED. Pin each marker with an explicit `raises=`/reason and assert the expected message or payload shape, so a test fails loudly on the WRONG failure instead of passing quietly as "still red". An unconstrained xfail is indistinguishable from a broken fixture.

It is therefore a CHARACTERIZATION test and MUST NOT be written as an expected failure.

GENESIS EXPECTATIONS — NARROW, NON-FAIL-OPEN RULE (review-fix cycle 2, finding 2). Genesis requires ALL of: G1 no edges and no `dag-root`; G2 no shipped-terminal shipment anywhere, live OR archived; G3 the candidate is the SOLE EXTANT NONTERMINAL shipment (no other queued/active record, live or archived); G4 no abandoned record anywhere. Assert EACH disqualifier independently so no single fixture can carry the whole rule vacuously:
N5a. GENESIS PASS — fresh workspace holding EXACTLY ONE shipment record and nothing else: passes with `predecessor_source: "genesis"`.
N5b. NO GENESIS FROM ARCHIVED SHIPPED HISTORY (G2) — a workspace whose only shipped-terminal shipments exist as ARCHIVED records is NOT genesis; an edge-less undeclared shipment there blocks as `unsequenced`. The probe must read `archived_status`/`archived_record_present`, never only live queue records; otherwise archiving or pruning history silently re-enters genesis and converts a block into a pass.
N5c. NO GENESIS WITH MULTIPLE PENDING SHIPMENTS AND NO SHIPPED HISTORY (G3) — a workspace holding several QUEUED shipments and nothing ever shipped: NONE of them is genesis. Assert this over at least two distinct candidates including a LATER-NUMBERED one, so the fixture proves a later-numbered edge-less candidate cannot silently pass. N5d. NO GENESIS FROM ABANDONED-ONLY HISTORY (G4) — a workspace whose only prior shipment record is `abandoned` (terminal but NOT shipped) is NOT genesis. Without G4, the G2 probe alone would admit it.
N5e. DECLARED ROOT STILL PASSES IN EVERY NON-GENESIS WORKSPACE — the same fixtures as N5b/N5c/N5d, with `dag-root` on the candidate, pass as `declared_root`. This proves the narrow genesis rule does not deadlock intentional roots.
