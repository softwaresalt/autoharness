In-memory read-time DAG assembler with three-colour cycle detection. Cycle = registry defect -> invalid, exit 2, zero nodes evaluated, never auto-broken. Upstream non-pass -> blocked_upstream. No persisted graph. Domain: code. Files: 1.

<!-- BEGIN:acceptance-criteria -->
* **INV-1**: no persisted graph. The assembler holds the graph in local scope and returns results, never a graph object.
* **INV-4**: cycle -> `invalid`, exit 2, and **zero nodes evaluated** — the evaluation COUNT is asserted, not merely the exit code.
* Cycle is never auto-broken.
* Upstream `failed`/`insufficient_evidence` -> downstream `blocked_upstream` (asserted NOT `passed`/`skipped`).
* Reported cycle node set is deterministic across runs.
* A validator cannot re-run an upstream producer (immutable evidence map).
<!-- END:acceptance-criteria -->

<!-- BEGIN:description -->
Plan unit **U5**. Create `src/autoharness/detectors/assembler.py`.

* Assemble the graph **in memory, at read time, on every invocation**. **Nothing persisted (Law 1)** — the graph is reassembled from the registry every run, so `backlogit_sync_index` cannot destroy it and no schema migration is ever needed.
* Three-colour DFS cycle detection over `depends_on`, mirroring the proven `_dag_detect_cycle` algorithm (`topology.py` L1842-L1870). Deterministic node iteration (`sorted`) so the reported cycle is stable.
* **Cycle -> `invalid`, exit 2, evaluate nothing, never auto-break.**
* Deterministic topological evaluation order.
* Upstream `failed` or `insufficient_evidence` -> downstream **`blocked_upstream`** — NEVER `passed`, NEVER `skipped`. Downstream silence on upstream failure is the fail-open class this programme is built to eliminate.
* A validator may consume upstream evidence but **may never re-run that node's producer** (D3) — enforced by passing an immutable evidence map.

**Execution posture**: test-first.
<!-- END:description -->

<!-- BEGIN:implementation-notes -->
**Depends on U1 and U3.**

**Decision D-3 — DE-RISKING (this is what keeps the task at medium, not high, complexity)**: implement a **self-contained cycle detector in this module** rather than refactoring `topology.py::_dag_detect_cycle`.

Rationale: the existing helper is typed to `ShipmentState` and lives in a 96 KB module on the critical path of the shipment topology gate. Generalizing it would put S1's blast radius into **P-001/P-016 enforcement code**. The algorithm is ~20 lines and proven; mirroring it is strictly cheaper and safer than generalizing it.

Architecture Strategist rated this P2 (duplication is normally a defect) and accepted it as justified against a materially worse alternative. RK5: the duplication is deliberate, recorded, and independently tested.
