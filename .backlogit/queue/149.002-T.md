Add an optional top-level `detectors` block to schemas/validation-gates.schema.json with mode as const report_only and additionalProperties:false per node. Domain: schema. Files: 1.

<!-- BEGIN:acceptance-criteria -->
* The `detectors` block is entirely optional; an absent block means zero nodes and behavior identical to today (back-compat asserted in U9).
* `mode` is `const: report_only` — a registry declaring `mode: blocking` fails **schema validation**.
* `additionalProperties: false` per node object.
* `node_id` pattern rejects malformed identifiers.
* Existing `lifecycle_hooks` and `telemetry` blocks validate unchanged.
<!-- END:acceptance-criteria -->

<!-- BEGIN:description -->
Plan unit **U2**. Extend `schemas/validation-gates.schema.json` (v1.0.0) with a top-level **optional** `detectors` block: an array of node declarations with

* `node_id` — pattern-constrained to the D1 scheme `det:<domain>/<detector-id>@<version>`
* `applies_when` — `changed_paths_any`, `shipment_has_items_of_type`, `workspace_surfaces_any`, `always`
* `producer` — `kind` enum `pure|ast|coverage|api|command`, `ref`, `tool_version_dims`
* `validator` — `ref`, `consumes`
* `depends_on`
* `severity` enum `critical|high|medium|low`
* `mode` — **`const: report_only`**
* `remediation` — `class` enum, `hint`, `target_refs`, `authority` enum

`additionalProperties: false` inside each node object, so an unknown key is a **registry defect** rather than silent tolerance.

**Execution posture**: schema-first. **No code in this unit** (width isolation).
<!-- END:description -->

<!-- BEGIN:implementation-notes -->
**Decision D-2**: extend the existing schema rather than create a new file — `031-DL` R4 names it the declaration extension point, and its root is already `additionalProperties: true`, so the block is additive and back-compatible.

**Decision D-4**: `mode` as schema **`const`**, not merely a default. A default can be overridden by a config edit; a `const` makes `mode: blocking` a registry defect. This makes silent promotion (RK4/D7) **structurally impossible** in S1 rather than merely discouraged. Constitution Reviewer rated this a strength.

Note: `producer.kind: command` is schema-declared but **NOT implemented** in S1 (see U3) — declaring it keeps the enum stable without opening a subprocess surface.
<!-- END:implementation-notes -->
