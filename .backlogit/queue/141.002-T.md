Land the AST structural isolation guard with a shrinking allowlist, and remove ambient-cwd coupling from the two smallest modules (8 of the 58 sites).

**Plan:** `docs/plans/2026-08-21-full-suite-test-isolation-plan.md` Task 2 (+ amendments A3, A4, H3 refinement)

## Test-first requirement
Add `tests/test_test_suite_isolation_contract.py`: an **AST-based** guard asserting that no module under `tests/` calls `tempfile.TemporaryDirectory` with a `dir=` keyword whose value is a `Path.cwd()` call.
- Use an AST visitor, NOT a line regex — a multi-line call would evade a regex (`docs/compound/2026-08-21-ast-based-structural-regression-guards-beat-line-regex.md`).
- **Amendment A3.** The guard asserts the ABSENCE of the anti-pattern (not the presence of a fix) and NAMES every offending file and line in its failure message.
- **Amendment A4.** The guard ships with an EXPLICIT allowlist seeded with the four known offenders: `test_gates_topology.py`, `test_backlog_root.py`, `test_gate_pipeline_topology_cli.py`, `test_gate_dag_readiness_cli.py`. This task removes `test_gate_dag_readiness_cli.py` and `test_gate_pipeline_topology_cli.py` from the allowlist in the SAME change that fixes their call sites, so the guard is GREEN at the end of this task and no commit carries a deliberately-red test.

## Scope of this task's call sites
- `tests/test_gate_pipeline_topology_cli.py` — 5 sites
- `tests/test_gate_dag_readiness_cli.py` — 3 sites

## Steps
1. **Per-call-site containment review (H3 refinement) — mandatory before editing.** For each of the 8 sites, determine whether the temp workspace being INSIDE the repository is semantically required (several of these tests exercise workspace-containment logic). Record the determination with a one-line justification per site.
2. Replace `dir=Path.cwd()` with a deterministic anchor:
   - containment REQUIRED → `dir=Path(__file__).resolve().parents[1]` (deterministic repo root)
   - containment NOT required → plain `tempfile.TemporaryDirectory()` (system temp)
   - **Never relocate a containment test to system temp.** Anchoring is always safe; relocating is not. Default to anchoring when uncertain.
3. Remove both modules from the guard's allowlist.

## Acceptance criteria
- AC-a. `tests/test_test_suite_isolation_contract.py` exists, is AST-based, names offenders by file and line, and is GREEN with an allowlist containing exactly `test_gates_topology.py` and `test_backlog_root.py`.
- AC-b. Zero `dir=Path.cwd()` sites remain in `test_gate_pipeline_topology_cli.py` and `test_gate_dag_readiness_cli.py`.
- AC-c. Every site has a recorded containment determination with justification.
- AC-d. Both modules pass IN ISOLATION before and after with IDENTICAL pass counts. No assertion is weakened. `tests/test_gate_pipeline_topology_cli.py` holds **victim #1**, so the the **assertion-integrity gate (AIG)** defined in `docs/plans/2026-08-21-full-suite-test-isolation-plan.md` applies to it: AIG-1 zero assertion-line edits, and every changed non-assertion line cited as N1 (anchor, permitted inside test method bodies), N2, N3, N4 or N6 per AIG-3/AIG-4.
