Make the workspace shipment record the SINGLE AUTHORITATIVE SOURCE for the implementation branch, with validated input, ONE resolution path, and a truthful statement of how the validator relates to git's own checker.

ONE SHARED resolve_expected_branches() across all four gate phases, with a precedence ladder of EXACTLY TWO RUNGS - explicit custom_fields.implementation_branch, then title-derived aliases - failing closed on a present-but-malformed explicit value and NEVER falling back. There is no third rung: the reserved workspace_convention tier was removed and stays removed. Its absence is asserted by a SCOPED EXECUTABLE CRITERION, not by a repository-wide ban on the literal token (such a ban is unsatisfiable, because the plan, these backlog records and the review history all have to name the rung in order to state that it is gone): no occurrence under src/autoharness/, in any schemas/*.json, or as a .autoharness/config.yaml key path; a frozen two-member resolution_source enum {explicit_contract, title_alias} making a third value unconstructible; and zero occurrences outside an explicitly identified historical set.

THE GATE'S OUTPUT IS CONSUMED, NOT JUST EMITTED. The topology gate emits selected_branch on success, and SHIP USES THAT EXACT VALUE for BOTH branch COMPARISON and branch CREATION. Emitting an authoritative value that no consumer reads leaves the workspace record authoritative in name only, and leaves Ship deriving a branch by its own independent rule - the precise divergence this feature exists to remove. The Ship template and its installed mirror are changed byte-identically, and the END-TO-END FIXTURE uses an explicit implementation_branch that DIFFERS FROM EVERY TITLE-DERIVED ALIAS, so a Ship that silently re-derived the name would fail. THIS CONSUMPTION CHAIN PRECEDES WORKAROUND RETIREMENT: retiring the live title-alias workarounds before Ship consumes the emitted value would leave no consumer of the authoritative field at all.

WORKAROUND RETIREMENT IS APPROVAL-GATED AND REVERSIBLE. Because it touches LIVE shipment records, 170.008-T carries operator approval naming the exact records and fields, a pre-mutation snapshot, and a pre-recorded rollback, as P2 hardening on the surfaces it directly touches.
