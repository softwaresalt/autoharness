Skill templates use generic {{OP_CREATE_MCP}}/{{STATUS_*}} variables INSIDE branches explicitly scoped to a non-active backlog tool, so a branch introduced by "When backlog-md is the installed backlog tool" renders BACKLOGIT values whenever backlogit is active - wrong in every workspace it appears in. Note the coupling: decision D3 selected keep-but-demote, so option (a) "eliminate the second tool and the trap disappears" is NOT available and the real fix is required here. SELECTED SHAPE (B): make the tool-scoped branch a block the installer resolves per tool, so generic tokens inside it bind to that blocks tool. REJECTED (A) per-tool tokens: multiplies the variable table by the number of tools and every new token is a new unresolved-placeholder opportunity; and using the wrong token would be indistinguishable from the right one, whereas an unbound block is a structural error the renderer can reject. BINDING H1: FAIL CLOSED on an unbound tool-scoped block - a block declaring no tool, or a tool the registry set does not contain, must ERROR rather than fall back to the active tool. Silent fallback is the present defect. BINDING H2: no unresolved {{ may survive for EVERY supported tool binding, not only the active one. BINDING H3: templates without tool-scoped blocks must render byte-identically before and after; whole-corpus render diff is the acceptance evidence. PLAN REVIEW FINDING 3 (P1): assert parity on NORMALIZED output (trailing-whitespace and line-ending normalized) and ENUMERATE the templates covered, so an intentional change is a visible edit to that enumeration rather than a silent relaxation. PLAN REVIEW FINDING 2 (P1) BOUND: exactly ONE new construct - no general templating language, no expression evaluation, no nesting beyond one level. Pure lookup against a fixed registry-derived table; no eval, no shell, no path resolution from template content (finding 7). SCOPE BOUND: fix the MECHANISM and convert only branches that currently render wrong; a branch that renders correctly today is left alone. Update template-authoring guidance where this pattern is documented (finding 5). Source: 57A43F55.
