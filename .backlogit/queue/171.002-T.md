Define the review-artifact schema and the review-history/ path contract that makes review history immutable and per-attempt addressable.

ONE IMMUTABLE ARTIFACT PER REVIEW ATTEMPT, written to docs/reviews/review-history/{plan-slug}-attempt-NN.md and NEVER appended to or edited after creation. A correction to an artifact already written is published as a separate immutable erratum or supplement artifact, never as an edit.

Each artifact carries plan_id, plan_path, plan_revision, attempt, verdict, findings and timestamp, and validates against this schema. THE SCHEMA IS THE PRIMARY IDENTIFYING CRITERION for a historical document, which is what allows the leak predicate in 171.013-T to be NAMING-INDEPENDENT: an artifact renamed to a plan-looking path still validates as a review artifact.

The mutable selection surface (docs/reviews/{plan-slug}-plan-review.md) is defined in 171.003-T and is the ONLY place a latest-attempt pointer may live; an artifact never points forward.

EARLIER ATTEMPTS ARE NEVER OPERATIVE. An artifact from any attempt, including the immediately preceding one, is historical evidence rather than an input the current review reasons over. The only operative document is the single plan_role: active revision. This separation is what makes REVIEW_INPUT_HISTORY_LEAK decidable at all.

Scope: schemas/ and the docs path contract; no assembly code (171.004-T), no detection logic (171.013-T), no tests (171.015-T). Entry point of 179-S: no predecessors. Blocks 171.003-T and 171.015-T.
