Define the review-artifact schema and the review-history/ path contract that makes review history immutable and per-attempt addressable. ONE IMMUTABLE ARTIFACT PER REVIEW ATTEMPT, written to docs/reviews/review-history/{plan-slug}-attempt-NN.md, never appended to after creation. Each artifact carries plan_id, plan_revision, attempt number, verdict, findings and timestamp. The mutable selection surface (docs/reviews/{plan-slug}-plan-review.md) is defined in 171.003-T and is the ONLY place a latest-attempt pointer may live; an artifact never points forward. This separation is what lets REVIEW_INPUT_HISTORY_LEAK be decidable at all: an input set assembled for attempt N must contain the current plan revision and MUST NOT contain earlier attempt artifacts.
