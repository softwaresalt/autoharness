1. Validate tag matches pyproject version (L26-L45)
2. Extract changelog for this version (L47-L67) — must yield NON-EMPTY notes
3. uv build (L77)
4. uvx twine check dist/* (L80)
5. Check PyPI pre-publish state (L82-L104)
6. Publish distribution to PyPI (L109-L112, pypa/gh-action-pypi-publish SHA-pinned @cef221092ed1bacb1cc03d23a2d87d1d172e277b)
7. Smoke test published package from PyPI (L114-L138)
8. Create/update GitHub Release

PUBLISHED-PACKAGE SMOKE EVIDENCE (capture, do not just observe):
- uv tool run --isolated --no-config --from "autoharness==1.5.0" autoharness version  -> must equal EXACTLY "1.5.0"
- uv tool run --isolated --no-config --from "autoharness==1.5.0" autoharness home     -> must resolve
- Record the PyPI project page URL and the GitHub Release URL as closure evidence.

VALIDATION WINDOW: the workflow polls PyPI for up to 280 SECONDS (L127). Allow the FULL window before declaring failure. Slow PyPI/CDN propagation is NOT a publish failure and must NOT trigger rollback.

*** ROLLBACK — DETERMINE WHICH SIDE OF THE PUBLISH STEP THE FAILURE OCCURRED ON BEFORE TAKING ANY ACTION ***

FAILED BEFORE the PyPI publish step (steps 1-5): SAFE.
  -> Delete the tag (git push --delete origin v1.5.0), fix, re-tag. NO version is burned.
  -> Tag deletion is permitted ONLY on this path and requires operator confirmation.

FAILED AT OR AFTER the PyPI publish step (steps 6-8): VERSION PERMANENTLY BURNED.
  -> DO NOT retry 1.5.0. DO NOT delete the tag — deleting it does NOT unpublish and creates misleading history.
  -> ESCALATE TO THE OPERATOR. Any remediation ships as 1.5.1.

PyPI reports 1.5.0 already exists at pre-publish -> STOP and escalate (version already burned).
Published smoke test fails AFTER a successful publish -> do NOT yank reflexively; capture evidence, escalate, prepare 1.5.1.

ALSO: confirm the PyPI publish credential / OIDC trusted-publishing configuration is in place when reviewing the workflow (plan-review P2-1). A bad credential fails before upload, so no version is burned — but discovering it here wastes a tag.
