Preserve the full Recommended Action literals in the pre-merge-install checklist report when stdout is redirected or non-TTY, unblocking the required `test` / `ci gate` checks on PR #373.

ROOT CAUSE (confirmed statically; exactly one call site): `scripts/deploy-harness.ps1` line 291 renders the checklist as `$rows | Format-Table -AutoSize | Out-String | Write-Host`. PowerShell's `Out-String` falls back to an 80-column default when stdout is redirected/non-TTY, clamping `-AutoSize` and ellipsis-truncating the RecommendedAction column ("retain-pre...", "needs-inst...") before the asserted literals complete. The sh counterpart (`scripts/deploy-harness.sh` `invoke_checklist`) already uses fixed-width `printf '%-24s'` and is NOT defective — which is why only the Ps1 execution class fails.
