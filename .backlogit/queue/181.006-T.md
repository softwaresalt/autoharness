ENTRY POINT, keyword-only: resolve_harness_surfaces(*, workspace_root: Path, autoharness_home: Path, shipment_id: str) -> HarnessResolution. READ-ONLY: writes no file, creates no directory, sets no environment variable, spawns no process and mutates no backlog record. Safe to call repeatedly and safe to call during crash recovery. It reads the filesystem ONLY through harness_read.

PUBLIC TYPES. HarnessState (HARNESS_READY, NO_HARNESS, UNRESOLVED); SurfaceStatus (PRESENT, MISSING, STALE, INVALID); DeclarationKind (SURFACES, NONE, INVALID); frozen dataclasses TaskDeclaration, SurfaceResolution, Diagnostic and HarnessResolution with exactly the fields the governing plan enumerates. Diagnostic REPLACES the free-text errors tuple: reason_code from the closed set, subject_kind, root-relative subject, and a short machine-authored detail. NO RAW EXCEPTION TEXT, NO TRACEBACK, NO ABSOLUTE PATH, NO USER DIRECTORY AND NO MACHINE NAME is ever placed in a Diagnostic.

FROZEN ENV SNAPSHOT. _BACKLOG_ENV_ALLOWLIST = ("BACKLOGIT_WORKSPACE_DIR",). At entry the resolver captures the allowlisted values as an immutable snapshot, calls the EXISTING resolve_backlog_root from src/autoharness/backlog_root.py EXACTLY ONCE under that snapshot, and never reads os.environ again. The returned root must be a component-wise descendant of the canonical workspace_root or the resolution is UNRESOLVED/BACKLOG_ROOT_OUTSIDE_WORKSPACE. The snapshot is bound into inputs_sha256, so a redirected root is visible in the evidence rather than silent.

CANONICAL SOURCE. Shipment membership comes SOLELY from custom_fields.items. For the shipment record and every member ID, EXACTLY ONE record must exist across the live queue and the archive combined; zero, multiple, or unparseable front matter is UNRESOLVED. Only -T task records are declaration sites; a member -F feature contributes no TaskDeclaration but is still subject to the exactly-one-record rule.

TOTAL DECLARATION FUNCTION. Every member task yields exactly one TaskDeclaration across the seven rows of the plan's grammar table. ABSENCE IS NOT CONSENT: a task with no harness-surface label is INVALID/DECLARATION_ABSENT, never an implicit none.

SINGLE CLASSIFICATION RULE. The plan's classification table is implemented once. Installed path is deterministically .github/skills/<id>/SKILL.md under workspace_root; the manifest must contain EXACTLY ONE artifacts entry whose path equals that exact string AND whose template equals the exact string skills/<id>/SKILL.md.tmpl; template path is that value under autoharness_home.

RENDERING FROM THE MANIFEST'S TOP-LEVEL variables_used. The manifest carries ONE TOP-LEVEL variables_used mapping that applies to the whole manifest. Entries under artifacts: carry path, primitive, template, checksum and an optional note - THEY DO NOT CARRY variables_used, and this module must not look for it there. The matched entry supplies ONLY path, template and checksum. Uppercase {{NAME}} placeholders only; a placeholder with no key in the top-level mapping is VARIABLE_UNRESOLVED. The WHOLE top-level mapping is bound into inputs_sha256, not merely the consumed keys. Canonical bytes: decode UTF-8, translate CRLF -> LF and lone CR -> LF, nothing else. PRESENT requires rendered canonical bytes equal to installed canonical bytes AND manifest checksum equal to the SHA-256 of the installed canonical bytes; either alone is STALE.

SEPARATED TRUST ROOTS. Backlog records, the manifest and installed .github/skills/** are asserted under workspace_root; templates under autoharness_home. The roots are canonicalized independently and NEVER substituted. When the two coincide, as in this self-hosting repository, each read still declares which root it asserts containment against.

AGGREGATION A1-A6, evaluated in order, stopping at the first match: A1 precondition failure -> UNRESOLVED/2; A2 any declaration INVALID -> UNRESOLVED/2; A3 any surface INVALID -> UNRESOLVED/2; A4 union of declared surface IDs empty -> HARNESS_READY/0/NO_SURFACES_REQUIRED with empty surfaces; A5 any surface MISSING or STALE -> NO_HARNESS/1; A6 all PRESENT -> HARNESS_READY/0/ALL_SURFACES_PRESENT. INVALID DOMINATES: A2 and A3 precede A4, so one malformed task among otherwise-none declarations is UNRESOLVED, never a vacuous ready. Ties resolve deterministically from the first entry in emitted order - declarations by ascending task_id, surfaces by ascending surface_id.

DIGESTS. Canonical JSON is json.dumps(obj, sort_keys=True, separators=(",", ":"), ensure_ascii=True).encode("utf-8"). Each bound input contributes {"label": ..., "sha256": ...} or, when unreadable, {"label": ..., "sha256": null, "absent": "<REASON_CODE>"} - the EXPLICIT ABSENCE SENTINEL, so an unreadable manifest and a zero-byte manifest produce different preimages. Bound in fixed label order: env_snapshot, backlog_root, shipment_record, declarations, manifest, manifest_variables_used, then template:<surface_id> and installed:<surface_id> ascending. inputs_sha256 = sha256(b"autoharness/harness-surfaces/inputs/v1\x00" + canonical_json(list)). INPUTS_SHA256 EXCLUDES ITSELF - it is computed over the bound input list only, never over the result document or any field of HarnessResolution. There is no self-referential digest anywhere in this unit.
