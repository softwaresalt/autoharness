BASELINE TASK - AND AN ELEVATED, APPROVAL-GATED BINARY ACQUISITION. This task re-establishes the authoritative SAFE_CLOSE behavioural observation baseline against the checksum-pinned backlogit v1.9.0 binary that CI installs (sha256 5bf29fda...87de), and makes that baseline the authoritative evidence for every downstream fixture. The local 1.10.1+dirty build is demoted to explicitly labelled corroboration and may never be the sole basis for an asserted exit code or message.

ACQUIRING AND INSTALLING v1.9.0 IS ELEVATED AND DESTRUCTIVE, NOT ORDINARY TEST SETUP. The tool being installed or replaced is the one that owns every backlog record in this workspace; a wrong install can leave the workspace unable to read its own queue. ORDINARY PULL-REQUEST REVIEW DOES NOT SATISFY THIS GATE, and nothing in this task may claim that it does: PR review approves a merged diff, while this action mutates the executing machine before any diff exists.

SEVEN BINDING PRECONDITIONS, every one of which must hold before a single byte is written. (1) EXPLICIT IN-SESSION OPERATOR APPROVAL for this specific action, naming the version being installed and the fact that a binary is being placed or replaced; a standing authorization, an autopilot directive or an approved pull request is NOT sufficient and may not be cited as sufficient. (2) WORKSPACE-CONTAINED INSTALL into a git-ignored tool directory inside this repository's working tree, invoked by explicit path; it must not replace, shadow or modify any machine-global, user-global or PATH-resolved backlogit installation, and must not write outside the working tree - and never into a %TEMP% workspace, which is the exact P-005 violation this plan exists to correct. (3) SHA-256 VERIFICATION AGAINST THE CI PIN BEFORE the artifact is made executable or invoked; a MISMATCH HALTS - never retried past, never warned through, never resolved by re-downloading. (4) BOUNDED EXECUTION in careful or investigate-first mode, with an explicit step budget and an operator-visible log of every command issued; never unattended and never autopilot. (5) NO LIVE BACKLOG MUTATION, enforced by construction: every observation command runs against disposable fixture records under tests/, the pinned binary is never invoked with this workspace as its --cwd, a pre-flight assertion records the .backlogit/ tree state, and a post-flight assertion proves it byte-identical. (6) ROLLBACK AND RESTORATION DEFINED BEFORE THE ACTION: the pre-existing binary's location and version are recorded first; rollback is deletion of the workspace-contained binary directory, because no global state was touched; if the pre-state cannot be captured, this task HALTS rather than proceeding. (7) CLEANUP INSIDE THIS TASK, not as a follow-up: the workspace-contained binary directory is removed at completion unless the operator explicitly directs retention, in which case it is git-ignored and named in the completion record so it cannot become undeclared state.

APPROVAL WITHHELD MEANS HALT AND REPORT. This task does not silently fall back to asserting the 1.10.1+dirty observations - asserting one binary's behaviour as another binary's expectation is precisely the unsound claim the plan's binary-version divergence constraint prohibits - and it does not degrade to a skip, which would delete the release unit's entire evidentiary value. A halted baseline blocks 173.001-T, 173.002-T, 173.003-T, 173.004-T, 173.005-T and 173.009-T through the existing dependency edges, which is the correct outcome: with no authoritative baseline there is nothing sound for the fixtures to assert.

MACHINE-ENCODED PREDECESSOR. This task blocks 173.001-T, 173.002-T, 173.003-T and 173.004-T (the four hermetic fixtures), 173.005-T (the portable upstream report) and 173.009-T (the version-aware fixture contract), so no fixture can pin its assertions to the wrong binary. Entry point of 181-S: no predecessors.

ACCEPTANCE. The completion record carries the operator approval naming the version and the install or replacement, the verified SHA-256 matching the CI pin, the workspace-contained install path, the pre-existing binary's location and version, the pre-flight and post-flight .backlogit/ assertions, and either the cleanup or the explicitly authorized retention. Divergences between the v1.9.0 observations and the 1.10.1+dirty corroboration are recorded rather than suppressed and are carried into the upstream report.
