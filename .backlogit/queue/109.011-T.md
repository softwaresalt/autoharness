* Entrypoint runs `gate pipeline-topology` in ci mode and returns fail-closed exit codes.
* NON-SHIPMENT-SCOPED CI INVOCATION: the entrypoint runs WITHOUT a human-supplied `--shipment`; it resolves the target deterministically from backlogit shared state (currently-claimed active shipment) and/or the branch under validation, and resolves the phase deterministically to `ambient` (at-most-one-active, validating the resolved target when one exists — zero-active ordinary CI is non-blocking). The target-INDEPENDENT invariants (the at-most-one-active count + the detect-before consistency scan) ALWAYS run fail-closed regardless of whether a target resolves; the target-DEPENDENT checks (branch-to-claimed-shipment ownership and shipment-scoped readiness) run ONLY when a target resolves. So a zero-active / no-target CI run PASSES (ordinary CI non-blocking), a mismatched single active blocks, and 2+ active blocks. The deterministic resolution rule is documented.
* Enforces the active-shipment + branch-ownership invariants by re-reading backlogit state from the SYNCED repo (server-side DETECT-AT-SYNC re-validation; NOT a lock or lease and NOT real-time serialization — divergence is caught at CI/merge, fail-closed on ambiguity).
* Does not depend on machine-local worktree state (documented: worktree uniqueness is local-only).

This is an honest DETECT-AT-SYNC re-validation — it catches divergence when checkouts converge in CI/merge, NOT a lock or lease and NOT real-time serialization (per 012-DL / 109-F documented local+cross-machine TOCTOU limitation; fail-closed on ambiguity). Runs non-shipment-scoped: the target is resolved deterministically from the currently-claimed shipment / branch under validation (no human-supplied `--shipment`) and the phase is deterministically resolved to `ambient` (at-most-one-active, zero-active ordinary CI non-blocking), so the target-INDEPENDENT at-most-one-active invariant (with the detect-before scan) always runs fail-closed while the target-DEPENDENT ownership/readiness checks run only when a target resolves.
