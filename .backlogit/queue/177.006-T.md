COVERAGE AND COMPOSED-STATE GATE (decision D6). Attempt 01 found that the plan's declared pass state was unreachable because a declared property had no determining task, and that the previous hardening pass never asked whether one existed. This task makes the coverage check STRUCTURAL rather than incidental, and executes the pass/fail transition mechanically so the gate is a check rather than a claim. TWO CHECKS, IN ORDER. (1) COVERAGE: every property I1-I7 has an assigned DETERMINING task in the plan's Property coverage table, and that task is a determining task - 177.004-T, 177.005-T, 177.001-T or 177.002-T - NEVER the authoring task 177.003-T alone. A property whose only assignment is the authoring task FAILS THIS CHECK OUTRIGHT, because an authoring task cannot produce an observation and an authoring-derived verdict rests on assertion, which R3 and H2 have already ruled insufficient. (2) EVIDENCE: every property's row in the coverage ledger of docs/spikes/2026-09-18-conformance-isolation-findings.md is DETERMINED - a verdict is present AND the evidence shape named in the Property coverage table is present in the artifact. A verdict supported only by a documentation citation resolves to ABSENT. Then APPEND A SINGLE VERDICT LINE to the findings artifact, in exactly one of these two forms: "COMPOSED_STATE: ISOLATION_CHARACTERIZED | determined=7 | undetermined=0 | checked=<date>" when every property is DETERMINED, or "COMPOSED_STATE: ISOLATION_UNDETERMINED | undetermined=<n> | properties=I<x>,I<y>" otherwise. A PARTIALLY-CLASSIFIED RESULT IS A FAIL, NOT A PARTIAL PASS. ISOLATION_UNDETERMINED blocks 181-S harvest and NAMES which properties are open, so a reader can check the verdict against the ledger without re-running the spike; a verdict line whose count disagrees with the ledger is ITSELF A FAIL. A missing artifact, or one with no completed coverage ledger, is ISOLATION_NOT_OBSERVED, which is distinct from ISOLATION_UNDETERMINED and is NEVER a pass. THE FLOOR STANDS EITHER WAY: 181-S degrades to evidence-and-documentation only and 002-C stays blocked; what the fail state prevents is 181-S inheriting an undetermined property as an assumption.
