Introduce the segment model and extend replay/preflight across segments, before any rollover exists. (1) Add segment enumeration + monotonic zero-padded generation naming as module constants in jsonl_sink.py (active = execution_epochs.jsonl; sealed = execution_epochs.jsonl.NNNNN); enumeration yields stable oldest->newest order. (2) Extend the replay lookup (scan_epoch_digest/find_epoch_digest) to scan the active segment plus all sealed segments; a match in ANY retained segment counts. No rollover code yet; test the identity-mismatch path by simulating an active-segment replacement. Files: src/autoharness/telemetry/jsonl_sink.py, tests/test_telemetry_jsonl_sink.py. <=3 files, <=5 functions, <=4 test scenarios. TDD: write failing tests first.
