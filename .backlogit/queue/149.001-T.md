Define NodeSpec/Evidence/NodeResult frozen dataclasses and the closed 8-value verdict vocabulary with report-only exit mapping. Domain: code. Files: 2.

<!-- BEGIN:acceptance-criteria -->
* All three dataclasses frozen, with `to_dict()` matching the `CheckResult`/`GateResult`/`TopologyResult` convention.
* Verdict vocabulary is exactly the 8 named values — an added verdict FAILS the suite (contract-freeze, verification step 1). This is what stops S2-S10 widening the contract silently.
* `waived` is declared but **unreachable** in S1 (no waiver engine) and asserted unreachable.
* `mode` is constructor-fixed to `report_only`; `NodeSpec` exposes no setter.
* Verdict->exit mapping: 0 for everything except `invalid` -> 2.
<!-- END:acceptance-criteria -->

<!-- BEGIN:description -->
Plan unit **U1**. Create `src/autoharness/detectors/__init__.py` and `src/autoharness/detectors/contract.py`.

* `NodeSpec` (frozen): `node_id` (D1 scheme `det:<domain>/<detector-id>@<version>`), `domain`, `detector_id`, `version`, `applies_when`, `producer`, `validator`, `depends_on`, `severity`, `mode`, `remediation`.
* `Evidence` (frozen): `node_id`, `payload`, `provenance`.
* `NodeResult` (frozen): mirrors `CheckResult` field-for-field (`name`, `status`, `token`, `message`, `details`) PLUS `verdict`, `provenance`, and `excluded_by` (FC2). `to_dict()` matches the existing convention.

**Verdict vocabulary — closed, exactly 8**: `passed`, `failed`, `insufficient_evidence`, `blocked_upstream`, `not_applicable`, `skipped`, `waived`, `invalid`.

**Verdict -> exit mapping**: report-only column of D5 — everything maps to 0 except `invalid` -> 2.

**Execution posture**: test-first.
<!-- END:description -->

<!-- BEGIN:implementation-notes -->
**Decision D-1**: `NodeResult` **mirrors** `CheckResult` rather than subclassing it. `CheckResult` is a frozen dataclass in a 96 KB high-traffic module; mirroring avoids coupling the detector package to topology's import graph while keeping D5's 'reuse unchanged' intent.

**Decision D-6**: `waived` is in the vocabulary but unreachable — keeps the vocabulary closed and stable for S10 without importing waiver authority into S1 (split (c)).

Architecture Strategist P1: contract stability is the real risk since S2-S10 all depend on this. Mitigated by the contract-freeze test and by the monitoring trigger — if S2's first detector needs a contract change, that is the RK1 signal arriving late.

Add no field S1 does not itself exercise, except `waived`.
