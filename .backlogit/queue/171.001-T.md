Define the durable plan identity schema that makes "the single governing plan" a machine-decidable property, and the immutable legacy boundary that bounds its one exemption.

THE SEVEN NORMATIVE IDENTITY FIELDS, and no other vocabulary for the same surface: plan_id (stable across renames and revisions); plan_role, an enum of active | superseded | history; revision (monotonic integer); supersedes; superseded_by; source_history; review_manifest.

THE ROLE FIELD IS plan_role AND NEVER status. Plan frontmatter already carries status on a different axis (draft | reviewed), and overloading it would make the single-active constraint undecidable on exactly the documents it governs.

supersedes AND superseded_by ARE REPO-RELATIVE PATHS OR null, NEVER (plan_id, revision) PAIRS. PLAN_SUPERSEDES_CYCLE is specified to fire on "cyclic OR UNRESOLVABLE", and unresolvability presupposes a reference that resolves to a document. superseded_by is null if and only if plan_role is active. source_history is an ordered list of repo-relative paths to the immutable review artifacts consumed, in attempt order; review_manifest is a repo-relative path to the structured latest-verdict record.

THE SINGLE-ACTIVE CONSTRAINT KEYS ON plan_id, NOT ON FILE PATH: at most one document may carry plan_role: active for a given plan_id, so renaming or copying the file cannot manufacture a second governing plan. The path is the supersession edge; plan_id is the identity.

LEGACY BOUNDARY: also generate and commit schemas/plan-legacy-allowlist.json ONCE, at contract introduction, as the exhaustive set of repo-relative paths of every plan document existing under docs/plans/ at that commit. The file is thereafter append-never and edit-never, and membership is by EXACT repo-relative path with no glob, prefix, directory or date matching. A plan ON the allowlist that carries no plan_id is classified PLAN_LEGACY_UNIDENTIFIED (reported, non-blocking). A plan NOT on the allowlist that omits plan_id or any other required identity field is BLOCKING PLAN_IDENTITY_MISSING. A DATE CUTOFF IS EXPLICITLY REJECTED: any date a verifier can read is author-controlled, so a new plan could be backdated into the exemption; joining a committed path allowlist requires editing a file the contract declares immutable, which is itself a reviewable diff.

Emits PLAN_IDENTITY_MISSING and PLAN_MULTIPLE_ACTIVE. Scope: schemas/ and the plan frontmatter definition only; no verifier code (171.006-T) and no tests (171.015-T). Entry point of 179-S: no predecessors. Blocks 171.004-T, 171.005-T and 171.015-T. This task defines identity for plans authored from here forward and MIGRATES NOTHING; repository-wide migration is deferred to 175.003-T and nothing in 179-S depends on it.
