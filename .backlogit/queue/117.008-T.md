SIZE: M. COMPLEXITY: medium. (Two independent axes; also emitted as structured backlog fields.) Shipment 2 (P0). Create src/autoharness/supervise/session.py implementing the explicit session state machine: INIT -> LOCKING -> BOOTSTRAPPING -> PREFLIGHT -> RESOLVING -> LAUNCHING -> RUNNING -> {CANCELLING | RESTARTING | DRAINING} -> {EXITED | FAILED | REFUSED}. The legal-transition table is DATA, not control flow. FAIL CLOSED (H2): any transition absent from the table raises ErrorKind.ILLEGAL_TRANSITION - there are no implicit transitions and no permissive fallback. DRAINING is the ONLY path from RUNNING to a terminal state and always flushes the journal, releases the lock, and reaps the child. REFUSED (lock contention) is a DISTINCT terminal state from FAILED, because a contended workspace is a policy outcome, not an error. Every transition emits exactly one SessionPhaseChanged event. Pure module: no I/O, no spawning, no threads - it is driven by the orchestrator. Tests enumerate the full transition table, assert every illegal transition raises, and assert terminal states are absorbing.
