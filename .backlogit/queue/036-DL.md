# context_tier on model_routing routes and agent frontmatter; new generic Ship default; durable dogfood Ship pin

## Problem Frame

<!-- BEGIN:problem-frame -->
Operators need a per-route context capacity (context_tier, default "default"), and the generic install Ship route should default to openai/gpt-6-luna/xhigh/long_context. The schema route objects reject extra keys (additionalProperties: false). The _ship/_stage templates render frontmatter from TIER_2/TIER_3 rather than the P-013.5 role variables, so this repository's claude-opus-5.5 Ship frontmatter is hand-maintained and would revert on re-install. That conflicts with the BINDING operator ruling (2026-09-27T13:18:02-07:00) that this repository's Ship stays claude-opus-5.5/anthropic. Full analysis: docs/decisions/2026-09-27-close-evidence-frontmatter-context-tier-staging-deliberation.md (F-C1 to F-C5).
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
(1) Additive schema enum, per-field fallback, fresh-install-only Ship seed, and role-variable binding of the pipeline agent templates as the durable pin [chosen]. (2) Record the pin in overrides: [rejected: a second source of truth]. (3) Bump schema_version [rejected: const invalidates all existing configs; F02FD596 precedent]. (4) Migrate existing installs to the new Ship default [rejected: silent model change; tune proposes only when Ship has no explicit route].
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
D-C1 through D-C7. context_tier enum is "", default, long_context (provider-agnostic), with ROUTING_DEGRADED when it cannot be honored. Fallback is role -> tier -> default, and nested escalation -> tier3 -> default. context_tier is excluded from the same-route guard and from nonEmptyRouteFields. The Ship default is a fresh-install seed only, and tune proposes only when no explicit Ship model_family exists. No schema_version bump. D-C6 (binding): the templates bind to SHIP_*/STAGE_* role variables, the explicit dogfood config Ship route is kept, and a pin regression test is added; dogfood Ship context_tier is "default". Reviewer routes are deferred. Plan: docs/plans/2026-09-27-context-tier-model-routing-plan.md.
<!-- END:chosen-direction -->

Operator confirmation of D-C1 through D-C5 and D-C7. The dogfood Ship context_tier value is undecided by the operator (default is used). Whether other existing workspaces adopt the new Ship default stays opt-in via tune proposal.
