TDD RED PHASE - ADAPTER ARGUMENT HARDENING. Author the contract tests for the autoharness checkpoint create adapter's argument surface and OBSERVE THEM FAILING before the adapter exists.

MUTUALLY EXCLUSIVE INPUT OPTIONS. The ambiguous --state-dump <path-or-json> is REPLACED by two explicit, mutually exclusive options: --state-dump-file <path> and --state-dump-json <json>. Assert that supplying both is an error, that supplying neither is an error, and that a JSON document that happens to look like a path (or a path that happens to look like JSON) is never guessed at. A single option whose meaning depends on the shape of its own value is undecidable at the boundary and is the defect this replacement removes.

ORIGIN IS NOT A PUBLIC OPTION. Assert that no --origin flag is reachable from the command line. The create path binds origin to the internal constant "harness"; the historical origin is reachable ONLY from the internal scanner. An operator-settable origin would let a caller select the reported-not-blocking historical branch for an author-time write, defeating the gate.

PATH HARDENING on --state-dump-file: workspace containment (a resolved path outside the canonicalized workspace root is rejected), rejection of non-regular files (directory, FIFO, device, socket), and rejection of symlink, junction and reparse-point components anywhere in the resolved chain. Assert containment is evaluated AFTER full canonicalization, so ../ traversal and link indirection cannot re-enter from outside.

BOUNDS on the parsed payload, each asserted independently: maximum serialized size, maximum nesting depth, maximum string length, and maximum collection length. Each bound rejects at its own limit with its own message.

ARGV AND SHELL DISCIPLINE: the delegated backlogit invocation uses a FIXED ARGUMENT VECTOR with shell=False; no argument is interpolated into a shell string. Assert the -- option terminator is honoured and that a value with a LEADING HYPHEN is carried through as a value, never re-parsed as a flag.

NO-WRITE / NO-DELEGATE ON EVERY FAILURE PATH. For EACH validation failure above, assert the adapter exits non-zero, writes nothing, and never reaches the delegated create call. Validation is strictly pre-write because a written checkpoint cannot be repaired through the official create operation.

IMPORT SAFETY (BINDING): this module imports cleanly under unittest.defaultTestLoader with zero loader.errors and zero _FailedTest placeholders. The not-yet-existing autoharness.checkpoint boundaries are loaded INSIDE the test body through a _load_boundary() helper, never at module scope, so every declared test individually executes and fails with its own declared marker in its own detail_text. A module that fails at import is a missing observation, not a valid red.
