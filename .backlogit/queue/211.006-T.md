Plan unit T5 (hardening H5, H12, H13). New src/autoharness/shipment_close/supervisor.py (python -m entry; accepts only a journal dir path): start with the platform probe tests (detached survival, descendant-group/Job Object membership, open-writer probe); if a probe cannot pass on the platform, stop and report. Reads the EXACT argv from protected launch.json (never the redacted copy), authenticates its argv_sha256 against the invoking record and re-hashes the binary before spawn, spawns the child with stdout/stderr OS-redirected to the journal files (no pipes), kills the process group on timeout, after the direct child exits proves the descendant group is quiescent (POSIX process-group liveness probe then group kill; Windows Job Object membership), kills survivors, ADDS an open-writer probe for escaped writers (Windows exclusive-open CreateFile share mode 0; Linux /proc/*/fd scan; otherwise unproven => fail closed), marks the capture drain_incomplete so successful finalization fails closed (unknown membership also fails closed), and persists the per-stream quiescence verdict (proven, method, survivors_killed, byte counts) in exit.json atomically BEFORE any finalization. run_journaled in runner.py returns a BoundedRunResult by streaming the journal files through StreamCapture (parse buffer and cap semantics preserved). Tests: port test_lingering_grandchild_does_not_hang_and_marks_drain_incomplete (same-group) AND an escaped-session (setsid/start_new_session) grandchild holding stdout; a redaction-triggering --message reaches the child byte-for-byte; detached-survival probe (child outlives a killed launcher; skipped with reason where the platform forbids). Deterministic tests only (sentinel files, bounded sleeps). Gate: PYTHONPATH=src python -m unittest discover -s tests.
