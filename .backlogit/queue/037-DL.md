# Agent and skill frontmatter conformity contract (bare model: keys, skill routing keys)

## Problem Frame

<!-- BEGIN:problem-frame -->
After auto-tune, the backlogit workspace still had bare `model:` keys on sqlite-reviewer and go-mcp-expert. Audit: neither agent comes from an autoharness template (the only generated tech reviewer is {{PRIMARY_LANGUAGE_LOWER}}-reviewer), so both are workspace-authored, and tune preserved them but had no detector. No autoharness template or mirror has a bare model: key, and no skill has a routing key. Real nonconformities: community adr-generator has no routing keys; the dogfood auto-tune and auto-mergeinstall agents have no routing keys; 31 skills have no name:. verify checks only the three pipeline agents. Full analysis: docs/decisions/2026-09-27-close-evidence-frontmatter-context-tier-staging-deliberation.md (F-B1 to F-B4).
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
(1) A single code contract module, plus verify (managed fail-closed / workspace-authored advisory), tune proposals, and remediation [chosen]. (2) Fail closed on every agent file, including workspace-authored ones [rejected: it violates override preservation]. (3) Warn-only everywhere [rejected: autoharness-generated defects would go unenforced].
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
D-B1 through D-B6, as amended by plan review (operator-confirmed 2026-09-27T22:50-07:00). Tier-routed agents: required name, description, max_subagent_tier, subagent_depth, model_family, model_provider, reasoning_effort. Plugin-global agents (auto-tune and auto-mergeinstall, the agents listed in the self-install plugin.json agents[]; D-B5): required name, description, max_subagent_tier, subagent_depth, and route-value keys (model_family, model_provider, reasoning_effort, context_tier) are forbidden, because the files ship verbatim to every plugin user. Bare model is forbidden on every agent. Skills: required name and description; every model-routing and tier key is forbidden (P-013.5 leaf executors). Verify fails closed on manifest-managed files whether or not they were edited (D-B6), and is advisory with migration_proposals on workspace-authored ones. Tune proposes and never auto-applies. Remediation covers adr-generator (tier-routed), auto-tune and auto-mergeinstall (plugin-global, B3), the 31 skill name: keys, and the P-013.1/P-013.4 clarification (B7). Plan: docs/plans/2026-09-27-agent-skill-frontmatter-conformity-plan.md (authoritative where this summary and the plan differ).
<!-- END:chosen-direction -->
