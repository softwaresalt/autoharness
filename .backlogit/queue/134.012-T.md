<!-- BEGIN:description -->
Sibling of 134.011-T. Where 134.011-T proves each clause is PRESENT on each carrier, this task proves each clause SAYS THE RIGHT THING on each carrier.

The distinction is load-bearing and is exactly why this task exists. All three defects found in the prior fix cycles were on surfaces where the clause was present and byte-identical to its dogfood, so both a byte-identity test and a clause-presence test would have passed while the contract was internally contradictory:

1. Fix cycle 1 -- the threadless path marked a KNOWN PR number `N/A`, permanently discarding a real identifier under the single-write invariant.
2. Fix cycle 2 -- authoritative C3 demanded a review-thread reply even on surfaces where no thread can exist, making the clause unsatisfiable for CI and pre-PR findings.
3. Fix cycle 3 -- the fix-ci threadless discharge named only two of the three required residual-risk records, weakening the only traceability mechanism available without a thread.

Each is a SEMANTIC contradiction between carriers, not a missing clause. This suite is what converts that class of defect from a review finding into a test failure.

The NO-PR/NO-THREAD-ASSUMPTION guard is deliberately broader than any single prior defect: all three cycles trace to one root cause -- the policy was first authored assuming every finding arrives on a PR review thread -- so the suite guards the root assumption directly rather than only its three known symptoms.
