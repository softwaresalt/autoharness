updated_at: 2026-09-03T08:23:07.9366942Z

Package and install only the minimum runtime file set for both autoharness distribution channels, driven by a single declarative allowlist manifest and enforced by a fail-closed composition test.

PROBLEM: `.github/plugin/marketplace.json` declares `source: "."` (repo root — 3,238 tracked files / ~18 MB), and `pyproject.toml` force-includes all 642 `docs/` files into every wheel. `.backlogit/` alone is 2,110 files (65% of all tracked files) of this workspace's own backlog records, shipped to every consumer with no runtime role.

EVIDENCE: `verify_workspace.py` resolves every `docs/*` path against `workspace_path` (the target workspace), never the packaged data dir — so the wheel's 6.9 MB docs force-include is provably dead weight. Skill references to `docs/compound|plans|memory|decisions|closure` are target-workspace OUTPUT destinations, not engine payload ("referenced != required payload").

DECISION: explicit allowlist manifest as single source of truth for both channels; allowlist-by-default fails closed, denylist fails open. Projected 3,238 -> ~350 files, ~18 MB -> ~3 MB.

Preserves install, update, verification, and cross-environment behavior. Target workspaces receive only generated output, never autoharness engine files.
