Goal: the fresh pre-close snapshot (classifier, engine semantics, close-path selection, disposition snapshot, fingerprints, observation set) and the --classify-only verdict record.
Files: src/autoharness/shipment_close/preclose.py (new), tests/test_shipment_cascade_close_preclose.py (new).
Key rules:
- Input validation before any read: S/F via closure_contract.validate_closure_id; --sha a full 40-char lowercase hex; invalid -> exit 2, nothing written.
- A1b lock and existing-record check run BEFORE classification in both modes (an invoking record always wins with exit 7; AN-F02).
- run_preclose(workspace, S, F, *, resolved) -> PreCloseSnapshot: load the manifest under the detected backlog root (backlog_root.py; both roots present fails closed); a shipment no longer open exits 2 (AN-F01); run classify_shipment_close_path fresh; run the A2a probe on resolved and record engine_semantics (R1); assemble tool{} from A3a path/hash + A2a version_excerpt (R7); select_close_path(classifier, engine) -> close_path_selection{selected_close_path, reason} (R2) and every later branch keys on the SELECTED path; redact(reason)[0] != reason (text element of the tuple; Copilot PR #481 T2) -> exit 2, no record (R6).
- Feature check: selected CASCADE -> feature_id in qualifying_feature_ids; selected SAFE_CLOSE (incl. CASCADE x UNVERIFIED) -> feature_id is a manifest member or a member's parent_id; else exit 2 (AS-F08).
- Fingerprint shipment record and every manifest member (location, SHA-256, declared status, parent_id) via A1 *_to_record (R8); fingerprint out_of_manifest_descendant_ids.
- Disposition snapshot (R5): compute_linked_deliberation_disposition(manifest_ids, shipment_id, backlog_dir, engine=<A2a decision>) with no stash_path; serialized with A1 disposition_plan_to_record; a planner path outside the backlog root is stored as path: null + reason_code (R12). Read-only; the command never archives. Non-null planning_error -> exit 2, no record; retained_*, unresolved references, read failures recorded, never halt.
- Selected SAFE_CLOSE: record the A2b observation set with excluded_ids = every disposition-snapshot ID; deliberation_records = none under VERIFIED (R2), every records[] entry of non-already-archived dispositions under UNVERIFIED (C2-1). Observation set cannot be established (torn/unreadable; missing is recorded, C2-2) -> exit 2, no record.
- Torn or missing manifest member fails closed; disposition-set deliberations follow non-halting retained_* outcomes.
- The 1.10.x qualifying-feature linked-deliberation collection and pre_close.linked_deliberations key are removed.
- --classify-only writes a phase: pre_close record and exits 0 when selected CASCADE, 3 when selected SAFE_CLOSE (incl. CASCADE x UNVERIFIED); never mutates backlog state.
