SIZE: M. COMPLEXITY: medium. (Two independent axes; also emitted as structured backlog fields.) Shipment 1 (P0). Create src/autoharness/supervise/locking.py enforcing exactly ONE active supervised session per workspace. F27 RULING - ACQUISITION MUST BE ATOMIC AND OS-BACKED. Exclusion is established by a SINGLE ATOMIC OPERATION - os.open(path, O_CREAT|O_EXCL) exclusive create, or an OS advisory lock (fcntl/flock on POSIX, msvcrt/LockFileEx on Windows) held for the session lifetime - and NEVER by a check-then-write sequence. A read-then-write acquisition is explicitly PROHIBITED: it opens a TOCTOU window in which two supervisors starting simultaneously both observe no live holder and both take the lock, which is precisely the concurrent-session failure this module exists to prevent. The PID + process-start-time record written into the lockfile is retained for STALE-LOCK DIAGNOSIS ONLY (118.006-T) and is explicitly NOT the exclusion mechanism. F31 CONSEQUENCE - THE PRIMITIVE MUST BE REUSABLE BY CLEANUP: expose the atomic exclusion primitive so that 118.006-T's force-unlock can ACQUIRE THE SAME PRIMITIVE and hold it across inspection AND removal as one critical section. Exclusion must NOT be an acquisition-path-only internal detail, because a cleanup path that cannot take the same lock is forced into the check-then-act deletion that F31 identified as able to delete a LIVE holder. Provide it as a documented, testable seam (not a private import-time side effect), and ensure a failed acquisition is distinguishable from an error so cleanup can treat 'cannot acquire' as 'a live holder exists' and refuse. FAIL CLOSED (H2): a live lock is NEVER auto-broken - contention yields the distinct terminal outcome REFUSED, not FAILED. RELEASE IS IDEMPOTENT AND CRASH-SAFE, exposed both as an explicit release() and as a context manager, because the 119.003-T DRAINING state calls it unconditionally on every terminal path (F22) and must never fail when the lock was already released. Every lock path is resolved and asserted INSIDE the workspace root before any write (path-traversal containment); an escaping path aborts rather than being clamped. MANDATORY CONCURRENCY TEST (F27, non-negotiable): a REAL parallel-contender suite - at least 8 contenders launched simultaneously as separate processes, repeated over at least 50 iterations - asserting that EXACTLY ONE acquires and every other observes REFUSED, with zero double-acquisitions across all iterations. A SEQUENTIAL contention test (start A, then start B) is explicitly INSUFFICIENT and must not be presented as evidence of mutual exclusion: it proves exclusion against a non-contending peer, which is a different proposition from the one the invariant needs. Tests also cover atomic acquire, idempotent release, double-release, release-after-crash, and path containment. Errors use the taxonomy from 118.003-T (supervise/errors.py). Stale-lock detection, --force-unlock and recycled-PID rejection are split into 118.006-T to keep this task inside the 2-hour box.
