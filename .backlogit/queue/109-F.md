Covering feature for E3C25E6D (deliberation 012-DL, informing spike 001-SP). Add a fail-closed `autoharness gate pipeline-topology` that MECHANICALLY enforces the serial Stage->Ship, single implementation branch/worktree workflow (P-001/P-016) instead of relying on agent prose. This is the mechanical enforcement layer on top of the 060-F/061-S prose policy + partial Ship intake gate — distinct, not duplicative.

AUTHORITY BOUNDARY (per 012-DL): backlogit is the authoritative cross-machine shared lease for shipment claim/status; the gate is a fail-closed READER/VALIDATOR of backlogit status + LOCAL git branch/worktree topology. The gate NEVER mutates backlogit internal transition rules (external-guard pattern). Do not mutate C:/Source/GitHub/backlogit.

The gate verifies four topology invariants before topology-sensitive ops (shipment claim, branch/worktree creation, build, push, PR, closure): (1) at most one ACTIVE shipment (global, via backlogit); (2) queue/dependency + prior-closure readiness; (3) branch-to-claimed-shipment ownership (three-case per P-011); (4) exactly one implementation WORKTREE (machine-local), honoring only the explicit time-boxed Stage spike/research exception (P-016).
