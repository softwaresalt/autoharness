TEST 2 - test_version_resolves_on_plugin_install_without_cli (AC10, finding P1-5):
install-harness FAILS the install if the `{{AUTOHARNESS_VERSION}}` template variable is unresolved (its Step 4.1). Resolution chain: (1) `autoharness version` CLI; (2) autoharness_home/pyproject.toml or src/autoharness/__init__.py; (3) for plugin installs with no Python CLI, the plugin/package manifest version.
The plugin channel excludes src/ and pyproject.toml, so source (3) is the ONLY remaining resolver for plugin-only consumers.
- Install from the trimmed plugin payload with NO Python CLI on PATH.
- Assert the manifest records a CONCRETE version and never an unresolved literal placeholder. The exact placeholder token is asserted in a fixture constant so this task record itself does not carry a bare unresolved-looking token.
- Assert plugin.json and .github/plugin/marketplace.json are present by name.
- The plugin-root VERSION RESOLUTION contract is specified by 160.013-T (AC6b). This test consumes that contract at the install-harness layer; it does not redefine it.
