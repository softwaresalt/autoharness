Applicability engine over discover_modified_files with fail-closed FC1 and recorded FC2 exclusions. Resolve the base ref BEFORE discovery so the empty-list ambiguity cannot silently violate FC1. Domain: code. Files: 1.

<!-- BEGIN:acceptance-criteria -->
* **FC1**: unresolvable base / unreadable manifest / missing profile -> ALL nodes `insufficient_evidence`. Explicitly asserted to be NOT `not_applicable`.
* **FC2**: every `not_applicable` result carries the excluding clause in `excluded_by`.
* `applies_when` glob evaluation matches `path_matches` doublestar semantics.

<!-- BEGIN:description -->
Plan unit **U4**. Create `src/autoharness/detectors/applicability.py`.

Build the applicability context **once per run** from `discover_modified_files(base, head)`, the resolved shipment manifest, and `workspace-profile.yaml` `runtime_surfaces`. Evaluate `applies_when` using `gates/match.py::path_matches` doublestar semantics.

**FC1 (fail-closed)**: if the context cannot be built — unresolvable diff base, unreadable manifest, missing profile — every node evaluates to **`insufficient_evidence`**, *never* `not_applicable`. Silently pre-filtering a node out of its own enumeration is the F13 defect class this programme exists to catch; the harness must not commit it.

**FC2**: every `not_applicable` verdict records the excluding predicate clause in `excluded_by`. An unaudited non-applicability decision is indistinguishable from a skipped check.

**Execution posture**: test-first.
<!-- END:description -->

<!-- BEGIN:implementation-notes -->
**Depends on U1.**

**THE CRITICAL TRAP — Python Reviewer P1 finding.** `discover_modified_files` **never raises** and returns `[]` with a warning on git failure. An empty list is therefore **ambiguous**: 'no files changed' and 'git unavailable / not a repo / unknown ref' look identical.

**Decision D-7**: the engine MUST explicitly resolve the base ref **BEFORE** calling discovery, so a genuine failure is not silently rendered as an empty-but-valid context. **This is the single most likely way FC1 gets accidentally violated.** U9 tests the unresolvable-base path explicitly.
