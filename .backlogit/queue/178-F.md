FOUNDATION (P1). Create the operation substrate that four separate release units have each been assuming and none has built. Establishes src/autoharness/ops/ with a typed operation result model, a single operation registry, and TWO transports derived from that one registry: the CLI namespace autoharness op <namespace> <operation> following the established _parse_*_args / _*_command convention that gate already demonstrates across five subcommands, and the MCP/sidecar surface whose handlers call the IDENTICAL registered functions. Parity is asserted by a test that enumerates the registry and requires both transports to expose the same operation set with the same parameter names. Markdown agents INVOKE operations by name; they never promise shell=False and never interpolate an untrusted value. Transport shape is decided by spike S1.
