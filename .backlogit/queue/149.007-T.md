HEAD-keyed report emitter under .autoharness/gates/pre-review/ (Q1 exception) plus the D6 freshness rule. Flat list only — the signature makes a persisted graph unrepresentable. No read-back, no blocking authority. Domain: code. Files: 1.

<!-- BEGIN:acceptance-criteria -->
* **INV-1 / Decision D-5**: the writer accepts a flat `Sequence[NodeResult]` and has **no access to edges** — a persisted graph is **unrepresentable by type**, not merely forbidden by prose.
* **INV-2 (Q1 boundary)**: the report is **derived evidence, not the source of truth**. The module exposes **NO read-back API** in S1; it is never read back as authoritative input to a verdict. Regeneration from the tree at that SHA must be possible.
* The emitter has **no blocking authority** and cannot influence the exit code (no return path into it).
* Epoch-keyed, append-only: a second run at the same epoch does NOT overwrite.
* Stale `head_sha` or changed `tool_version_dims` -> `insufficient_evidence`, never a reused `passed`.
<!-- END:acceptance-criteria -->

<!-- BEGIN:description -->
Plan unit **U7**. Create `src/autoharness/detectors/report.py`.

Write `.autoharness/gates/pre-review/<head_sha>.json` — a **flat list of node results**, keyed by immutable epoch, **append-only per epoch, never overwritten**. This sits alongside the existing `.autoharness/gates/*-force-audit.log` and `pipeline-topology-telemetry.jsonl` precedents.

**Provenance block (D6)**: `base_sha`, `head_sha`, `reviewed_sha` (nullable), `platform`, `tool_versions`, `produced_at` (RFC3339), and `touches_reviewable_paths: bool` (per `028-DL` R2, so documentation-only pushes do not inflate the epoch count).

**Freshness rule (D6)**: a node result is fresh iff its `head_sha` equals current HEAD **and** every dimension declared in `producer.tool_version_dims` is unchanged. **A stale result is `insufficient_evidence`, never a reused `passed`.** This mechanizes family F11 against the harness's own output — the programme must not commit the defect it detects.

**Execution posture**: test-first.
