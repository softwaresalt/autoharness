Create src/autoharness/supervise/process.py defining the ChildProcess Protocol (spawn / read / write / signal / wait / close) plus the DEFAULT PipeChildProcess implementation on stdlib subprocess. H4: ARGV-ARRAY SPAWN ONLY - shell=True is prohibited and asserted against in tests; no path or argument is ever interpolated into a command string. H3: EXIT-STATUS FIDELITY IS A HARD INVARIANT - the child's exit code propagates unmodified through wait(); no masking, no remapping of a non-zero child exit into a supervisor-level status, no inference of success from non-empty output. Includes a scripted FAKE child implementation of the same Protocol so the entire state machine, journal, cancellation and restart paths can be tested deterministically without Copilot. Tests: argv fidelity, no-shell assertion, exit-code round-trip over {0,1,2,42,130}, stream capture, signal/terminate, and reaping without zombies.
