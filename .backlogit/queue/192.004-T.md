<!-- BEGIN:description -->
Files: src/autoharness/shipment_close/runner.py (new), tests/test_shipment_close_runner.py (new).
- resolve_backlogit_binary(workspace) -> ResolvedBinary reads cli.binary from .autoharness/backlog-registry.yaml and resolves it with shutil.which. It refuses (exit 2) when the binary is unresolved, when the resolved path lies inside the workspace root (Windows working-directory hijack), when it is a symlink or reparse point, and on Windows when its suffix is not .exe (a .cmd/.bat shim is refused because batch argument parsing can reinterpret metacharacters even with shell=False; SL-F02).
- Records the absolute path, the file's SHA-256 and a bounded, redacted --version excerpt as tool{...}. The spawn always uses that absolute path; A3 re-hashes immediately before spawning (SL-F03 in-scope part). The trust model equals today's (first backlogit on PATH); pinning a trusted absolute path in the registry is out of scope (P-021 C1) and is stashed as the SBA-F04 follow-up.
- ResolvedBinary carries argv_prefix: tuple[str, ...] = (absolute_path,) in production and (sys.executable, fake_script) in tests; the .exe and containment checks apply to argv_prefix[0] (PR-F02).
- run_bounded(argv, *, cwd, timeout) -> BoundedRunResult (frozen dataclass): subprocess.Popen with shell=False, stdin=DEVNULL, one reader thread per stream feeding A1b StreamCapture; the child starts in a new process group (start_new_session=True on POSIX, CREATE_NEW_PROCESS_GROUP on Windows). On timeout kill the group (os.killpg on POSIX; on Windows the absolute %SystemRoot%\System32\taskkill.exe /T /F /PID <pid>, by PID only; PR-F03), then a bounded wait(10). Reader threads are joined with a bounded timeout after exit (PR-F04).
- timeout defaults to 120 s; --timeout accepts 30-900 s and out-of-range values exit 2.
