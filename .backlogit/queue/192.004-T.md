<!-- BEGIN:description -->
Goal: trusted backlogit binary resolution and a bounded subprocess runner. Now precedes A2 (the A2a engine probe needs it).
Files: src/autoharness/shipment_close/runner.py (new), tests/test_shipment_close_runner.py (new).
Key rules:
- resolve_backlogit_binary(workspace) -> ResolvedBinary reads cli.binary from .autoharness/backlog-registry.yaml and resolves it with shutil.which. Refuses (exit 2) when: cli.binary is not a bare name matching ^[A-Za-z0-9_-]+$ (R3: path separator, drive/UNC prefix, absolute path such as /bin/sh, '.', or extension refused BEFORE any lookup); unresolved; the resolved file's basename (minus trailing .exe on Windows) != cli.binary (case-insensitive on Windows, exact elsewhere) so which cannot substitute a differently named program (R3); resolved path inside the workspace root; symlink or reparse point; on Windows suffix not .exe (.cmd/.bat shims refused, SL-F02).
- Every version probe of the resolved binary runs with cwd = a fresh empty temporary directory outside the workspace, created per probe and removed in finally (R3).
- Records tool{binary_path, binary_sha256} (absolute path and SHA-256). A3a NEVER spawns --version itself (R7): tool.version_excerpt comes from the single A2a probe spawn. Spawns always use the absolute path; A3 re-hashes before spawning (SL-F03). Pinning a trusted absolute path in the registry is out of scope (P-021 C1, follow-up).
- ResolvedBinary.argv_prefix: tuple[str, ...] = (absolute_path,) in production, (sys.executable, fake_script) in tests; .exe and containment checks apply to argv_prefix[0].
- run_bounded(argv, *, cwd, timeout) -> BoundedRunResult (frozen): Popen shell=False, stdin=DEVNULL, one reader thread per stream feeding A1b StreamCapture; new process group (start_new_session=True POSIX; CREATE_NEW_PROCESS_GROUP Windows); on timeout kill the group (os.killpg; Windows absolute %SystemRoot%\System32\taskkill.exe /T /F /PID <pid>, by PID only), then bounded wait(10); reader threads joined with bounded timeout.
- timeout default 120 s; --timeout accepts 30-900 s, out of range exits 2. EXIT_* imported from shipment_close/__init__.py.
