Defines the checkpoint resume-hint and payload-shape contract in three parts, landing in the order policy -> producers -> validation.

VALIDATION BOUNDARY IS AN EXECUTABLE ADAPTER. Producers invoke autoharness checkpoint create instead of the raw backlogit create operation; validate_checkpoint_payload(payload, origin) is the single predicate behind it, and validation is strictly PRE-WRITE so no malformed record is ever created. A package-local Python function cannot enforce anything against Markdown agent templates that call backlogit directly, which is why the boundary is a command.

HISTORICAL CLASSIFICATION IS TOTAL. status: resolved with no usable hint yields the reported, non-blocking CHECKPOINT_LEGACY_HINTLESS_RESOLVED; status: active with a missing, empty or whitespace-only hint yields the blocking CHECKPOINT_ACTIVE_HINTLESS and fails closed to operator handoff. No record is left unclassified and no active record is grandfathered. NO MIGRATION MECHANISM SHIPS: no committed checkpoint file is ever rewritten.

AUTHORITATIVE CONTRACT UPDATED ATOMICALLY. 172.001-T changes .github/instructions/backlogit.instructions.md and templates/instructions/backlogit.instructions.md.tmpl together so the raw backlogit create call is no longer advertised as a permitted harness producer path, regenerating install-manifest checksums for every modified tracked file. 172.010-T verifies this by INVENTORY-BACKED DISCOVERY across every producer surface - agents, skills, instructions, docs and source - rather than against a hardcoded two-file list.

SOURCE STASH: 71200CBB is the canonical selected entry, matching the shipment title.

ENFORCEMENT SAFETY IS ENCODED, NOT PROMISED: 172.009-T (enable) is blocked by 172.003-T, 172.004-T and 172.005-T, so the adapter cannot be switched on against a producer that has not yet adopted the contract or before the adapter exists.
