=== PART 1 (C0EA1175) - THE APPROVAL GATE ===

P-007's violation-remediation step instructs an automatic `git restore .backlogit/archive/` with no approval or safety-mode gate, conflicting with Constitution Principle VII's destructive-command approval rule. Cycle 0 resolved this as "gate it behind explicit operator approval" but NAMED NO ARTIFACT, leaving a gate any agent could self-satisfy. Cycle 1's DECISION G named a backlogit comment as the approval artifact. THAT IS WITHDRAWN AS THE AUTHORIZATION SOURCE (P1, cycle 2): backlogit_append_comment / `backlogit append-comment` is an operation THE EXECUTING AGENT ITSELF CAN CALL, so an agent could write "APPROVAL: P-007-ARCHIVE-RESTORE ..." onto the shipment and then read its own writing back as authorization. A gate whose token the gated party can mint is not a gate - it is the same self-satisfiable shape cycle 0 was trying to remove, moved one layer down.

G1 THE AUTHORIZATION SOURCE IS A DIRECT RUNTIME OPERATOR APPROVAL (BINDING): the policy text MUST require authorization to be a LIVE approval RESULT obtained at the moment of the request over an INDEPENDENT OPERATOR CHANNEL the executing agent CANNOT SYNTHESIZE - the intercom approval/clearance operation, an interactive operator ask/confirm prompt, or the operator session channel. The defining property is NON-SYNTHESIZABILITY: the approving act must originate outside the agent's own writable surface, and the agent must have no operation that can produce the affirmative result on its own behalf.

G2 THE BACKLOG COMMENT IS EVIDENCE ONLY, NEVER AUTHORITY: after (and only after) a G1 approval RESULT is obtained, the agent SHOULD record an "APPROVAL: P-007-ARCHIVE-RESTORE" comment on the shipment item carrying the shipment ID, the exact archive paths, the operator actor identity, the approval timestamp, and the CHANNEL the approval came over. That record exists for AUDIT AND TRACEABILITY. The text MUST state it is NOT read back as authorization, is NOT a substitute for a live G1 result, and that its presence does NOT shorten, cache, or pre-satisfy any future approval - each remediation attempt requires its own fresh G1 approval.

G3 NO INDEPENDENT CHANNEL MEANS HALT, DO NOT RESTORE (BINDING): when NO independent approval channel is available - intercom degraded or unreachable, no interactive operator session, ask/confirm unavailable, or the channel present but unanswered - the policy MUST direct the agent to HALT AND NOT RESTORE. Absence of a channel is NEVER an implicit approval and NEVER a fallback to the comment path. The ungated path is UNCHANGED and MANDATORY: detect the violation, halt, record it through P-005 telemetry with the exact remediation command for a human to run, leave the working tree untouched.

G4 DARK-MODE / AFK IS FAIL-CLOSED (PRESERVED VERBATIM FROM CYCLE 1): under dark-factory/AFK mode no operator is present to give a G1 approval, so `git restore` NEVER RUNS. A dark-mode run always REPORTS and never RESTORES. This is the Principle VII-conformant outcome, not a degradation, and it is also the answer to cycle-0 finding 2's AFK-stall objection. Cycle 2 strengthens rather than weakens this: G3 makes "no channel" a halt in ALL modes, so dark mode is now the specific case of a general rule instead of a special exception.

G5 VERIFICATION IS A READ OF A LIVE RESULT, NOT AN INFERENCE: the text must require matching the approval result to the CURRENT shipment ID and the EXACT archive paths to be restored. Mismatch, absence, ambiguity, timeout, or an unreadable channel is a REFUSAL, never a pass.

G6 NO ADMIN AUTHORITY IS INVENTED: G1 is an OPERATOR-PERFORMED act the agent merely RECEIVES. The agent cannot create it, cannot mark it satisfied on its own behalf, and gains no new authority; merge preauthorization does NOT imply destructive-command preauthorization.

G7 DETERMINISTIC STATIC CONTRACT CASES (MANDATORY ACCEPTANCE, four cases, each observed RED against the unmodified policy text before the amendment lands, per binding H7). Each case asserts over the RENDERED policy text (and, where the clause also governs the constitution reviewer, that mirror too). These are the same four conditions cycle 2 enumerated; only the observable changed from a fictional runtime effect to the text that governs it.
  (i) NO-APPROVAL CONDITION: assert the remediation step contains NO UNCONDITIONAL `git restore` INSTRUCTION - every occurrence of the restore command is either (a) inside an explicitly G1-gated branch, or (b) presented as a command FOR A HUMAN TO RUN in the refusal/report path. Assert the default path is detect-halt-report-with-P-005-telemetry and leave the tree untouched. RED PRE-FIX because the current text instructs the restore unconditionally.
  (ii) MISMATCH CONDITION: assert the text requires the approval result to MATCH the current shipment ID AND the exact archive paths, and names mismatch/ambiguity/timeout/unreadable as a REFUSAL. RED PRE-FIX because no matching rule exists.
  (iii) SELF-AUTHORIZATION NEGATIVE COVERAGE (the specific defect this revision closes): assert the text NOWHERE treats an agent-writable artifact as an authorization source - specifically that no clause permits a backlog comment, a telemetry record, a file the agent can write, or any agent-callable operation to satisfy the gate; and assert the AFFIRMATIVE G2 clause is present stating a backlog comment is EVIDENCE ONLY and is NOT an authorization source. Both halves are required: the negative alone passes vacuously on text that never mentions comments, and the affirmative alone does not exclude a competing clause elsewhere. RED PRE-FIX.
  (iv) NO-CHANNEL CONDITION: assert the text declares HALT-WITHOUT-RESTORE when no independent channel is available, in ALL modes, and that dark-factory/AFK is named as an instance of that rule rather than an exception to it. RED PRE-FIX.

G8 THE REFUSAL MESSAGE TEXT must name the missing authorization channel and the exact command a human can run themselves, so a legitimate operator is never stranded without a remedy. Asserted as a text requirement in case (i)'s refusal branch.
