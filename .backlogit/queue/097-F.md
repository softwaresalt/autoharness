### H2. Checksum-refresh method (raw-bytes sha256, CRLF-safe normalize-then-hash)
The generic manifest scan hashes RAW working-tree bytes
(`hashlib.sha256(file.read_bytes())`, no normalization — verify_workspace.py:3186).
The committed form is LF. A `.gitattributes` `eol=lf` pin only governs FUTURE
checkout/clean conversion — it does NOT rewrite an already-checked-out CRLF file,
so hashing an LF-normalized *printout* of a still-CRLF working-tree file would
mismatch verify. Ordered recipe (do NOT reorder):
* (1) Pin BOTH renamed installed agent files to LF in `.gitattributes`
  (`_ship.agent.md text eol=lf` AND add `_stage.agent.md text eol=lf` — currently
  only ship is pinned; adding stage closes a portability gap), THEN force in-place
  LF conversion: `git add --renormalize .github/agents/_stage.agent.md .github/agents/_ship.agent.md`
  (or rewrite bytes CRLF→LF and write back).
* (2) ASSERT no CRLF remains in either working-tree file:
```
python -c "import pathlib,sys; [sys.exit('CRLF in '+p) for p in ['.github/agents/_stage.agent.md','.github/agents/_ship.agent.md'] if b'\r\n' in pathlib.Path(p).read_bytes()]"
```
* (3) Hash the RAW bytes of the now-LF files (no in-hash normalization):
```
python -c "import hashlib,pathlib; print(hashlib.sha256(pathlib.Path('.github/agents/_stage.agent.md').read_bytes()).hexdigest())"
```
* Only 2 manifest artifact entries change (the 2 installed agent files); templates
  are not checksummed.
