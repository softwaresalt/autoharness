Turn autoharness into a LOCAL, operator-driven supervisor / control-plane runtime for long-horizon Copilot CLI workloads. Copilot CLI is PRESERVED as the reasoning/agent-execution engine; autoharness owns lifecycle, policy, and supervision only and implements NO model action/observation reasoning loop. Move the orchestration policy currently duplicated and untested across start.ps1 and start.sh into tested, typed shared Python application services under src/autoharness/supervise/, with start.ps1 / start.sh reduced to compatibility shims over a new `autoharness run` CLI entry point. Scope: workspace bootstrap, sidecar lifecycle/preflight, child process/PTY management (ConPTY abstraction on Windows), session state machine, local structured commands/approvals, progress/events, cancellation, controlled restart/resume, logs/checkpoints, secret redaction, workspace/session locking, and recovery. Consumes stash 34D50F2D candidate (a) under the reconciled spike disposition (004-SP: CONDITIONAL PROCEED -> PROCEED under the clarified scope "supervising an external agent runtime is in scope; implementing a new agent runtime is not"). EXCLUDED / DEFERRED to Plan 2: Gradio, Microsoft devtunnel, remote UI/control, remote authentication, remote approvals, browser terminal streaming, and any remote service. P-006 plan-harden HARDENED (H1-H10); plan-review PASS (0 P0 / 0 P1, 1 of 3 cycles).

<!-- BEGIN:Architecture -->
New package src/autoharness/supervise/ containing: result.py (one typed SupervisorResult envelope), errors.py (one AutoharnessError base with machine-readable kind + exit-code contract), redact.py (single secret-redaction choke point), locking.py (single-active workspace/session lock), process.py (ChildProcess Protocol + PipeChildProcess default), process_pty.py (ConPTY / POSIX pty behind the same Protocol, optional extra), session.py (explicit state machine), events.py (typed event bus; candidate-(c) hook surface only), journal.py (append-only redacted JSONL session journal), recovery.py (cancellation, bounded restart budget, resume), bootstrap.py (.env.local, COPILOT_HOME/ENGRAM_DATA_DIR, token resolution), sidecar.py (backlogit sync + Engram direct-then-daemon prewarm), resolve.py (Copilot exe resolution + argv composition incl. opt-in --remote), approvals.py (local console-only approval channel), app.py (run_session() - the single orchestrator). Adapter: `autoharness run` in cli.py, parse -> call -> render -> exit, zero policy.
<!-- END:Architecture -->

<!-- BEGIN:State-Machine -->
INIT -> LOCKING -> BOOTSTRAPPING -> PREFLIGHT -> RESOLVING -> LAUNCHING -> RUNNING -> {CANCELLING | RESTARTING | DRAINING} -> {EXITED | FAILED | REFUSED}. Transitions not in the legal-transition table are rejected with ErrorKind.ILLEGAL_TRANSITION; there are no implicit transitions. DRAINING is the only path from RUNNING to a terminal state and always flushes the journal, releases the lock, and reaps the child. REFUSED (lock contention) is a distinct terminal state from FAILED.
<!-- END:State-Machine -->
