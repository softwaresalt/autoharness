Bake hosted-review (Copilot) finding-pattern learning into the harness workflow so the agent proactively detects known issue classes before opening a PR and systematically compounds new ones after hosted review. Installs: (1) review-skill Step 1.5 pattern retrieval before persona routing; (2) a new conditional Evidence Consistency Reviewer persona with a 10-point branch-tree-only rubric; (3) a bounded mechanical post-fix delta check for the four drift-prone classes (RC-9 head-SHA parity, RC-10 identifier propagation, RC-11 chronology verbs, RC-12 date ordering); (4) pr-lifecycle hosted-review finding inventory (threaded AND suppressed) plus a bounded 5-signal compound-promotion checkpoint; (5) suppressed-findings enumeration in the GitHub PR automation instruction; (6) Ship wiring at both ends plus a Stage-handback rule for Stage-owned data-currency gaps; (7) template/dogfood parity tests and harness manifest checksum coverage. Motivated by PR 436 (13 rounds, 56 raw utterances, 24 distinct findings, 12 root-cause classes, 100 percent escape past local review and CI).
