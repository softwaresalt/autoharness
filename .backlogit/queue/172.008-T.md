TDD RED PHASE. Author the contract tests for BOTH validation surfaces and OBSERVE THEM FAILING before either surface exists.

SURFACE 1 - THE PREDICATE validate_checkpoint_payload(payload, *, origin) -> ValidationOutcome. Assert the four tokens and the origin partition: origin="harness" can emit CHECKPOINT_RESUME_HINT_MISSING and CHECKPOINT_RESUME_HINT_EMPTY and NEITHER historical token; origin="historical" can emit CHECKPOINT_LEGACY_HINTLESS_RESOLVED (reported) and CHECKPOINT_ACTIVE_HINTLESS (blocking) and NEITHER harness token. Assert the predicate is TOTAL: every historical input returns a ValidationOutcome, never None and never an unclassified result, with the branch decided by status alone. Assert outcome is DATA, not an exception, so the scan can report while the adapter halts.

SURFACE 2 - THE EXECUTABLE ADAPTER COMMAND autoharness checkpoint create --state-dump <path-or-json> [--origin harness]. Assert it by INVOKING IT as a command, not by importing a function: that is the only form of assertion that can distinguish "a producer called the gate" from "a gate exists somewhere in the package". Assert that on CHECKPOINT_RESUME_HINT_MISSING or CHECKPOINT_RESUME_HINT_EMPTY it EXITS NON-ZERO AND WRITES NOTHING - validation is strictly PRE-WRITE, because a written checkpoint cannot be repaired through the official create operation. Assert that on a clean outcome it performs the backlogit create call itself and adds no capability beyond it.

KEY CASES: an active hintless record fails closed with CHECKPOINT_ACTIVE_HINTLESS and is NEVER classified CHECKPOINT_LEGACY_HINTLESS_RESOLVED; a whitespace-only hint is treated as empty on both origins; a legacy payload with no schema_version classifies without crashing.

Every case is RED here because neither the predicate nor the adapter exists. Tests import and invoke the real boundaries and MUST NOT re-implement them.
