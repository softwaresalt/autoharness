Derive the install-shape variables (structured block values) and add the idempotent round-trip acceptance test.

**Plan:** `docs/plans/2026-08-21-verify-workspace-variable-derivation-plan.md` Task 2 + amendments B3, B7

## Variables in scope (~11)
`INSTALL_PRESET`, `PRIMARY_STACK_PACK`, `STACK_PACKS_YAML`, `INSTALL_LAYERS_YAML`, `CAPABILITY_PACKS_YAML`, `HARNESS_OVERRIDES_YAML`, `ENABLED_SIDECARS_YAML`, `ENABLED_SIDECARS_SH`, `ENABLED_SIDECARS_PS1`, `COPILOT_CLI_ARGS_YAML`, `COPILOT_CLI_ARGS_SH`, `COPILOT_CLI_ARGS_PS1`.

## STRUCTURAL-RENDERING HAZARD (023-DL R4, hardening H4)
These are BLOCK values (YAML array, sh array, PowerShell array) injected by an engine that knows nothing about indentation. A wrong indent produces a file that still "renders" but no longer PARSES — and `_find_unresolved_placeholders` would report SUCCESS because no `{{...}}` remains.

**Therefore: the zero-unresolved metric MUST NOT be reported as met unless the parse-level assertions below also hold.** Zero-unresolved alone is not evidence of a correct render.

## Test-first requirement
- Assert the rendered `.autoharness/config.yaml` PARSES as YAML and that parsed values round-trip equal to the source config.
- Assert the rendered `start.sh` and `start.ps1` array literals are syntactically valid — by parse/shape, not by eyeball.
- **Amendment B3 (round-trip idempotence).** derive → render → parse → RE-DERIVE from the re-parsed config → assert the second derivation equals the first.
- **Amendment B7 (semantic equivalence).** Because rendering `harness-config.yaml.tmpl` NORMALISES scalar-shorthand routes into mappings, a derivation-map comparison alone is INVARIANT under normalisation and would mask the reshape. The round-trip test must ALSO assert SEMANTIC route equivalence (each route's resolved family/provider/effort) before and after.

## Hard constraint (amendment B7)
Shape normalisation in the STAGED tree is acceptable and expected. **This feature MUST NOT write the staged `.autoharness/config.yaml` back over the live workspace config.** Doing so would rewrite an operator's hand-authored config shape as a side effect of a bug fix.

## Acceptance criteria
- AC2a. All install-shape variables removed from T0a's expected set.
- AC2b. Staged `.autoharness/config.yaml` parses as YAML and round-trips.
- AC2c. Staged `start.sh` / `start.ps1` array literals are structurally valid (asserted by parse/shape).
- AC2d. The B3 idempotent round-trip test passes.
- AC2e. The B7 semantic route-equivalence assertion passes.
- AC2f. No write to the live `.autoharness/config.yaml`.
