Create src/autoharness/supervise/events.py: the IN-PROCESS EVENT BUS that fans out the event catalog DEFINED UPSTREAM IN THE SHARED CORE (118.003-T contracts.py). Per the F19/F21 ruling this module owns DELIVERY, not DEFINITION - it neither declares event names nor depends on 119.003-T, so the state machine can emit SessionPhaseChanged without a cycle back through the bus. Every event passes through the 118.004-T redactor ON EMIT; the module exposes NO raw-emit API (H5). H7 ANTI-DRIFT (explicit, test-enforced): the ONLY permitted subscribers in this feature are the journal writer and the console renderer. No background thread performs verification, summarization, or compaction - this event bus is a HOOK SURFACE that a future candidate (c) Verification and Compaction layer could consume, but candidate (c) is NOT implemented here and Engram gains NO authority. F28 RULING - THE ANTI-DRIFT GUARD IS BEHAVIORAL, NOT LEXICAL. A token/import denylist is bypassed by ordinary stdlib constructs (socket.create_server, socketserver.TCPServer, asyncio.start_server, http.server.HTTPServer), and because this guard is the control that discharges cycle-1 P0 F2 it inherits that severity. ENFORCEMENT: install a sys.addaudithook (socket.bind / socket.__new__) or equivalent interception for the duration of the supervisor test suite and FAIL if any listening socket is created while importing or exercising supervise/. POSITIVE CONTROL IS MANDATORY: a fixture that deliberately opens a listener through EACH of socket.create_server, socketserver.TCPServer, asyncio.start_server and http.server.HTTPServer must be CAUGHT by the hook - a guard never observed to fire on a real violation is an untested guard. The import denylist (gradio, fastapi, flask, uvicorn, aiohttp, devtunnel clients) is RETAINED ONLY as a fast pre-filter and is explicitly NOT the enforcement mechanism. Local in-process fan-out only - no sockets, no IPC, no network.
