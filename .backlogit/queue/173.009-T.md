Version-aware fixture contract that FAILS LOUDLY on undeclared binary versions. Every SAFE_CLOSE fixture declares the backlogit version it was observed against and FAILS (never SKIPS) when run against an undeclared version, so a CI pin bump forces re-observation instead of silently inheriting stale assertions. Skipping is explicitly prohibited: a skipped fixture reads as a pass in aggregate and is exactly how stale evidence survives a version bump.
