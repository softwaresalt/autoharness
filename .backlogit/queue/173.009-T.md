Version-aware fixture contract that FAILS LOUDLY on undeclared binary versions. Every SAFE_CLOSE fixture declares the backlogit version it was observed against and FAILS (never SKIPS) when run against an undeclared version, so a CI pin bump forces re-observation instead of silently inheriting stale assertions. Skipping is explicitly prohibited: a skipped fixture reads as a pass in aggregate and is exactly how stale evidence survives a version bump. Blocked by 173.008-T (the baseline defines the first declared version) and by 173.001-T, 173.002-T, 173.003-T, 173.004-T (the fixtures the contract is applied to). Scope: tests/.
