ART-01 reference detector: backlogit section-marker conformance. Read-only producer over .backlogit/templates and .backlogit/queue; pure validator over the evidence. The one detector that proves the SDK. Domain: code. Files: 2.

<!-- BEGIN:acceptance-criteria -->
* **INV-7 — READ-ONLY**: no backlogit mutation. Producer opens `.backlogit/**` read-only; U11 asserts file content/mtimes unchanged after a run (Q9: zero backlogit change).
* Validator is a **pure function** over evidence — no I/O, no producer re-entry.
* Detects all four malformed-marker classes: unpaired, misordered, nested, duplicated.
* Detects empty `required: true` sections.
* `mode: report_only`; the detector does not and cannot set its own mode.
<!-- END:acceptance-criteria -->

<!-- BEGIN:description -->
Plan unit **U6**. Create `src/autoharness/detectors/art/__init__.py` and `src/autoharness/detectors/art/section_markers.py`.

**`produce`**: read `.backlogit/templates/*.md` frontmatter for the declared `sections:` list per artifact type; scan `.backlogit/queue/*.md`; emit an `Evidence` record of observed marker pairs per artifact.

**`validate`**: pure function over that evidence — for each artifact, every declared section has a well-formed `<!-- BEGIN:<name> -->` / `<!-- END:<name> -->` pair (**paired, correctly ordered, non-nested, non-duplicated**) and every `required: true` section is non-empty.

**Node declaration**:
* `applies_when: {changed_paths_any: [".backlogit/**"]}`
* `severity: medium`, `mode: report_only`
* `remediation.class: guided_fix`, `remediation.authority: stage`

**Execution posture**: test-first.
<!-- END:description -->

<!-- BEGIN:implementation-notes -->
**Depends on U1 and U4.**

**Decision D-8 — why ART-01 is the right reference detector**: closed surface, declared shape, fully deterministic, and — critically for `031-DL` RK2 — it **reads data that already exists for another reason** and requires **no new author-minted identifier** (A8).
