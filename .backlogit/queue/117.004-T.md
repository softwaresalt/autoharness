SIZE: M. COMPLEXITY: medium. (Two independent axes; also emitted as structured backlog fields.) Shipment 1 (P0). Create src/autoharness/supervise/locking.py enforcing exactly ONE active supervised session per workspace. Lockfile under <workspace>/.autoharness/sessions/ records PID, process start-time, and session id. Liveness check uses PID plus start-time so a recycled PID cannot be mistaken for the original holder. FAIL CLOSED (H2): a live lock is NEVER auto-broken - contention yields the distinct terminal outcome REFUSED, not FAILED. A stale lock (dead PID or start-time mismatch) still requires an explicit operator --force-unlock; it is never silently reclaimed. Every lock path is resolved and asserted INSIDE the workspace root before any write (path-traversal containment); an escaping path aborts rather than being clamped. Tests cover acquire/release, contention -> REFUSED, stale detection, force-unlock, recycled-PID rejection, crash-without-release cleanup, and path containment. Errors use the taxonomy from 117.002-T (supervise/errors.py).
