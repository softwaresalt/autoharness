GOAL: replace the hierarchical-closure coverage predicate in src/autoharness/gates/shipment_closure.py with the INV-6 ENGINE-INERTNESS CONTAINMENT predicate. NO new ClosePath member is added — the enum keeps exactly SAFE_CLOSE and CASCADE.

CHANGES
1. Extend _ArtifactRecord with `status: str | None`, read from the record's own frontmatter and normalized (strip + lower-case). A DECLARED-but-unnormalizable status fails closed exactly as the existing malformed-parent_id path does (raise BacklogUnavailableError -> SAFE_CLOSE).
2. Extend _build_children_index to return BOTH the children index AND a status index (parent/child edges plus every record's declared status) from the SAME single full queue/+archive/ scan. A malformed record anywhere still invalidates the WHOLE index (return None -> SAFE_CLOSE). Coverage/inertness must be POSITIVELY verified against a complete index, never inferred from a partial or failed scan.
3. REPLACE the verdict predicate. Currently:
     missing = tuple(d for d in descendants if d not in manifest_id_set)
     if missing: -> SAFE_CLOSE
   Becomes:
     out_of_manifest = tuple(d for d in descendants if d not in manifest_id_set)
     non_inert = tuple(d for d in out_of_manifest if status_index.get(d) != "archived")
     if non_inert: -> SAFE_CLOSE
   The reason string MUST name the offending IDs AND their observed status (the existing tests assert the offending ID appears in `reason`, so this keeps them green).
4. DO NOT add inert out-of-manifest descendants to accounted_ids (plan-review P0-2). The `extras` check MUST remain exactly as-is: a manifest member that is neither a qualifying root feature nor a descendant of one still forces SAFE_CLOSE. Absorbing inert descendants into accounted_ids would silently re-widen closure scope through the back door.
5. KEEP the descendant walk (_enumerate_descendants) and its visited-set cycle guard. Deleting it was rejected as plan-review P0-1: the measured engine archives a LIVE out-of-manifest task while reporting returned_ids: [], so the pre-mutation walk is the ONLY protection. Only the VERDICT changes, never the traversal.
6. KEEP the root-ness precondition, the positively-verified-childlessness precondition, the childless-root terminality cross-check, and the fail-closed SAFE_CLOSE default on any ambiguity.
7. REWRITE the module docstring to state the flat-manifest contract, INV-1/INV-2/INV-6, and that the descendant walk is a BLAST-RADIUS containment check over the backlogit cascade instrument — NOT a definition of closure scope. Remove the "fully covered" framing.

PURITY (unchanged, NON-NEGOTIABLE): the function stays pure and read-only — no git access, no subprocess, no backlogit call, no mutation.
