CI-invariant regression test asserting the WHOLE-SUITE CI gate is unmodified and still green. This is the guard against the P-004 rewrite accidentally relaxing the separate, unrelated CI requirement. The two gates observe DIFFERENT refs and different states and must not be conflated: CI requires `PYTHONPATH=src python -m unittest discover -s tests` to exit ZERO on the default branch, while P-004's red gate requires a NON-ZERO exit at the red phase on a feature branch. A transient full-suite RED on a feature branch is therefore lawful and is not a CI violation; this test asserts that the CI invocation, its expected exit code, and its workflow wiring are byte-unchanged by this release unit.
