Create src/autoharness/supervise/journal.py: an append-only, redacted JSONL session journal under <workspace>/.autoharness/sessions/<session-id>/ with one event per line, a monotonic seq, UTC timestamps, a schema-versioned header record, and a resume cursor. All writes go through the 118.004-T redactor; the module exposes NO raw-write API (H5). Every write path is resolved and asserted INSIDE the workspace root before the write; an escaping path ABORTS the session rather than being clamped or silently rewritten (H2). H6 AUTHORITY CONTAINMENT (must be documented in-module and asserted): the journal is GITIGNORED LOCAL OPERATIONAL STATE - it is NOT a backlog artifact, NOT a checkpoint, and MUST NOT be read by any agent crash-resumption/recovery protocol. backlogit remains the SOLE authority for backlog items and agent checkpoints, and the journal never substitutes for a backlogit checkpoint. F24 RULING - THE CORE OWNS IGNORE BEHAVIOR, NOT A TEMPLATE. No gitignore template exists to add to, so the H6 'gitignored local operational state' claim must be made TRUE BY THE CORE AT RUNTIME: on journal-root creation, journal.py idempotently ENSURES a self-contained ignore file inside <workspace>/.autoharness/ covering sessions/, creating it when absent and never rewriting unrelated operator content. A test asserts a freshly created session directory is ACTUALLY ignored by git (git check-ignore or equivalent), so the containment claim is ENFORCED rather than merely asserted in prose. F29 RULING - JOURNALING NEVER REPLACES TERMINAL ATTACHMENT: under the default inherited-stdio backend the supervisor does not observe child output, so ChildOutput lines are NOT journaled; this is a DECLARED, JOURNALED degradation - a single explicit ChildOutputUnavailable(reason=inherited-stdio) marker is written at session start rather than silently emitting an empty stream, and the resume cursor stays valid without it. Full ChildOutput journaling requires the opt-in PTY backend (119.002-T); capturing output must NEVER be achieved by downgrading an interactive session to pipes. Tests: append-only, seq monotonicity, crash-mid-write recovery, cursor resume, no secret substring of length >= 8 in any produced file, and path containment.
