Apply the SAME logic change to ALL FOUR mirrored files (dogfood output + product templates), or rendering/parity tests in tests/test_deploy_harness_scripts.py will fail:

- templates/scripts/deploy-harness.ps1.tmpl  (mirror)
- templates/scripts/deploy-harness.sh.tmpl   (mirror)

1. Distinguish an OMITTED pack input from an EXPLICIT `all`. Change the default sentinel (e.g. empty/`preset`) so omission is detectable rather than pre-set to "all".

3. Keep explicit `--packs all` / `-Packs all` meaning ALL registry packs.
4. Teach the registry enumerators (Get-RegistryPacks / registry_packs) to parse `default_in_preset` (they currently read only `- id:` lines) with a deterministic line scan (no YAML module dependency), preserving the existing style.
