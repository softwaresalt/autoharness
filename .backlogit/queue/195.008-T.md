Scope (code only): src/autoharness/gates/shipment_closure.py + new tests/test_linked_deliberation_disposition_planner.py.
Add `compute_linked_deliberation_disposition(manifest_items, shipment_id, workspace_backlog_dir, *, engine: EngineSemanticsDecision, stash_path=None) -> LinkedDeliberationDispositionPlan` (frozen dataclasses; module-local; read-only; uses autoharness.gates.topology._frontmatter; NEVER raises — every read error fails closed to the `retained_read_error` outcome; see "Outcome enum and reason codes").
- Stash path default (PR #466 review, cycle 4): stash_path=None resolves to `<workspace_backlog_dir>/stash.jsonl` (the active stash file at the resolved backlog root; here `.backlogit/stash.jsonl`); it never means "do not scan stashes". An explicit stash_path overrides it; both pass the same containment checks (Input safety). A missing stash file = no active stash entries; any other read error on it (unreadable, malformed line, containment failure) fails closed to `retained_read_error` (reason_code from the read-error vocabulary; path = the stash path) for every disposition-set DL (first in the outcome precedence below). The U5a call site passes no stash_path, so the default is the production path.
- Disposition set: union over EVERY explicit manifest member regardless of artifact_type of (a) literal custom_fields.source_deliberation_id, (b) description + each frontmatter `references` entry scanned with `\b(?:DL\d+|[0-9]+(?:\.[0-9]+)*-DL)\b`; exclude self and every id in closure_scope(S) (H10); existence validated BEFORE location (>=1 record with artifact_type deliberation); unresolved ids -> `unresolved_references` (never a halt). Record link kinds, linking members, every record path, declared status, SHA-256 per record path.
- Planned outcome precedence (first match): retained_read_error [reason_code, path] (any read or containment failure on the DL's own record(s) or on an input of the live-referrer scan: the resolved stash file or any record the scan reads; evaluated FIRST so a record that cannot be read never reaches later classification) -> retained_ambiguous (>1 record) -> already-archived (declared status exactly "archived", H3) -> retained_engine_unverified (engine UNVERIFIED; every path) -> retained_live_status (DL status active|blocked|review — the live statuses of the deliberation vocabulary in .backlogit/header-def.yaml: queued|active|blocked|review|done|accepted|rejected|archived; deliberations have no in-progress; a DL under review is never archived; queued/done/accepted/rejected are not live) -> retained_shared_reference [referrers] -> retained_description_mention (no source_deliberation_id link; report-only) -> archive.
- Live referrers COUNTED: work items (feature/task/subtask/bug/chore) outside closure_scope(S) not truly archived linking via any of the 3 sources; shipments != S not truly archived whose custom_fields.items lists the DL or whose description/source_deliberation_id names it; ACTIVE stash entries (the resolved stash_path; default `<workspace_backlog_dir>/stash.jsonl`) with deliberation_id == DL or text match. NEVER counted: the DL itself, other deliberations (A<->B cycles), docs/plans, truly archived items/shipments, archive/stash.jsonl. Referrer id with >1 record counts as live. H3 applies (archive/ + status done = live; queue/ + status archived = not live).
- Description source (PR #466 review): topology._frontmatter returns only the YAML mapping, but the backlogit description is the Markdown body after the closing frontmatter delimiter; read that body text from the same record read and use it wherever this task says "description" (member links and live referrers). A record whose body cannot be separated from its frontmatter is a read error: `retained_read_error` with reason_code `body_unseparable`.
- Input safety (Constitution III; PR #466 review): apply the same ID and path-containment checks as classify_shipment_close_path by reusing its helpers (_ARTIFACT_ID_PATTERN, _read_artifact_record, _scan_backlog, _is_symlink_or_reparse_point). Every candidate id (including a literal source_deliberation_id) must match _ARTIFACT_ID_PATTERN before any path is built, else it goes to `unresolved_references` with reason_code `invalid_id` (no path is built, so it never becomes a disposition-set member or a `retained_read_error`); every record path and the supplied stash_path must canonicalize inside the workspace backlog tree and must not be or sit under a symlink/reparse point. A containment failure is a read error: `retained_read_error` with reason_code `path_escape` or `symlink_or_reparse_point` (never `archive`); never raise.
- Outcome enum and reason codes (PR #466 review, cycle 5; operator design 2026-09-29): INV-12 is the invariant (the rule: each disposition-set member gets exactly one outcome; mutation only when its conditions hold); `LinkedDeliberationOutcome` is the CLOSED enum of the values INV-12 assigns, exactly eight: archived, already-archived, retained_read_error, retained_ambiguous, retained_engine_unverified, retained_live_status, retained_shared_reference, retained_description_mention (module-local str-valued Enum; the planner's planned `archive` is the pre-mutation form of `archived`, which U5a assigns only after verify-after-each). Every outcome record carries `reason_code` (non-empty string); for every outcome except retained_read_error it defaults to the outcome value (e.g. `retained_live_status`). A retained_read_error record also carries `path`: the offending path, workspace-relative with `/` separators (a path that resolves outside the workspace is recorded as supplied). Initial read-error reason_code vocabulary: `path_escape` (a record path or the stash_path does not canonicalize inside the workspace backlog tree); `symlink_or_reparse_point` (the path is, or sits under, a symlink, junction, or reparse point); `unreadable_file` (OS error on open/read, or content not decodable as UTF-8); `malformed_frontmatter` (frontmatter missing, not valid YAML, or not a mapping); `body_unseparable` (no closing frontmatter delimiter, so the Markdown description body cannot be separated); `malformed_stash_entry` (a stash.jsonl line that is not a JSON object). `unresolved_references` entries are {id, reason_code} with `invalid_id` (fails _ARTIFACT_ID_PATTERN) or `not_found` (no deliberation record); neither is a read error. The enum is closed (adding a value is a contract change); the reason_code vocabulary is extensible, and report consumers (U5a report, U6b Ship Step 7 and operational-closure) MUST accept any reason_code, including unknown ones, and copy it verbatim, never re-deriving it.
