Added by the 2026-09-29 independent plan review (P2 pure read-only planner; P1-6 shared-reference sources; P1-7 engine-unverified retention; P2 self/cycle/torn/every-member-type). Plan unit U1b. P-004 harness: fixture tests FIRST (red -> green).
Scope (code only): src/autoharness/gates/shipment_closure.py + new tests/test_linked_deliberation_disposition_planner.py.
Add `compute_linked_deliberation_disposition(manifest_items, shipment_id, workspace_backlog_dir, *, engine: EngineSemanticsDecision, stash_path=None) -> LinkedDeliberationDispositionPlan` (frozen dataclasses; module-local; read-only; uses autoharness.gates.topology._frontmatter; NEVER raises — read errors fail closed to a retention outcome).
- Stash path default (PR #466 review, cycle 4): stash_path=None resolves to `<workspace_backlog_dir>/stash.jsonl` (the active stash file at the resolved backlog root; here `.backlogit/stash.jsonl`); it never means "do not scan stashes". An explicit stash_path overrides it; both pass the same containment checks (Input safety). A missing stash file = no active stash entries; any other read error on it (unreadable, malformed line, containment failure) fails closed to a retention outcome for every DL that could still be archived. The U5a call site passes no stash_path, so the default is the production path.
- Disposition set: union over EVERY explicit manifest member regardless of artifact_type of (a) literal custom_fields.source_deliberation_id, (b) description + each frontmatter `references` entry scanned with `\b(?:DL\d+|[0-9]+(?:\.[0-9]+)*-DL)\b`; exclude self and every id in closure_scope(S) (H10); existence validated BEFORE location (>=1 record with artifact_type deliberation); unresolved ids -> `unresolved_references` (never a halt). Record link kinds, linking members, every record path, declared status, SHA-256 per record path.
- Planned outcome precedence (first match): retained_ambiguous (>1 record) -> already-archived (declared status exactly "archived", H3) -> retained_engine_unverified (engine UNVERIFIED; every path) -> retained_live_status (DL status active|blocked|review — the live statuses of the deliberation vocabulary in .backlogit/header-def.yaml: queued|active|blocked|review|done|accepted|rejected|archived; deliberations have no in-progress; a DL under review is never archived; queued/done/accepted/rejected are not live) -> retained_shared_reference [referrers] -> retained_description_mention (no source_deliberation_id link; report-only) -> archive.
- Live referrers COUNTED: work items (feature/task/subtask/bug/chore) outside closure_scope(S) not truly archived linking via any of the 3 sources; shipments != S not truly archived whose custom_fields.items lists the DL or whose description/source_deliberation_id names it; ACTIVE stash entries (the resolved stash_path; default `<workspace_backlog_dir>/stash.jsonl`) with deliberation_id == DL or text match. NEVER counted: the DL itself, other deliberations (A<->B cycles), docs/plans, truly archived items/shipments, archive/stash.jsonl. Referrer id with >1 record counts as live. H3 applies (archive/ + status done = live; queue/ + status archived = not live).
- Description source (PR #466 review): topology._frontmatter returns only the YAML mapping, but the backlogit description is the Markdown body after the closing frontmatter delimiter; read that body text from the same record read and use it wherever this task says "description" (member links and live referrers). A record whose body cannot be separated from its frontmatter is a read error (fail closed to retention).
- Input safety (Constitution III; PR #466 review): apply the same ID and path-containment checks as classify_shipment_close_path by reusing its helpers (_ARTIFACT_ID_PATTERN, _read_artifact_record, _scan_backlog, _is_symlink_or_reparse_point). Every candidate id (including a literal source_deliberation_id) must match _ARTIFACT_ID_PATTERN before any path is built, else it goes to `unresolved_references`; every record path and the supplied stash_path must canonicalize inside the workspace backlog tree and must not be or sit under a symlink/reparse point. A containment failure is a read error: fail closed to a retention outcome (never `archive`); never raise.
Tests (fixtures first): multi-feature manifest; self-reference; A<->B DL cycle; stash-only referrer (field and text); other-shipment member referrer; other-shipment description referrer; archived referrer (not counted); archive/ status done referrer (counted); queue/ status archived referrer (not counted); torn DL -> retained_ambiguous; explicit-member DL excluded (H10); status active, status blocked, and status review -> each retained_live_status (the review fixture has no other referrer, proving a DL under review is never archived); status queued with no referrer -> archive (not live); DEFAULT CALL with no stash_path argument: a source_deliberation_id DL (the 038-DL shape) cited only by an entry in `<workspace_backlog_dir>/stash.jsonl` -> retained_shared_reference naming that stash entry, and the same fixture without the entry -> archive; default call with `<workspace_backlog_dir>/stash.jsonl` absent -> no stash referrer counted, no raise; description-only -> retained_description_mention; engine UNVERIFIED -> retained_engine_unverified for every non-archived DL; unresolved id -> unresolved_references; non-deliberation artifact_type excluded; links from task/bug/chore members; a DL id present only in a member's Markdown body (found as a description link) and only in another shipment's body (counted as a live referrer); negative input-safety cases: traversal-shaped source_deliberation_id (e.g. `../x-DL`) -> unresolved_references, stash_path outside the backlog tree, symlink/junction record or stash_path -> each fails closed with no `archive` outcome.
