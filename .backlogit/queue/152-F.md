The release.yml pre-publish PyPI probe exits 0 when the target version already exists, so an unattended re-tag smoke-tests a pre-existing package and creates a GitHub Release around artifacts the run did not produce. Separately, the topology tests have no end-to-end push-context guard for ambient empty-string GITHUB_HEAD_REF, so the hotfixed failure class can silently recur. Source stash 8E10B13B, E738A7D1.
