IMPLEMENTATION - the single predicate and the INERT adapter command.

Implement validate_checkpoint_payload(payload, *, origin) -> ValidationOutcome in src/autoharness/ as THE SINGLE PREDICATE, with the four tokens and the structural origin partition. It is TOTAL over historical input: every record returns a ValidationOutcome decided by status alone - resolved yields the reported CHECKPOINT_LEGACY_HINTLESS_RESOLVED, active yields the blocking CHECKPOINT_ACTIVE_HINTLESS - never None and never an unclassified result. Outcome is DATA, not an exception, so the startup scan can report while the adapter halts.

Implement the EXECUTABLE ADAPTER COMMAND autoharness checkpoint create --state-dump <path-or-json> [--origin harness] as an invocable boundary. WHY A COMMAND AND NOT A LIBRARY CALL: the two producers this contract guards are MARKDOWN AGENT TEMPLATES. They import no Python and call backlogit directly, so a package-local function beside that call path cannot intercept it and a structural test would have no wiring to assert. Because the adapter is a command, "did this template invoke the adapter or the raw tool?" is a decidable, greppable property of the template text rather than an unverifiable intention.

VALIDATION IS STRICTLY PRE-WRITE: the adapter evaluates the payload before any create call is issued, and on a failing harness outcome it exits non-zero and WRITES NOTHING. The adapter ADDS NO CAPABILITY beyond backlogit's own create operation and introduces no second checkpoint store; it validates, then performs the official backlogit checkpoint create call. The instruction rule that checkpoints are written only through the official create operation is preserved, because the adapter IS how that operation is reached.

THE ADAPTER SHIPS INERT. No agent template references it yet. Wiring is 172.009-T, and doing it here would switch enforcement on before both producers have adopted the contract.
