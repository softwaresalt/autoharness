SIZE: M. COMPLEXITY: medium. (Two independent axes; also emitted as structured backlog fields.) Shipment 3 (P1). Create src/autoharness/supervise/approvals.py: a structured LOCAL command and approval channel. The supervisor emits ApprovalRequested carrying a typed request (kind, summary, options, default, timeout), renders it on the LOCAL CONSOLE, blocks for the operator's answer, and journals both request and response. Structured local commands (status, pause, resume, cancel) are handled over the same console channel. HARD CONSTRAINTS: console/TTY only - NO socket, NO port, NO HTTP, NO tunnel, NO remote identity, NO delegated approver, NO Gradio, NO devtunnel. Any remote approval path is DEFERRED to Plan 2 and is an explicit non-goal here. FAIL CLOSED (H2): in a non-interactive session an approval request resolves to its DECLARED SAFE DEFAULT, or to REFUSED where no safe default exists, and is journaled as auto-resolved - it NEVER silently auto-approves. Tests cover interactive approve/deny, timeout, non-interactive safe-default resolution, no-safe-default -> REFUSED, and an assertion that the module opens no socket.
