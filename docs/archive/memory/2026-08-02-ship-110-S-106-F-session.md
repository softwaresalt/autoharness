## Key learnings (durable)

1. **Fail-closed directive/presence checks need a stable multi-marker set,
   not two loose substrings.** A directive-presence check that only greps
   for a policy ID and a state-name token is trivially satisfiable by an
   incidental mention with zero real directive content. Require a
   combination of a stable section-heading fragment, a cross-reference to
   the canonical shared instruction, the policy identifier/state term, and
   the concrete required-action phrases the directive actually names.
   (`docs/compound/2026-05-07-role-route-resolution-fallback-gap.md`-style
   lesson family — see verify_workspace.py escalation checks.)
2. **A same-route/collision check gated on "has an explicit override key"
   misses the case where the role's live behavior comes entirely from
   fallback.** Any config-comparison guard modeling a role's resolved route
   must also consider whether that role's agent is actually installed
   (and therefore adopts the fallback chain) — not only whether an override
   key exists in config. This is a distinct-but-related pattern to the
   token-marker lesson above: both are "the check only covers the
   explicitly-declared case, not the fallback/default case."
3. **The `backlogit move --status done` vs `backlogit archive <id>`
   two-step (compound doc:
   `docs/compound/2026-08-02-backlogit-done-move-vs-explicit-archive.md`)
   applied cleanly this time** — proactively running explicit `archive`
   for every manifest artifact avoided the correction cycle `109-S`'s
   closure needed. Confirms the compound doc is now load-bearing; keep it
   current if backlogit's archive semantics change.
4. **Copilot review findings on a documentation-accuracy PR are often about
   truthfulness of "what's live vs. what's external," not style** — all 5
   findings this round were substantively correct: a template/policy/doc
   claiming a capability is "dormant" or a check claiming to be fail-closed
   must be verified against the actual shipped behavior, not just
   internally consistent prose.
