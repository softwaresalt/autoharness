## Lessons for future Ship sessions

- **Cut the post-merge branch first, always** — before running *any* backlog
  archival or other closure mutation, `git checkout main && git pull && git
  checkout -b post-merge/{slug}`. Doing archival "quickly" on `main` right
  after confirming the merge is a natural but incorrect shortcut; the protocol
  exists specifically because closure commits deserve the same review cycle as
  feature work.
- Copilot review re-arms on every push — never assume an old SATISFIED verdict
  survives a new commit; always re-request review and poll fresh.
- Reply-then-resolve on Copilot threads: reply with the fixing SHA before the
  GraphQL resolve mutation, for auditability.
- `backlogit archive <id>` on a shipment record is single-artifact-safe and
  does not require a preceding `move --status done` step (unlike task
  artifacts) — confirmed empirically this session.
