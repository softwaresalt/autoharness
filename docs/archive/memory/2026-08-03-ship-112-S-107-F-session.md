## Key learnings

- The move-vs-archive gap (`docs/compound/2026-08-02-backlogit-done-move-vs-explicit-archive.md`)
  is now a **recurring** pattern (3rd occurrence). The documented pre-flight
  check works when actually run, but nothing currently forces an agent to
  run it before applying the "pre-archived, skip" rule. This remains an
  open cross-shipment follow-up: harden Step 5 with a scripted/hard
  pre-flight status check rather than relying on a compound-doc reminder.
- Re-running every gate from scratch (rather than trusting a carried-over
  "known state" from a prior session) is cheap relative to the risk of a
  stale HEAD, a reopened Copilot thread, or a since-dismissed review — this
  session found no drift, but the re-verification is what makes that a
  fact rather than an assumption.
- Task-only shipment manifests whose covering feature has no other
  children (verified by enumerating both `queue/` and `archive/` for
  sibling IDs) can safely have the feature closed alongside the shipment
  without violating the partial-feature protected-set rule.
