## Key decisions / lessons

- The three-layer validation checklist (presence → container shape →
  member/value shape) for any backlog-frontmatter field feeding a decision,
  lookup key, or filesystem path — see the compound doc for the full
  11-round derivation.
- Any id later used in a filesystem glob must be shape-validated BEFORE the
  glob call.
- `REVIEW_TIMEOUT` with zero unresolved threads means "retry the gate",
  never an implicit pass or fail.
- Partial-feature closures must compute the protected set from the full
  hierarchy (covering feature + every non-manifest sibling task across
  `queue/` and `archive/`), not merely from what currently exists in queue,
  and must verify that set survives every single mutation step.
