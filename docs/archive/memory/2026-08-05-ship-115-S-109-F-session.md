## Key decisions / lessons

- See the compound learning doc for the full technical breakdown: (1)
  PowerShell CRLF-remangling breaks git-blob checksum computation — always
  hash subprocess `.stdout` directly or read renormalized staged bytes,
  never a shell-redirected read of working-tree bytes; (2) post-merge
  closure branches are feature-scoped, not shipment-scoped, and any
  ownership check keyed on a different id than its own primary key is a
  latent gap; (3) a task's code landing in `main` does NOT mean its
  backlogit record reached `done` — always verify live status directly
  before any safe-close, never infer from commit history or a prior
  session's summary.
- The user's explicit removal of the 3-review-fix-cycle cap was not
  actually needed this session — all findings were resolved in a single
  round each (1 local-review round, 1 Copilot round with fresh zero-thread
  confirmation) — but the uncapped posture was honored as instructed
  throughout.
