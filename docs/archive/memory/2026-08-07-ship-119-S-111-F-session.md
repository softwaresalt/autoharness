## Key learnings / cross-references

- `docs/compound/2026-08-07-copilot-review-fix-introduces-new-filter-bug.md`
  — the generalizable "narrowing a filter to fix an unsafe-inclusion
  finding can itself create a new unsafe-exclusion" pattern, observed
  identically across all 3 review rounds of this shipment. Key rule:
  prefer "unfiltered enumeration + anomaly-first fail-closed check +
  only-then partition" over composing successively narrower filters, and
  never conflate a fail-closed handoff (no action taken, state preserved)
  with an explicit disposition (resolve, or a named archival/abandonment
  decision).
- CRLF/LF checksum gotcha (from earlier in this session, consistent with
  prior shipments): always compute manifest checksums from committed git
  blob bytes (`git cat-file -p HEAD:<path>` or `:<path>` for staged), never
  a raw Windows working-tree read or PowerShell redirect.
- `gh api graphql -f query=` backtick-escaping in PowerShell: use GraphQL
  variables (`-F id=$t`) instead of inlining IDs into the query string
  with `\"` literals.
