## Key lessons (full detail in the compound-learning doc and archived memory)

1. **Three distinct LEGB scope-modeling bugs**, each found in a separate
   Copilot review round on the same `_EnvMutationVisitor` AST guard: flat
   alias map → scope stack (round 1); class bodies are NOT enclosing
   (LEGB) scopes for their own nested methods, unlike function bodies
   which chain as real closures (round 2); a def's header (decorators,
   defaults, annotations, bases) evaluates in the *enclosing* scope at
   definition time, never inside the def's own freshly-pushed body scope
   (round 3). Each fix was verified empirically against real CPython
   behavior, not reasoned from analogy.
2. **Stop Conditions circuit breaker held under autonomy pressure**: a
   4th review round surfaced a real, in-scope (P-021 C1) but P2-severity
   finding (control-flow-insensitive alias tracking). Reaching the 3-cycle
   review-fix budget correctly triggered a halt-and-escalate rather than a
   4th auto-fix, even though the operator had instructed "autonomous
   end-to-end completion" — that instruction did not itself authorize
   exceeding the explicit cycle limit; only the operator's subsequent
   explicit disposition (accept as documented residual risk) did.
3. **P-021 C1-passing-but-over-budget ≠ P-021 C2 (out-of-scope capture)**:
   the round-4 finding was in-scope the whole time; the correct
   disposition was a PR-readiness residual-risk note, not a deferred
   capture entry — conflating the two would have produced a misleading
   backlog artifact.
4. `backlogit shipment ship` (P-015 cascade close) took ~2 minutes for 7
   tasks + 1 feature + 1 shipment and can appear to hang; the 4-gate
   post-hoc verification (empty `returned_ids`, exact `archived_ids`
   match, unchanged `parent_id`) is what actually proves correctness, not
   mere command completion.
