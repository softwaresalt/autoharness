## Key learnings / gotchas

- **Tool-agnostic contract is enforced by Copilot**: shared agent/policy templates
  must reference abstract operations; concrete tool commands belong ONLY in
  tool-specific overlays. `backlogit.instructions.md.tmpl` IS the backlogit
  overlay, so concrete commands there are correct. Don't hardcode backlogit verbs
  in `_orchestrator.agent.md.tmpl` or `workflow-policies.md.tmpl`.
- **Registry asymmetry**: `get_queue` (queue-ordered) exists in the backlogit
  registry but NOT backlog-md; `list_shipments` exists in both but is unordered.
  A shared variable must not assume queue-ordering exists on every backend →
  conditional composition (abstract requirement in shared template, concrete
  selection in overlay/mirror).
- **Consume/produce loop closure**: if a rule consumes a cursor/token, the same
  agent must produce and advance it, or a downstream fix is inevitable. Issue E
  was a self-referential gap that CI/render checks can't catch — only behavioral
  review does.
- **Dogfood mirror discipline**: every Orchestrator template edit requires a
  matching render into `.github/agents/_orchestrator.agent.md` + regenerated
  checksum in `.autoharness/harness-manifest.yaml`
  (`(Get-FileHash -Algorithm SHA256 file).Hash.ToLower()`). Mirror is a RENDER,
  not a byte-copy (`{{STATUS_QUEUED}}`→`queued`, etc.). Checksum this round:
  `4286b2d5…`.
- **Copilot race window**: after each push, Copilot re-reviews the new HEAD
  (2–5 min). MUST confirm latest Copilot review `commit.oid` == current HEAD
  before checking threads; a gate check during the race falsely shows 0 comments.
- **v1.7.0 pre-archives on `move --status done`**: both the manifest tasks (during
  build) and the shipment record (during safe-close) were archived by the move,
  so the explicit `archive` call is an idempotent no-op / manifest-item skip.
