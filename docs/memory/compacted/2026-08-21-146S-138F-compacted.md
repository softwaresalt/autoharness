## Key learnings

1. A review-fix that hardens the task's own newly-added regression guard to
   meet its own stated acceptance criterion (B5: "fails if a new
   lifecycle-volatile path literal is introduced") is C3 in-scope across
   multiple review passes, even when each pass finds a different real gap in
   the same guard.
2. The P-021 C2 single-write invariant on a captured entry survives even a
   legitimate evidence-completeness finding ABOUT that entry — fix the PR's
   own evidence, never the already-captured entry.
3. `pytest tests/` and the canonical `PYTHONPATH=src python -m unittest
   discover -s tests` produce identical failure sets in this repo; citing
   the canonical gate directly (not just an equivalent pytest run) is the
   evidence reviewers expect as authoritative.
4. AST-based structural regression guards (walk for the underlying literal
   value) generalize far better than regex-over-text guards for a "no
   hardcoded X outside the resolver" assertion — see
   `docs/compound/2026-08-21-ast-based-structural-regression-guards-beat-line-regex.md`.
