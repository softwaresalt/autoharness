## Key learnings (durable)

1. **Schema strictness beats convenience normalization.** `event_id` schema
   allows arbitrary non-whitespace; don't let a UUID-normalizer silently
   narrow that. Same principle for `work_sizing_snapshot` — `anyOf(object,
   null)` means anything else must raise, not silently become `None`.
2. **Path-bearing telemetry fields need workspace-containment validation**,
   not just schema type-checking — mirrors `context.py`'s `_is_within` /
   `Path.resolve()` pattern; catches `..` traversal, absolute paths, and
   Windows drive-relative escapes in one check.
3. **A composer must never operate on a silently-truncated read.** Any
   segment I/O failure should discard all partial results and report
   `unavailable`, not compose an undercount into an immutable epoch.
4. **Defensive clamping (e.g. `max()` aggregation) should still surface the
   anomaly it's clamping** — added non-monotonic diagnostics alongside the
   safe aggregate.
5. **`exclusiveMinimum: 0` in a schema means `0` doesn't count as "populated"
   for provenance purposes** — `is not None` is the wrong proxy whenever
   0/false/empty are in-domain-but-meaningless.
6. **Copilot review re-arms on every push** — never trust an old SATISFIED
   verdict after a new commit; re-request and poll fresh.
7. **Post-merge branch protocol has zero exceptions** — cut the branch first,
   always, even for "just archiving the shipment record."
