## Outcome

Shipped **PR #379** (merge commit `f57d0f0c`, two parents `e1a42a70`+`08607503`,
merged 2026-08-21T11:37:53Z). Ship's Task Execution Loop now derives its
executable task set from live task records (filter to `-T` artifacts before
any status read; keep `queued`/`active`; skip-and-report `archived` as
`pre_archived_skipped` distinct from `already_done`; fail-closed halt on any
other/missing/unreadable status; halt on an empty derived set over a
non-empty manifest) instead of iterating the shipment manifest
unconditionally. The manifest stays the closure-membership record only,
byte-for-byte unchanged. This unblocks `144-S`/`145-S`.

## Key learnings

See `docs/compound/2026-08-21-ship-executable-set-must-wire-into-actual-loop-variable.md`
for the full generalizable writeup: a prose derivation that is internally
coherent can still be a functional no-op if it isn't explicitly wired into
the specific variable/list a later, unedited step consumes by name; and
relaxing an implicit assumption ("manifest is status-uniform at intake") in
one part of a contract requires re-checking every other part that silently
depended on it.
