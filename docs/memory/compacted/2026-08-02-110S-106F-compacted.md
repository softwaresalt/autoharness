## Key learnings (durable)

1. **Fail-closed directive/presence checks need a stable multi-marker set,
   not two loose substrings** — a check that greps only a policy ID and a
   state-name token is trivially satisfiable by an incidental mention with
   no real directive content. Require a heading fragment, a cross-reference
   to the canonical shared instruction, the identifier/state term, and the
   concrete required-action phrases.
2. **A same-route/collision (or any role-route) comparison gated on "has an
   explicit override key" misses the fallback-only case** — a role whose
   live behavior comes entirely from tier fallback (no override key) must
   still be compared if its agent is actually installed. Check installed
   status, not just explicit config keys.
3. **`backlogit move --status done` vs `backlogit archive <id>` two-step
   (see `docs/compound/2026-08-02-backlogit-done-move-vs-explicit-archive.md`)
   is now a load-bearing, verified-twice lesson** — applied proactively this
   closure with no correction cycle, confirming the compound doc's guidance
   is correct and durable.
4. **Copilot findings on a documentation-accuracy PR are usually about
   truthfulness of "what's live vs. external," not style** — verify claims
   of dormancy/fail-closed behavior against actual shipped code, not just
   internal prose consistency.
