# Compacted memory: shipment 145-S

**What shipped**: authored the formal template/dogfood paired-edit
maintenance contract (two categories, eight-pair inventory, cause
taxonomy, author obligation, recorded-exception-not-a-goal); pinned the
four divergent pairs with a fail-closed membership assertion; migrated
Ship's post-merge Step 7 stash-retirement operation from the deprecated
`backlogit_stash_remove` to `backlogit_stash_archive` across the Ship
template + dogfood mirror, verifier, contract tests, manifest checksum,
P-021 C5 policy clause, and backlog registry `cli_command` mapping.

**Key decisions**:
* Execution order followed the feature-level directive:
  `137.002-T` -> `137.001-T` -> `137.003-T`, then order-independent
  `137.004-T`; `137.005-T`/`137.006-T` stayed archived and untouched
  throughout (pre_archived_skipped).
* `137.003-T` bundled the Ship template/mirror, verifier marker, three
  contract-test files, and the manifest checksum in ONE atomic commit per
  its hardening constraint H1 (the former three-task split was mutually
  breaking under Ship's per-task gate).
* `137.004-T` added the registry's missing `cli_command` as the exact
  parameterized string `backlogit stash archive {{stash_id}}` (a bare
  command is unexecutable per the CLI's single required positional arg)
  while keeping `stash_remove` present-but-undeleted per H5.
* Test-first throughout: every production edit in 137.003-T/137.004-T was
  preceded by a confirmed RED run, then GREEN after the edit.

**Review-fix history**:
* Self-review (pre-PR) caught and fixed a **P0**: a stray corrupted
  trailing line accidentally introduced into `.github/agents/_ship.agent.md`
  by an `apply_patch` tool artifact, baked into the manifest checksum;
  fixed by stripping the line and recomputing the checksum.
* Copilot review round 1 caught and fixed a **P1**: the divergent-pair
  membership assertion (`_EXPECTED_DIVERGENT_PAIR_MANIFEST_PATHS`) was
  derived from the same tuple (`_DIVERGENT_MARKER_ONLY_PAIRS`) as the
  "actual" side it compared against, making the fail-closed check vacuous.
  Fixed by hardcoding the expected set as an independent literal, verified
  locally to now catch both a simulated removal and addition.

(used to isolate the pre-existing E8158860 test-isolation failures)
desynced the on-disk `.backlogit/queue/*.md` files for the shipment and
its four tasks back to their pre-claim state, even though the CLI's
internal state and all committed deliverables remained correct. Detected
via the `pipeline-topology --phase lifecycle` gate and the CLI's own
`status conflict` refusal on re-claim; repaired by re-running the
`queued -> active -> done` transitions and correcting the shipment file
directly. Promoted to
`docs/compound/2026-08-21-backlogit-shipment-status-file-desync-after-git-stash.md`.
