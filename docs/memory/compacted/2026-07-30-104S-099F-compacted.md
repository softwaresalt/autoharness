## Key learnings

1. **v1.7.0 `move --status done` auto-archives** (queue → archive) for both tasks
   and shipments. The Step 5 safe-close protocol anticipates pre-archived manifest
   items ("skip pre-archived") and only protects the covering feature + unshipped
   sibling tasks. Verify-after-each on `git status -- .backlogit/` is the guardrail.
2. **Copilot as a canonical-surface completeness checker**: even a plan-reviewed
   "full canonical surface" table can miss a sibling tool (`query_graph_neighborhood`).
   When an AC lists a *required-minimum* set, an additive superset fix is the clean
   resolution and strengthens the consistency AC rather than violating scope.
3. **P-001 drift is not P-001 blocking**: features `094-F`/`095-F`/`097-F` show
   `active` but have zero active tasks and zero in-flight PRs (stuck-active backlog
   drift; 094-F already merged `612f47d`). Substantive P-001 precondition (no
   competing active tasks, no in-flight PR) was met.
