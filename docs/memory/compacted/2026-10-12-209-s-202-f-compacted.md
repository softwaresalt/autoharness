## Learnings

* `backlogit move <task> --status done` relocates the task record under `.backlogit/archive/` but
  the record still declares `status: done`. Under P-015 that is NOT truly archived or engine-inert
  (only a declared `status: archived` counts); location is descriptive only. The pre-close contract
  matches those members by declared `done` status, and the later CASCADE close set the final
  `archived` status.
* Observed in 209-S (not a configured fallback; see stash `1AD61D32`): a GraphQL `requestReviews`
  mutation with `botIds` registered the Copilot reviewer when `gh` and REST did not:
  `docs/compound/2026-10-12-requesting-copilot-review-via-graphql-bot-id.md`.
* Each push runs the full unittest suite and markdownlint through the pre-push hook (about 10
  minutes); batch fixes per Copilot round.
* The CASCADE child run took about 680 s for 6 artifacts, above the 515 s reference estimate; the
  1800 s default timeout was correct.
