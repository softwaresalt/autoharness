Every row below is executed and its output summary is recorded in
[1.6.0-readiness-evidence.md](1.6.0-readiness-evidence.md). No agent creates, pushes, or triggers a tag or the
release workflow; the tag is an operator action.

| # | Gate | Command or check | Evidence section |
|---|---|---|---|
| 1 | Version sites agree on 1.6.0 | `tests/test_version_consistency.py`, `uv lock --check` | E1 |
| 2 | CHANGELOG has a non-empty `1.6.0` section and no `Unreleased` content | `tests/test_release_changelog_extraction.py` | E2 |
| 3 | Release notes and upgrade guide exist and link-resolve | `docs/releases/1.6.0-*.md`, markdownlint | E3 |
| 4 | Full unit test suite | `PYTHONPATH=src python -m unittest discover -s tests` | E4 |
| 5 | Markdown lint | `markdownlint "**/*.md"` | E5 |
| 6 | Dogfood workspace verification | `autoharness verify-workspace --workspace .` | E6 |
| 7 | Distribution builds and passes metadata checks | `uv build`, `twine check dist/*` | E7 |
| 8 | Wheel contains templates and schemas | wheel content listing | E7 |
| 9 | `release.yml` dry review | tag equals `pyproject.toml` version, changelog extraction, publish path | E8 |
| 10 | No tag exists | `git tag -l v1.6.0`, `git ls-remote --tags origin v1.6.0` | E9 |
| 11 | Operator tag instruction recorded | OPERATOR TAG INSTRUCTION section | E10 |
